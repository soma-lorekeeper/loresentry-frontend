# UI 비교

두 서비스의 시각적 표현과 작업 화면 구성 방식을 비교한다. 이 문서는 경쟁 서비스의 UI를 구현하기 위한 명세가 아니다.

## 시각적 비교

| 기준 | 펜시브 | 뮤블 |
| --- | --- | --- |
| 전체 인상 | 절제된 전문 생산성 도구 | 친근한 브랜드와 기능적 데스크톱 도구 |
| 기본 테마 | 어두운 무채색 | 밝은 작업 화면 중심 |
| 화면 구분 | 명도 차이와 얇은 선 | 분명한 테두리와 분할선 |
| 원고 강조 | 넓은 여백과 제한된 본문 폭 | 독립 문서 패널과 높은 대비 |
| 탐색 | 메뉴와 파일 트리 통합 | 전역 레일과 워크트리 분리 |
| 보조 정보 | 우측 패널 또는 다른 파일 | 위젯과 독립 패널 |
| 상태 표현 | 제한된 색상과 작은 칩 | 여러 기능색, 점, 칩과 테두리 |
| 정보 밀도 | 중간, 원고 중심 | 높음, 다중 패널 중심 |

## 공통 UI 패턴

- 원고 제목과 본문이 도구보다 높은 시각적 우선순위를 갖는다.
- 파일 트리는 들여쓰기, 아이콘, 선택 상태와 펼침 상태를 함께 사용한다.
- 현재 열린 문서와 현재 선택한 트리 항목을 별도로 표현한다.
- 넓은 모니터에서도 본문 폭을 제한한다.
- 저장·동기화 상태를 작업 화면 안에서 지속적으로 표시한다.
- 색상만으로 상태를 전달하지 않고 아이콘이나 텍스트를 함께 사용한다.
- 여러 자료를 동시에 보여줄 때 패널별 경계를 제공한다.

## 서비스별 고유 표현

### 펜시브

- 검정 기반 IDE형 셸과 상단 통합 검색.
- 좌측 파일 트리, 브라우저형 탭과 우측 댓글 패널.
- 타임라인의 상태별 레일과 카드.

### 뮤블

- 랜딩과 로그인에서 사용하는 대형 문자와 캐릭터.
- 최좌측 아이콘 레일과 작품 워크트리.
- 흰색 다중 패널, 메모 카드와 플로팅 도움말 버튼.
