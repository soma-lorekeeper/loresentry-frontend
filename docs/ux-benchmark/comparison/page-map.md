# 펜시브·뮤블 페이지 대응표

두 서비스의 화면을 기능 이름이 아니라 사용자가 해결하는 과업을 기준으로 대응시킨다. 완전히 동일한 페이지가 없는 경우 가장 가까운 작업 화면을 연결했다.

| 사용자 과업 | 펜시브 | 뮤블 | 구조 차이 |
| --- | --- | --- | --- |
| 서비스 이해·인증 | [로그인](../pensiv/01-login.md) | [랜딩과 로그인](../muvel/01-landing-and-login.md) | 펜시브는 인증에 집중하고, 뮤블은 랜딩에서 제품을 먼저 설명한다. |
| 작품 선택·생성 | [프로젝트 목록과 생성](../pensiv/02-project-list-and-create.md) | [프로젝트와 에피소드 목록](../muvel/02-project-and-episode-list.md) | 펜시브는 템플릿과 구조 선택을, 뮤블은 에피소드 진입을 강조한다. |
| 작품 전체 상태 확인 | [프로젝트 홈과 탐색](../pensiv/03-project-home-and-navigation.md) | [프로젝트와 에피소드 목록](../muvel/02-project-and-episode-list.md) | 펜시브는 별도 프로젝트 홈의 역할이 더 분명하다. |
| 원고 작성 | [문서 편집기](../pensiv/04-document-editor.md) | [일반 편집기](../muvel/03-general-editor.md) | 펜시브는 통합 작업 셸, 뮤블은 단순한 기본 편집기에서 시작한다. |
| 여러 자료 동시 참조 | [탭과 분할 보기](../pensiv/08-tabs-and-split-view.md) | [워크스페이스 편집기](../muvel/04-workspace-editor.md) | 펜시브는 패널 분할, 뮤블은 독립 패널과 위젯 구성을 사용한다. |
| 작품 설정 관리 | [시트와 설정](../pensiv/05-sheet-and-settings.md) | [위키](../muvel/05-wiki.md) | 펜시브는 구조화된 시트, 뮤블은 작가에게 익숙한 위키 개념을 사용한다. |
| 이야기 순서 관리 | [플롯보드와 타임라인](../pensiv/06-plotboard-and-timeline.md) | [플롯 캔버스](../muvel/06-plot-canvas.md) | 펜시브는 보기 전환, 뮤블은 공간형 캔버스에 가깝다. |
| 관계 탐색 | [캔버스와 관계 그래프](../pensiv/07-canvas-and-relation-graph.md) | [플롯 캔버스](../muvel/06-plot-canvas.md) | 펜시브는 파일 연결 그래프를 별도로 제공한다. |
| 임시 정보·보조 도구 | 프로젝트 노트와 작업 기능 | [메모와 위젯](../muvel/07-memo-and-widgets.md) | 뮤블이 사용자별 도구 배치와 개인화를 더 적극적으로 지원한다. |

## 핵심 차이

- 펜시브는 프로젝트 구조와 파일 간 연결을 먼저 보여준다.
- 뮤블은 에피소드 집필에서 시작해 위키·캔버스·위젯으로 확장한다.
- 펜시브의 작업 공간은 파일 유형이 달라도 공통 패널 구조를 유지한다.
- 뮤블의 작업 공간은 개별 편집기와 고급 워크스페이스로 나뉜다.
