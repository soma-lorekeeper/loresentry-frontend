# 뮤블 페이지별 분석

- 대상: [뮤블](https://muvel.app/ko)
- 관점: PC 웹의 작가 중심 용어, 집필 흐름, 작업 환경과 시각 표현
- 주의: 구현 명세가 아닌 벤치마킹 자료이며 UI를 그대로 복제하지 않는다.

## 전체 흐름

```text
랜딩과 로그인
→ 소설 프로젝트
→ 에피소드 생성
→ 일반 편집기에서 원고 작성
→ 위키·플롯·메모 추가
→ 워크스페이스와 위젯으로 고급 작업 환경 구성
```

## 공통 관찰

- 에피소드, 위키와 메모처럼 작가에게 익숙한 용어로 정보 구조를 설명한다.
- 기본 집필과 고급 워크스페이스를 분리해 기능을 단계적으로 노출한다.
- 밝은 작업 화면, 분명한 패널 테두리와 여러 기능색으로 영역을 구분한다.
- 사용자가 위젯과 패널을 구성할 수 있어 개인화가 강하지만 기본 화면의 일관성은 약해질 수 있다.
