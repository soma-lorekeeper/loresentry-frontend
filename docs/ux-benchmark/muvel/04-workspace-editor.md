# 뮤블 워크스페이스 편집기

## 페이지 목적과 흐름

- 목적: 원고, 위키, 플롯과 메모를 한 화면에 배치해 복합 작업을 수행한다.
- 진입: 에피소드의 워크스페이스 열기 또는 고급 편집 모드 전환.
- 다음 이동: 선택한 문서 편집, 패널 재배치 또는 일반 편집기로 복귀.

## 화면 구조

```text
최좌측: 전역 아이콘 레일
좌측: 워크스페이스 트리
중앙 상단: 원고와 위키 문서 패널
중앙 하단: 플롯 캔버스
우측: 메모 보드·위젯
```

| 영역 | UI 구성 | UX 역할 |
| --- | --- | --- |
| 전역 레일 | 메뉴, 검색, 설정과 테마 아이콘 | 작업 공간을 확보하며 앱 영역을 전환한다. |
| 워크트리 | 작품 정보, 에피소드와 위키 계층 | 한 작품의 전체 구조와 현재 위치를 보여준다. |
| 문서 패널 | 제목, 상태, 검색·닫기와 본문 | 여러 문서를 독립된 창처럼 구분한다. |
| 캔버스 | 점 격자, 노드, 연결선과 줌 도구 | 플롯과 관계를 시각적으로 다룬다. |
| 보조 영역 | 메모 보드와 위젯 | 집필 중 필요한 짧은 정보와 도구를 제공한다. |

## 핵심 인터랙션

- 여러 문서 창을 분할하고 탭을 이동한다.
- 패널마다 검색, 닫기와 상태 제어를 제공한다.
- 흰색 패널과 분명한 테두리로 동시에 열린 영역을 구분한다.
- 위젯과 보조 도구를 사용자가 배치해 작업 환경을 구성한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 여러 자료를 열어도 패널 경계가 분명하다. | 테두리와 제어 아이콘이 시각적 소음을 만든다. |
| 원고와 설정·플롯을 동시에 확인한다. | 패널이 늘수록 원고보다 도구가 강하게 보인다. |
| 숙련자가 작업 환경을 개인화한다. | 사용자마다 화면이 달라 지원과 학습이 어렵다. |
