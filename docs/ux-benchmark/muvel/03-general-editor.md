# 뮤블 일반 편집기

## 페이지 목적과 흐름

- 목적: 복잡한 화면 구성을 하지 않고 에피소드 원고를 바로 작성한다.
- 진입: 에피소드 목록에서 회차 열기.
- 다음 이동: 다른 에피소드, 위키·메모 또는 고급 워크스페이스.

## 핵심 UX

- 에피소드라는 익숙한 단위에서 바로 원고 작성으로 연결한다.
- 기본 집필과 고급 워크스페이스를 구분해 초기 기능 부담을 낮춘다.
- 필요할 때 다른 자료와 보조 기능을 추가하도록 점진적으로 확장한다.
- 배경, 글꼴, 줄 간격과 테마를 조정해 장시간 집필 환경을 개인화한다.

## 화면 표현

- 밝은 원고 배경과 높은 본문 대비를 기본 작업 인상으로 사용한다.
- 문서 제목과 본문은 크기와 굵기로 위계를 구분한다.
- 상태나 속성 정보는 본문보다 작은 칩과 텍스트로 압축한다.
- 작업 화면의 문체는 로그인보다 기능 중심이고 중립적이다.

## 장점과 마찰

- 고급 도구를 먼저 이해하지 않아도 집필을 시작할 수 있다.
- 밝은 화면은 일반적인 문서 편집 경험과 가까워 익숙하다.
- 일반 편집기에서 워크스페이스로 전환할 시점과 차이가 명확하지 않을 수 있다.
- 개인화 옵션이 많으면 사용자가 적절한 기본값을 직접 찾아야 한다.
