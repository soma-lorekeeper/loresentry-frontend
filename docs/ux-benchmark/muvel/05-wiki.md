# 뮤블 위키

## 페이지 목적과 흐름

- 목적: 인물, 세계관과 사건처럼 확정된 작품 설정을 관리하고 원고에서 참조한다.
- 진입: 워크트리, 검색, 워크스페이스 패널 또는 새 위키 생성.
- 다음 이동: 연결된 에피소드, 다른 위키 또는 플롯 캔버스.

## 핵심 UX

- 원고와 설정을 에피소드와 위키라는 익숙한 용어로 구분한다.
- 위키를 독립 문서 패널로 열어 원고와 나란히 참조할 수 있다.
- 속성은 태그, 등급, 장르와 표 같은 구조화된 표현을 사용한다.
- 워크트리의 아이콘과 들여쓰기로 설정 계층을 빠르게 훑는다.

## 화면 표현

- 밝은 배경과 높은 텍스트 대비를 사용한다.
- 문서 제목과 속성 영역의 위계를 크기와 굵기로 구분한다.
- 속성은 파랑·회색 계열 칩과 표로 압축해 한 화면에 많은 정보를 표시한다.
- 패널 제목, 상태 점, 검색과 닫기 버튼이 다른 문서 패널과 같은 위치에 반복된다.

## 장점과 마찰

- 설정과 원고의 시각적 구분이 명확하고 동시에 열어 비교하기 쉽다.
- 속성 위치가 고정되어 반복 확인이 빠르다.
- 작은 칩과 조밀한 표가 많아지면 읽기보다 관리 화면처럼 느껴질 수 있다.
- 패널 제어와 상태색이 누적되면 실제 설정 내용의 우선순위가 낮아진다.
