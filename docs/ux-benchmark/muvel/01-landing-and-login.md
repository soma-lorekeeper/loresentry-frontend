# 뮤블 랜딩과 로그인

## 페이지 목적과 흐름

- 랜딩 목적: 제품의 창작 도구 이미지를 전달하고 집필 시작 행동을 유도한다.
- 로그인 목적: 키뮤스토리 통합 계정으로 인증한다.
- 다음 이동: 인증 완료 후 소설 프로젝트 화면.

```text
뮤블 랜딩
→ 로그인하고 글 쓰러 가기
→ 키뮤스토리 통합 로그인
→ 소설 프로젝트
```

## 화면 구성과 UI

| 영역 | 관찰 | UX 효과와 위험 |
| --- | --- | --- |
| 랜딩 배경 | 어두운 보라 계열과 큰 제품 미리보기 | 창작 도구의 감성적 인상을 주지만 실제 작업 화면과 차이가 있다. |
| 로그인 배경 | 밝은 청회색과 큰 장식 텍스트 | 빈 공간을 브랜드 요소로 채우지만 시선을 분산할 수 있다. |
| 인증 영역 | 여러 소셜 로그인을 중앙 세로 열에 배치 | 선택은 단순하지만 수가 많으면 우선순위가 흐려진다. |
| 캐릭터 | 우측 하단 일러스트와 말풍선 | 친근하고 기억하기 쉽지만 전문 도구의 신뢰감과 충돌할 수 있다. |
| 전역 제어 | 우측 상단 언어와 테마 버튼 | 진입 전부터 접근성과 개인화를 제공한다. |

## 핵심 마찰

- 뮤블 브랜드에서 키뮤스토리 계정 화면으로 바뀌어 서비스 연결감이 약해진다.
- 감성적인 랜딩·로그인과 기능적인 작업 화면의 시각적 어조가 다르다.
- 아이콘만 있는 언어·테마 제어는 의미를 바로 이해하기 어려울 수 있다.
