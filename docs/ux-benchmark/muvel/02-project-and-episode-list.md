# 뮤블 프로젝트와 에피소드 목록

## 페이지 목적과 흐름

- 목적: 소설을 선택하고 집필할 에피소드를 생성·관리한다.
- 진입: 로그인 완료 또는 다른 프로젝트에서 전환.
- 다음 이동: 일반 편집기, 워크스페이스, 위키, 플롯 캔버스 또는 메모.

```text
소설 프로젝트
→ 에피소드 생성
→ 제목과 필요한 속성 설정
→ 원고 편집기
```

## 정보 구조

```text
소설 프로젝트
├─ 에피소드
├─ 위키
├─ 플롯 캔버스
├─ 메모
├─ 일반 편집기
└─ 워크스페이스 편집기
```

에피소드에는 연령 등급과 서술 시점 같은 작품 속성을 부여할 수 있다. 목록의 맥락 메뉴에서 열기, 이름 변경, 복제, 상태 변경, 버전 관리, 댓글, 워크스페이스 열기와 삭제를 실행한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 작가에게 익숙한 에피소드 용어를 사용한다. | 맥락 메뉴에 기능이 집중되면 발견하기 어렵다. |
| 기본 목록에서 고급 관리 기능으로 확장한다. | 속성과 상태가 많으면 회차 생성이 무거워진다. |
| 같은 회차를 일반·워크스페이스 편집기로 열 수 있다. | 두 편집 방식의 차이를 학습해야 한다. |
