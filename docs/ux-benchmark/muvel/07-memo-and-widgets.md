# 뮤블 메모와 위젯

## 화면 목적과 흐름

- 메모 목적: 집필 중 생긴 임시 아이디어와 짧은 참고 정보를 보관한다.
- 위젯 목적: 현재 작업에 필요한 보조 도구를 편집 화면에 추가한다.
- 진입: 워크스페이스 보조 영역 또는 위젯 추가·설정.

## 제공 기능

- 글자 수와 현재 선택 위치.
- 다른 에피소드와 위키 참조.
- 메모와 상용구 관리.
- 사전과 특수문자 입력.
- 타이머, 스톱워치, 집필 속도와 집중도 측정.
- TTS와 빠른 스크롤.
- 단락 및 반복 표현 분석.

## 배치와 인터랙션

- 일반 위젯은 편집기 좌우 빈 공간에 배치한다.
- 짧은 상태 정보는 편집기 하단에 둔다.
- 위젯은 드래그로 순서를 바꾸고 접거나 일부 크기를 조절할 수 있다.
- 메모는 긴 문서와 다른 카드 표현을 사용해 빠르게 식별한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 사용자가 자신의 집필 환경을 구성한다. | 무엇을 배치해야 하는지 먼저 결정해야 한다. |
| 보조 도구를 위해 작업 맥락을 벗어나지 않는다. | 위젯이 많아지면 원고보다 도구가 강조된다. |
| 자주 쓰는 기능을 가까운 곳에 고정한다. | 사용자마다 화면이 달라 도움말과 지원이 어려워진다. |
