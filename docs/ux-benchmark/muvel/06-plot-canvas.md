# 뮤블 플롯 캔버스

## 페이지 목적과 흐름

- 목적: 사건, 관계와 이야기 분기를 공간적으로 배치하고 에피소드·위키와 연결한다.
- 진입: 프로젝트 탐색 또는 워크스페이스의 캔버스 패널.
- 다음 이동: 선택한 노드와 연결된 에피소드 또는 위키.

## 화면 구성과 인터랙션

- 점 격자 기반의 넓은 캔버스를 사용한다.
- 노드와 연결선으로 사건 또는 관계를 표현한다.
- 줌 도구와 미니맵을 사용해 넓은 작업 공간을 탐색한다.
- 워크스페이스 안에서는 원고·위키 패널과 함께 열어 시각화와 실제 내용을 비교한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 선형 목록으로 보기 어려운 관계를 공간적으로 표현한다. | 자유 배치 기준을 사용자가 직접 만들어야 한다. |
| 원고와 함께 열어 플롯을 바로 참조한다. | 작은 패널에서는 캔버스 탐색성이 급격히 떨어진다. |
| 노드에서 관련 문서로 이동할 수 있다. | 노드가 많아지면 연결선이 시각적 소음을 만든다. |
