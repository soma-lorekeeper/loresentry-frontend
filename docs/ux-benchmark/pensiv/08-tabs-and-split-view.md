# 펜시브 탭과 분할 보기

## 화면 목적과 흐름

- 목적: 원고를 닫지 않고 설정, 플롯과 다른 문서를 동시에 참조한다.
- 진입: 파일 열기, 패널 분할, 탭 이동 또는 새 창 열기.
- 종료: 패널 닫기, 분할 합치기 또는 한 패널 확장.

## 핵심 인터랙션

- 열린 파일은 상단 탭에 남아 최근 작업 맥락을 유지한다.
- 패널을 좌우 또는 상하로 분할하고 다시 확장할 수 있다.
- 탭을 다른 패널로 옮기거나 패널을 잠글 수 있다.
- 필요하면 파일을 새 창으로 열어 별도 모니터에서도 작업한다.
- 각 패널은 탭 바, 파일 헤더, 툴바와 작업 영역의 계층을 유지한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 원고와 설정을 동시에 확인한다. | 분할이 늘수록 원고의 최소 폭이 무너진다. |
| 탭이 현재 사고 중인 파일 집합을 보존한다. | 탭이 많으면 열린 파일과 현재 위치가 혼동된다. |
| 패널 조작 규칙이 파일 유형과 무관하게 같다. | 패널마다 헤더와 툴바가 반복된다. |
| 숙련자는 자신에게 맞는 화면을 구성한다. | 초보자는 적절한 배치를 직접 결정해야 한다. |
