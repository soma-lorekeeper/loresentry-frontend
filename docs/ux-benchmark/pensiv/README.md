# 펜시브 페이지별 분석

- 대상: [펜시브 웹 앱](https://app.pensiv.so/)
- 관점: PC 웹의 페이지 흐름, 작업 맥락, 인터랙션과 시각 표현
- 주의: 구현 명세가 아닌 벤치마킹 자료이며 UI를 그대로 복제하지 않는다.

## 전체 흐름

```text
로그인
→ 전체 프로젝트
→ 새 프로젝트
→ 프로젝트 홈
→ 문서·시트·플롯보드·캔버스
→ 탭과 분할 보기로 여러 자료를 함께 작업
```

## 공통 관찰

- 파일이 아니라 프로젝트에서 시작하며 모든 자료를 작품 단위로 묶는다.
- 좌측 탐색, 상단 탭, 중앙 작업 영역의 역할이 대부분의 화면에서 유지된다.
- 검정과 짙은 회색을 기본으로 사용하고 선택·상태·관계에 강조색을 제한한다.
- 기능이 많지만 콘텐츠 유형마다 동일한 패널 계층을 재사용한다.
