# 펜시브 프로젝트 목록과 생성

## 페이지 목적과 흐름

- 목적: 작업할 작품을 선택하거나 새 프로젝트를 만든다.
- 진입: 로그인 완료 또는 전역 프로젝트 전환.
- 다음 이동: 선택한 프로젝트 홈 또는 신규 프로젝트 설정.

```text
전체 프로젝트
→ 새 프로젝트
→ 빈 프로젝트 또는 예제 선택
→ 구조 템플릿 선택
→ 제목·설명 입력
→ 프로젝트 홈
```

## 핵심 UX

- 프로젝트를 모든 원고와 설정의 최상위 단위로 사용한다.
- 빈 프로젝트뿐 아니라 예제와 구조 템플릿을 제공한다.
- 예제 프로젝트가 복잡한 파일 구조를 직접 탐색하는 튜토리얼 역할을 한다.
- 생성 완료 후 프로젝트 안에서 문서, 캐릭터와 플롯을 추가하게 한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 처음부터 작품 단위로 정보가 묶인다. | 첫 원고 전에 프로젝트 개념을 이해해야 한다. |
| 예제가 완성된 작업 구조를 보여준다. | 빈 프로젝트와 템플릿 사이에서 망설일 수 있다. |
| 다른 작품으로 전환하는 기준이 명확하다. | 제목·설명·구조 선택이 즉시 집필을 늦출 수 있다. |
