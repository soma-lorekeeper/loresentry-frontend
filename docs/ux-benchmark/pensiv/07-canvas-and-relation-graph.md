# 펜시브 캔버스와 관계 그래프

## 페이지 목적과 흐름

- 목적: 인물, 사건, 설정과 아이디어의 연결을 시각적으로 탐색한다.
- 진입: 프로젝트 메뉴, 캔버스 파일 또는 설정의 연결 정보.
- 다음 이동: 선택한 노드에 대응하는 문서·시트.

## 핵심 UX

- 캔버스는 아직 정형화되지 않은 아이디어와 관계를 공간적으로 배치한다.
- 관계 그래프는 프로젝트 파일 사이의 기존 연결을 탐색한다.
- 텍스트 계층만으로 파악하기 어려운 연결과 군집을 시각적으로 보여준다.
- 노드에서 원본 파일로 이동하여 시각화와 실제 편집 맥락을 연결한다.

## 장점과 마찰

- 복잡한 인물 관계와 설정 연결을 한 화면에서 조망할 수 있다.
- 자유 배치는 창작 과정에 유연하지만 정리 기준을 사용자에게 맡긴다.
- 노드와 연결선이 많아지면 그래프가 오히려 구조 이해를 방해할 수 있다.
- 범용 그래프는 현재 사용자가 해결하려는 문제를 명확하게 설명하지 못할 수 있다.
