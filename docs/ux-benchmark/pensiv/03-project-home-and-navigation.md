# 펜시브 프로젝트 홈과 탐색

## 페이지 목적과 흐름

- 목적: 작품의 현재 상태를 파악하고 이전 작업 맥락으로 복귀한다.
- 진입: 프로젝트 선택 또는 새 프로젝트 생성 완료.
- 다음 이동: 최근 파일, 할 일, 문서, 시트, 플롯보드, 캔버스와 노트.

## 정보 구조

```text
프로젝트 홈
├─ 최근 파일·할 일
├─ 문서
├─ 캐릭터·설정 시트
├─ 플롯보드
├─ 캔버스
├─ 노트
├─ 관계 그래프
└─ 작업 관리
```

## 화면 구성과 인터랙션

| 영역 | 역할 | 관찰 |
| --- | --- | --- |
| 상단 | 프로젝트 경로, 통합 검색과 상태 | 낮은 높이로 전역 기능의 공간을 줄인다. |
| 좌측 상단 | 홈, 그래프, 작업 등 주요 메뉴 | 작품의 기능 영역을 전환한다. |
| 좌측 트리 | 폴더와 파일 계층 | 들여쓰기, 아이콘과 선택 행으로 현재 위치를 표현한다. |
| 트리 하단 | 휴지통, 가져오기, 내보내기와 설정 | 집필 기능과 관리 기능을 분리한다. |
| 중앙 | 홈 요약 또는 선택 파일 | 최근 맥락에서 실제 작업으로 이동한다. |

## 장점과 마찰

- 최근 파일과 할 일을 통해 큰 프로젝트에서도 작업을 재개하기 쉽다.
- 기능 메뉴와 파일 트리가 한 탐색 영역에 모여 작품 구조를 계속 확인할 수 있다.
- 문서가 많아지면 트리의 세로 밀도와 탐색 비용이 급격히 커질 수 있다.
- 작은 아이콘 중심 탐색은 신규 사용자의 기능 발견성을 낮출 수 있다.
