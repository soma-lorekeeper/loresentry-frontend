# 펜시브 플롯보드와 타임라인

## 페이지 목적과 흐름

- 목적: 이야기의 순서, 단계와 진행 상태를 원고 목록과 다른 관점에서 조망한다.
- 진입: 프로젝트 탐색, 폴더 보기 전환 또는 플롯보드 파일.
- 다음 이동: 선택한 장면·회차 문서 또는 관련 설정.

## 핵심 인터랙션

- 동일한 폴더 데이터를 그리드, 리스트, 보드와 타임라인으로 전환한다.
- 타임라인은 상태별 가로 레일에 회차 카드를 배치한다.
- 카드에서 제목, 요약과 상태를 확인하고 해당 원고로 이동한다.
- 색상과 상태 텍스트를 함께 사용해 상태 의미를 보완한다.

## PC 화면 활용

- 넓은 가로 공간을 시간 축과 여러 상태 레일에 사용한다.
- 개별 원고보다 작품 전체의 배열과 빠진 구간을 파악하는 데 초점을 둔다.
- 같은 데이터를 다른 보기로 전환해 사용자의 현재 과업에 맞는 밀도를 제공한다.

## 장점과 마찰

| 장점 | 마찰 가능성 |
| --- | --- |
| 원고 순서와 상태를 한 화면에서 비교한다. | 보기 방식이 많으면 각각의 차이를 학습해야 한다. |
| 목록 데이터를 다시 입력하지 않고 시각화한다. | 카드가 많아지면 가로·세로 탐색이 복잡해진다. |
| 카드에서 원고로 바로 이동할 수 있다. | 색상 의존 상태는 접근성 문제가 생길 수 있다. |
