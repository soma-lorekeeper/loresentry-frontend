# 펜시브 로그인

## 페이지 목적과 흐름

- 목적: 기존 사용자가 인증 수단을 선택하고 앱으로 진입하게 한다.
- 진입: 펜시브 웹 앱 접속.
- 다음 이동: 인증 성공 후 전체 프로젝트 화면.

## 주요 사용자 행동

1. Google, Apple 또는 이메일 인증 중 하나를 선택한다.
2. 약관을 확인하거나 인증을 진행한다.
3. 인증이 끝나면 프로젝트 목록으로 이동한다.

## 화면 구성과 UI

| 영역 | 관찰 | UX 효과 |
| --- | --- | --- |
| 전체 배경 | 거의 단색인 어두운 화면 | 인증 영역으로 시선을 집중시킨다. |
| 브랜드 | 중앙 상단의 세리프 워드마크 | 차분하고 문학적인 인상을 준다. |
| 인증 영역 | 같은 폭의 버튼을 세로로 배치 | 선택지를 빠르게 비교할 수 있다. |
| 보조 정보 | 약관과 버전을 낮은 위계로 분리 | 핵심 행동을 방해하지 않는다. |

정보 밀도가 매우 낮아 기존 사용자의 빠른 진입에는 유리하다. 반면 처음 방문한 사용자는 로그인 화면만으로 제품 효용을 이해하기 어렵고 별도 랜딩 설명에 의존한다.
