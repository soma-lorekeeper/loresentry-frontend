# 펜시브 시트와 설정

## 페이지 목적과 흐름

- 목적: 인물, 장소, 사건과 아이템처럼 반복해서 참조할 정보를 구조화한다.
- 진입: 파일 트리, 검색, 다른 문서의 연결 정보 또는 새 파일 생성.
- 다음 이동: 연결된 원고, 관계 그래프, 캔버스 또는 다른 시트.

## 핵심 UX

- 자유 서술 문서와 구조화된 설정 시트를 서로 다른 생각의 역할로 구분한다.
- 설정을 독립 파일로 관리하면서 원고와 연결한다.
- 파일 헤더에서 상태, 태그와 연결 정보를 함께 확인한다.
- 동일한 탭·패널 계층을 사용해 문서와 설정을 오갈 때 조작 방식을 다시 배우지 않게 한다.

## 기대 효과와 위험

| 기대 효과 | 위험 |
| --- | --- |
| 인물과 세계관 정보의 형식이 일정해진다. | 시트 필드가 많으면 입력 부담이 커진다. |
| 설정을 여러 원고에서 재사용할 수 있다. | 문서와 시트의 차이가 불명확하면 생성 시 망설인다. |
| 원고와 설정의 연결 관계를 추적할 수 있다. | 구조가 고정되면 장르별 차이를 수용하기 어렵다. |
