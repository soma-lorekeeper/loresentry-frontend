# 제품 사용 분석 확대

[English](README.md)

상태: 2026-11-03 작업 트리에 애플리케이션 계측을 구현했다. 배포와 운영 GA 수신은 아직 검증하지 않았다. 최초 조사는 프런트엔드 커밋 `ec2efd98a0de365d465c105bbfd7576e85415b33`을 기준으로 했다. 구현 범위, GA 정의와 검증 결과는 [구현 결과](implementation-results.ko.md)를 참고한다.

## 목적

서비스의 의미 있는 사용자 행동과 관찰된 결과 전반으로 측정을 넓힌다. 기존 가입·최신화 퍼널 밖의 기능도 포함해 탐색적 분석에 필요한 폭을 확보한다. 기능 열기, 작업 시도, 결과 수신, 결과 활용을 구분한다.

원고 준비, 작성·저장, 검색, 관계도·타임라인, AI 챗, 설정 오류 점검, 메모, 버전, 내보내기, 프로젝트·계정 관리, 도움말·피드백을 제안 범위에 포함한다. 빈번한 편집과 카메라 이동은 브라우저 이벤트마다 전송하지 않고 요약하거나 제외한다.

## 기존 계약의 기준 유지

- [유입·온보딩](../acquisition-onboarding/acquisition-events.ko.md)
- [첫 핵심 가치](../first-core-value/core-value-events.ko.md)
- [설정 문서 최신화](../refresh/refresh-events.ko.md)

기존 이벤트를 유지한다. 추가 이벤트 문서에서 중복 관계와 추가 항목을 명시한다. `project_created`의 이름을 바꾸거나, `sign_up`을 약관 동의 완료로 바꾸거나, `manuscript_saved`를 첫 저장 또는 본문만 바뀐 저장으로 재해석하지 않는다.

P0는 첫 구현 묶음, P1은 이후 범위 확대, P2는 초기 보고서의 유용성을 확인한 뒤 넣을 선택적 상세다. 제안 우선순위이며, 일정 약속이나 배포 증거가 아니다. 최초 조사는 문서만 추가했다. 이후 구현은 implementation-results에 별도로 기록하며, 비교를 위해 당시 기준 상태와 제안 카탈로그를 보존한다.
