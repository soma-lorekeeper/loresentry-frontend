# 프론트엔드 문서 안내

> **책임:** 프론트 구현에 필요한 문서와 담당 범위를 안내한다.
>
> **확인할 때:** 구현·검증할 기능의 기준 문서를 찾을 때.

| 필요한 작업            | 기준 문서                                                                              | 담당 범위                                  |
| ---------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------ |
| 브라우저 QA 수행       | [QA 유스케이스](qa/README.md)                                                          | 실행 환경·기준 데이터·절차·기대 결과·판정  |
| QA 범위·누락 확인      | [기능 대응표](qa/coverage.md)                                                          | 경로·화면·서비스·사용자 동작·요구사항 공백 |
| QA 실행 조건 선택      | [실행 프로필](qa/execution.json) · [사용 방법](qa/README.md#실행-프로필)               | 도구·환경·계정 참조·로그인·미결정          |
| 세부 동작·상태 검증    | [추가 케이스](qa/extended-cases.md)                                                    | 도구·필터·입력·조회/변경 상태별 검증       |
| 공통 QA 수행 방식      | [QA 기능](../../../../agent-hub/capabilities/qa/AGENTS.md)                             | 범위 작성·실행·기록·실패 처리·보고         |
| 약관 동의 화면 구현    | [약관 동의 설계](auth/TERMS_CONSENT_DESIGN.md)                                         | 로그인 분기·모달·캐시 처리·검증            |
| BFF 호출 구현          | [호출 API](API_CALLS.md)                                                               | 호출 시점·입력 구성·응답 검증·오류 변환    |
| 브라우저 API 규격 확인 | [BFF 제공 API](../../loresentry-gateway/docs/API.md#약관-동의-api)                     | 요청·응답·오류 코드                        |
| 인증 연동 규칙 확인    | [BFF 프론트 계약](../../loresentry-gateway/docs/FRONTEND_AUTH_CONTRACT.md)             | 쿠키 기반 인증·동의 UI 계약·인증 전환      |
| 서버 동의 처리 확인    | [Auth 동의 설계](../../loresentry-authentication/docs/account/TERMS_CONSENT_DESIGN.md) | 원문·버전·동의 기록·대기 수명·세션 발급    |

프론트 문서는 화면과 프론트 코드의 구현 방법을 관리한다. 서버 API와 저장 규칙은 해당
서버 문서를 참조한다. 실행·검증 명령과 공통 프로젝트 문서는 [프로젝트 README](../README.md)를 따른다.
