# LOREKEEPER-594 만료와 초안 보존

2026-09-26 세션 무효·전환 시 보호 요청과 자동 저장을 멈추되 열린 문서를 유지한다.
새 탭에서 재로그인한 뒤 서버 계정을 확인하고 같은 계정의 작업만 재개한다.
일시 장애는 로그아웃으로 단정하지 않는다. 로그인 유지를 위한 heartbeat는 추가하지 않았다.

사용자·문서별 복구 사본은 초안과 원래 기준 내용·revision을 보관한다. 복구 직후 저장은
수동으로 시작한다. 네트워크 결과 불명 뒤 동일 내용의 재시도는 같은 X-Save-Id를 유지한다.
브라우저 저장소가 막혀도 메모리 초안과 종료 경고를 유지하며 내려받기를 제공한다.
동작과 제한은 [세션 인증 안내](../SESSION_AUTH.md)를 따른다.

단위·컴포넌트 테스트 240개가 통과했다. 세션 무효·일시 장애·응답 유실에서 자동 재전송
없이 초안 보존, 계정별 복구 분리, 원래 revision과 멱등 키 유지, 14일 동안 heartbeat
미발생 및 서버 거절 후 요청 차단을 확인했다. 열린 편집기의 동일 계정 복귀와 다른 계정
차단도 확인했다. 실제 14일 TTL 경계는 Auth/BFF 통합 Work 595의 검증 범위다.

포맷·토큰 생성 일치·린트·타입 검사, Next 정적 빌드와 static export 검증을 통과했다.
제한된 네트워크 환경의 최초 webpack 빌드가 실패한 뒤 네트워크가 허용된 동일 소스로
빌드했다. Next Google font 다운로드를 사용하는 기존 레이아웃은 변경하지 않았다.
