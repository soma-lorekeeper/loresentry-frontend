# LOREKEEPER-592 세션 API 연결

2026-09-26 실제 API 모드의 인증·계정 포트를 BFF에 연결했다. 요청은 credentials:
include를 사용하고 변경 요청에 CSRF 헤더를 넣는다. 개발 사용자 헤더는 제거했다.
로그인 성공 안내 뒤 서버 계정을 조회하며, 세션 무효와 일시 장애를 구분한다.
로그아웃의 네 가지 폐기 결과를 보존하고 미확인을 성공으로 표시하지 않는다.

런타임 설정이 초기 mock 서비스에 고정되던 문제도 수정했다. 설정 로딩 뒤에 서비스를
생성하고 API 모드 선택과 검증된 복귀 경로만 탭 저장소에 보관한다. 세션 ID는 읽거나
저장하지 않는다. 실제 인증 전환·탭 조율과 미저장 작업 보호는 다음 Atomic 범위다.

API·컴포넌트 테스트를 포함한 231개 테스트와 TypeScript 검사가 통과했다.
로그인 성공·취소·무효·일시 장애, 폐기 미확인, 요청 재전송 부재를 확인했다.
Content 조건부 저장·멱등 키·충돌·검색 인코딩 회귀를 유지했다.
