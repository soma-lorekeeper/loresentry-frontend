# 계정 설정과 전역 진입

프로젝트 목록의 전역 사이드바에서 계정 정보를 관리하고 사용 가이드와 피드백에
진입한다. 프로젝트 데이터와 현재 작업공간 설정은 변경하지 않는다.

## 사용자 정보와 메뉴

- 사이드바 상단에 사용자 이름과 Google 계정 이메일을 표시한다.
- 이름이나 이메일이 한 줄을 넘으면 말줄임하고 전체 값은 접근 가능한 이름으로 제공한다.
- 사용자 정보를 선택하면 바로 아래에 `계정 설정`과 `로그아웃`을 포함한 메뉴를 연다.
- `계정 설정`과 `로그아웃`은 아이콘과 텍스트로 구분하며 로그아웃은 마지막 항목에 둔다.
- `Esc`, 메뉴 밖 선택 또는 사용자 정보 재선택은 메뉴를 닫고 사용자 정보로 포커스를 돌린다.
- 메뉴가 열린 동안 프로젝트 목록과 다른 전역 사이드바 행동은 그대로 유지한다.

## 계정 설정

`계정 설정`은 현재 프로젝트 목록 또는 프로젝트 휴지통 위에 대화상자로 연다. 별도
Route로 이동하지 않으며 닫으면 기존 목록과 스크롤 위치를 유지한다.

| 항목 | 표시와 편집 | 규칙 |
| --- | --- | --- |
| 이름 | 한 줄 입력으로 표시하고 편집을 허용한다. | 필수이며 앞뒤 공백을 제거한 뒤 빈 값이면 저장하지 않는다. |
| 이메일 | `Google 계정 이메일`로 표시하고 읽기 전용으로 제공한다. | 인증 계정 식별자이므로 초기 범위에서 변경하지 않는다. |

- 처음 열면 현재 이름과 이메일을 표시하고 `저장`을 비활성화한다.
- 앞뒤 공백을 제거한 이름이 저장된 이름과 같으면 `저장`을 비활성화한다.
- 이름이 비어 있으면 입력과 연결된 `이름을 입력해 주세요.`를 표시한다.
- `취소` 또는 `Esc`는 변경을 저장하지 않고 대화상자를 닫은 뒤 사용자 메뉴의 `계정 설정`으로 포커스를 돌린다.
- 저장 중에는 이름 입력, 닫기, 취소와 저장 행동을 잠그고 `저장 중…`을 표시한다.
- 저장에 성공하면 사이드바와 사용자 메뉴의 이름을 갱신하고 `계정 정보를 저장했어요.`를 표시한다.
- 저장 완료 후 포커스는 대화상자의 `닫기`로 옮긴다. 닫으면 사이드바의 사용자 정보로 돌아간다.
- 저장에 실패하면 입력값을 유지하고 `계정 정보를 저장하지 못했어요. 다시 시도해 주세요.`와 `다시 시도`를 제공한다.
- 이메일 변경, 비밀번호, 연결된 Google 계정 변경과 회원 탈퇴는 초기 범위에 포함하지 않는다.

## 로그아웃

```text
사용자 메뉴
→ 로그아웃
→ 계정과 결과를 확인
├─ 취소 또는 Esc → 사용자 메뉴의 로그아웃
└─ 로그아웃 → 처리 중
   ├─ 성공 → 세션 종료 → /login
   └─ 실패 → 현재 페이지와 대화상자 유지 → 다시 시도 또는 취소
```

- 확인 대화상자에 사용자 이름과 이메일, 로그아웃 후 로그인 화면으로 이동한다는 결과를 표시한다.
- 기본 포커스는 `취소`에 두고 대화상자가 열린 동안 포커스를 내부에 가둔다.
- 처리 중에는 닫기, 취소와 확인 행동을 잠그고 `로그아웃 중…`을 표시한다.
- 실패하면 현재 프로젝트 목록 또는 휴지통과 사용자 정보를 유지한다.
- 성공하면 인증이 필요한 이전 화면으로 자동 복귀하지 않고 로그인 화면으로 이동한다.

## 사용 가이드

```text
전역 사이드바
→ 사용 가이드
→ 프로젝트 목록 셸의 가이드 화면
→ 프로젝트 목록으로 돌아가기
```

- 사용 가이드는 Lorekeeper 내부 화면으로 열고 전역 사이드바를 유지한다.
- 가이드 화면에서는 `사용 가이드`를 현재 위치로 표시하고 프로젝트 목록과 프로젝트 휴지통은 기본 상태로 표시한다.
- `프로젝트 목록으로 돌아가기`는 `/projects`로 이동하고 사이드바의 `프로젝트 목록`으로 포커스를 옮긴다.
- 가이드 주제, 검색, 빈 결과와 불러오기 오류는 [작업공간 도움말](../workspace/help.md)의 사용 가이드 계약을 공유한다.
- 프로젝트 목록 셸에서는 프로젝트 식별자나 작업공간 탭 상태를 요구하지 않는다.

## 피드백 보내기

- `피드백 보내기`에는 외부 이동 아이콘과 `새 탭에서 열림` 접근 가능한 이름을 제공한다.
- 선택하면 브라우저 새 탭에서 외부 피드백 폼을 열고 현재 Lorekeeper 화면을 유지한다.
- 외부 폼에는 로그인한 계정과 프로젝트 식별자를 전달하지 않는다.
- 새 탭을 열면 `피드백 페이지를 새 탭에서 열었습니다.`를 알리고 사이드바의 `피드백 보내기`로 포커스를 돌린다.
- 새 탭을 열지 못하면 현재 화면에 `피드백 페이지를 열지 못했어요.`와 `다시 열기`, `링크 복사`를 제공한다.
- 실패 상태에서 프로젝트 목록, 프로젝트 휴지통 또는 계정 설정의 사용자 문맥을 바꾸지 않는다.

## 전역 사이드바 상태

| 상태 | 선택 또는 포커스 | 잠금 범위 |
| --- | --- | --- |
| 사용자 메뉴 열림 | 사용자 정보와 열린 메뉴 | 없음 |
| 계정 설정 열림 | 대화상자 내부, 시작은 이름 입력 | 배경의 사이드바와 목록 행동 |
| 계정 저장 중 | `저장 중…` | 계정 설정의 입력과 모든 행동 |
| 로그아웃 확인 | 대화상자 내부, 시작은 `취소` | 배경의 사이드바와 목록 행동 |
| 로그아웃 중 | `로그아웃 중…` | 확인 대화상자의 모든 행동 |
| 사용 가이드 | `사용 가이드` 현재 위치 | 없음 |
| 피드백 외부 이동 | `피드백 보내기` 복귀 포커스 | 없음 |

프로젝트별 이름과 설명은 [작업공간 프로젝트 설정](../workspace/settings.md), 인증은
[Google OAuth 인증 Workflow](../workflow/authentication.md)를 따른다.
