# 프로젝트 휴지통

휴지통으로 이동한 프로젝트를 복원하거나 영구 삭제한다.

## Route

```text
/projects/trash
```

## 사이드바

- 프로젝트 목록과 같은 전역 사이드바를 사용한다.
- `프로젝트 휴지통`을 현재 위치로 표시하고 `프로젝트 목록`은 기본 상태로 표시한다.
- `프로젝트 목록`을 선택하면 `/projects`로 이동한다.
- 기본·빈 상태·로딩·오류와 작업 결과 상태에서 사이드바의 폭과 위치를 유지한다.

## 프로젝트 표시

- 휴지통으로 이동한 프로젝트만 표시한다.
- 프로젝트마다 `복원`과 `영구 삭제`를 제공한다.
- 프로젝트 제목, 휴지통으로 이동한 일시와 보관 중 상태를 표시한다.
- 최근 휴지통으로 이동한 프로젝트가 먼저 오도록 정렬한다.
- 자동 삭제 기한은 초기 범위에 포함하지 않는다.

### 목록 항목 계약

| 요소 | 표시 규칙 | 행동 |
| --- | --- | --- |
| 프로젝트 제목 | 항목의 주 정보로 한 줄만 표시하고 넘치는 값은 말줄임한다. | 행동을 제공하지 않는다. |
| 이동 일시 | `휴지통으로 이동: <날짜>` 형식의 보조 정보로 표시한다. | 행동을 제공하지 않는다. |
| 상태 | `보관 중`을 텍스트와 아이콘으로 함께 표시한다. | 행동을 제공하지 않는다. |
| 복원 | 항목의 주 행동으로 제공한다. | 복원 요청을 시작한다. |
| 영구 삭제 | 복원보다 낮은 시각 우선순위의 파괴적 행동으로 제공한다. | 영구 삭제 확인 대화상자를 연다. |

- 목록 항목의 프로젝트 정보는 선택 영역으로 사용하지 않는다. 휴지통에 있는 프로젝트는 작업공간에 진입할 수 없다.
- `복원`과 `영구 삭제`는 각각 키보드 포커스를 받고, 색상 변화 외에 외곽선으로 포커스를 구분한다.
- 하나의 프로젝트를 처리하는 동안 해당 항목의 두 행동만 잠그고 다른 항목은 유지한다.

## 화면 상태 매트릭스

| 상태 | 진입 조건 | 본문 | 핵심 행동 | 유지 요소 |
| --- | --- | --- | --- | --- |
| 기본 | 조회가 성공하고 하나 이상의 프로젝트가 있다. | 휴지통 프로젝트 목록 | 프로젝트 복원 또는 영구 삭제 | 전역 사이드바와 `프로젝트 휴지통` 선택 상태 |
| 빈 상태 | 조회가 성공하고 목록이 비어 있다. | 보관된 프로젝트가 없다는 안내 | `프로젝트 목록으로 돌아가기` | 전역 사이드바와 `프로젝트 휴지통` 선택 상태 |
| 로딩 | 조회가 진행 중이다. | 실제 항목과 같은 높이의 목록 스켈레톤 | 없음 | 전역 사이드바와 `프로젝트 휴지통` 선택 상태 |
| 오류 | 조회가 실패했다. | 목록을 불러오지 못했다는 안내 | `다시 시도` | 전역 사이드바와 `프로젝트 휴지통` 선택 상태 |
| 복원 중 | 항목의 복원 요청이 진행 중이다. | 대상 항목에 `복원 중…`을 표시하고 행동을 잠근 목록 | 없음 | 대상과 나머지 목록 순서 |
| 복원 실패 | 복원 요청이 실패했다. | 대상 항목에 오류 안내와 원래 행동을 표시한 목록 | `다시 시도` | 대상과 나머지 목록 순서 |
| 복원 성공 | 복원 요청이 성공했다. | 대상이 제거된 목록과 성공 안내 | `프로젝트 목록에서 보기` | 남아 있는 항목 순서 |
| 영구 삭제 확인 | 항목의 영구 삭제를 선택했다. | 목록 위에 대상과 복구 불가 영향을 표시한 대화상자 | `영구 삭제` 또는 취소 | 배경 목록과 대상 항목 |
| 영구 삭제 중 | 확인 후 요청이 진행 중이다. | 닫기와 행동이 잠긴 대화상자 및 `삭제 중…` | 없음 | 배경 목록과 대상 항목 |
| 영구 삭제 실패 | 요청이 실패했다. | 대상을 유지한 대화상자와 오류 안내 | `다시 시도` 또는 취소 | 배경 목록과 대상 항목 |
| 영구 삭제 성공 | 요청이 성공했다. | 대상이 제거된 목록과 성공 안내 | 남은 항목의 행동 또는 목록 복귀 | 남아 있는 항목 순서 |

- 로딩 상태는 목록 항목의 높이와 간격을 기본 상태와 같게 유지한다.
- 오류 원인을 확정할 수 없으면 추측하지 않고 재시도 가능 여부만 안내한다.
- 복원 또는 영구 삭제 후 남은 항목이 없으면 성공 안내와 빈 상태를 함께 표시한다.
- 성공 안내는 다음 행동을 제공하되, 사용자가 선택하기 전까지 현재 휴지통 화면을 유지한다.

## 복원

- `복원`을 선택하면 별도 확인 없이 즉시 요청한다.
- 처리 중에는 대상 항목에 `복원 중…`을 표시하고 같은 프로젝트의 행동을 잠가 중복 요청을 막는다.
- 실패하면 프로젝트와 목록 순서를 유지하고 `프로젝트를 복원하지 못했어요. 다시 시도해 주세요.`와 `다시 시도`를 제공한다.
- 성공하면 프로젝트를 휴지통 목록에서 제거하고 `프로젝트를 복원했어요.`를 표시한다.
- 성공 안내의 `프로젝트 목록에서 보기`는 `/projects`로 이동하고 복원된 프로젝트 카드로 포커스를 옮긴다.
- 휴지통에 남아 있으면 포커스를 다음 항목의 `복원`으로 옮긴다. 다음 항목이 없으면 빈 상태의 `프로젝트 목록으로 돌아가기`로 옮긴다.

## 영구 삭제

- 삭제할 프로젝트 이름을 명확하게 표시한다.
- 프로젝트의 파일과 설정이 함께 삭제되며 되돌릴 수 없음을 안내한다.
- 확인 대화상자의 기본 포커스는 `취소`에 두고 포커스를 대화상자 안에 가둔다.
- `취소` 또는 `Esc`는 삭제하지 않고 대상 항목의 `영구 삭제`로 포커스를 돌린다.
- `영구 삭제`를 선택하면 닫기와 모든 대화상자 행동을 잠그고 `삭제 중…`을 표시한다.
- 실패하면 대화상자와 대상을 유지하고 `프로젝트를 영구 삭제하지 못했어요. 다시 시도해 주세요.`와 `다시 시도`를 제공한다.
- 성공하면 대화상자를 닫고 프로젝트를 휴지통 목록에서 제거하며 `프로젝트를 영구 삭제했어요.`를 표시한다.
- 성공 후 휴지통에 남아 있으면 포커스를 다음 항목의 `복원`으로 옮긴다. 다음 항목이 없으면 빈 상태의 `프로젝트 목록으로 돌아가기`로 옮긴다.

페이지 간 이동은 [프로젝트 휴지통 Workflow](../workflow/project-trash.md)를 따른다.
