# 프로젝트 휴지통

휴지통으로 이동한 프로젝트를 복원하거나 영구 삭제한다.

## 프로젝트 표시

- 휴지통으로 이동한 프로젝트만 표시한다.
- 프로젝트마다 `복원`과 `영구 삭제`를 제공한다.
- 자동 삭제 기한은 초기 범위에 포함하지 않는다.

## 복원

프로젝트를 프로젝트 목록으로 되돌린다.

## 영구 삭제

- 삭제할 프로젝트 이름을 명확하게 표시한다.
- 영구 삭제는 되돌릴 수 없음을 안내한다.
- 사용자의 확인을 받은 뒤 영구 삭제한다.

페이지 간 이동은 [프로젝트 휴지통 Workflow](../workflow/project-trash.md)를 따른다.
