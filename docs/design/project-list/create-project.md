# 프로젝트 생성

프로젝트 목록 안에서 한 번의 입력 단계로 새 프로젝트를 만든다.

## 입력

- 프로젝트 제목만 필수로 입력한다.
- 설명, 장르, 구조 템플릿과 표지는 초기 생성 단계에서 입력하지 않는다.

### 프로젝트 제목 계약

| 조건 | 처리 | 피드백 |
| --- | --- | --- |
| 입력하지 않았거나 공백만 입력 | 제출하지 않는다. | `프로젝트 제목을 입력해 주세요.`를 입력과 연결해 표시한다. |
| 1~255자 | 제출할 수 있다. | 입력 오른쪽 아래에 현재 글자 수와 `255`자 한도를 표시한다. |
| 255자 초과 | 제출하지 않는다. | `프로젝트 제목은 255자 이하여야 해요.`를 표시한다. |
| 같은 사용자의 기존 프로젝트 제목과 중복 | 서버 응답 후 제출 상태를 해제한다. | `같은 제목의 프로젝트가 이미 있어요.`를 표시하고 입력값을 유지한다. |

- 검증과 제출 전에 입력 앞뒤의 공백을 제거한다. 단어 사이의 공백은 유지한다.
- 필수·길이 오류는 입력을 벗어나거나 제출을 시도할 때 표시한다.
- 중복 여부는 서버 응답으로 확정하며, 중복 오류도 제목 입력에 연결한다.
- 오류가 있는 동안 `프로젝트 만들기`를 비활성화한다.

## 행동

- `취소`: 프로젝트를 만들지 않고 프로젝트 목록으로 돌아간다.
- `프로젝트 만들기`: 프로젝트를 생성하고 통합 작업공간으로 이동한다.

## 상태

| 상태 | 입력 | 행동 | 결과 |
| --- | --- | --- | --- |
| 초기 | 빈 입력에 포커스를 둔다. | `취소` 가능, `프로젝트 만들기` 비활성 | 프로젝트 목록 문맥을 유지한다. |
| 입력 가능 | 유효한 제목을 표시한다. | 취소와 제출 가능 | 제출 전까지 프로젝트를 만들지 않는다. |
| 유효성 오류 | 입력과 오류 메시지를 함께 표시한다. | 제출 불가 | 사용자가 수정한 값은 유지한다. |
| 생성 중 | 입력을 읽기 전용으로 유지한다. | `프로젝트 만드는 중…`을 표시하고 모든 행동을 잠근다. | 중복 요청을 보내지 않는다. |
| 생성 실패 | 마지막 입력과 오류를 표시한다. | 취소 또는 `다시 시도` 가능 | 프로젝트 목록과 입력값을 유지한다. |
| 생성 완료 | 새 프로젝트 ID를 수신한다. | 추가 입력 없음 | 발급된 ID의 통합 작업공간 시작 안내로 이동한다. |

- `Esc`와 `취소`는 요청을 보내지 않고 프로젝트 목록의 새 프로젝트 행동으로 포커스를 돌린다.
- 알 수 없는 서버 오류는 원인을 추측하지 않고 `프로젝트를 만들지 못했어요. 다시 시도해 주세요.`로 안내한다.
- 생성 완료 응답에 유효한 프로젝트 ID가 없으면 이동하지 않고 생성 실패 상태로 처리한다.

페이지 간 이동은 [프로젝트 생성 Workflow](../workflow/project-creation.md)를 따른다.
