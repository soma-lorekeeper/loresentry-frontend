# 프로젝트 목록 디자인 시스템 감사

프로젝트 목록 관련 화면은 `docs/design/lorekeeper.lib.pen`을 디자인 변수와 재사용
컴포넌트의 단일 원본으로 사용한다. `docs/design/lorekeeper.pen`에는 화면 구성만
유지하며, 변수와 재사용 컴포넌트는 `b` 별칭으로 가져온 항목만 참조한다.

## 감사 범위

- 프로젝트 목록과 생성·카드 관리 화면 `91`~`110`
- 프로젝트 휴지통 화면 `111`~`122`
- 계정 설정과 전역 진입 화면 `123`~`138`
- `docs/design/lorekeeper.pen`의 변수, 재사용 컴포넌트, 인스턴스와 placeholder
- `docs/design/lorekeeper.lib.pen`의 변수, 최상위 컴포넌트와 내부 인스턴스

hover·focus·disabled 상태, 프로젝트 카드의 기본·hover·focus·selected 상태,
프로젝트 카드 메뉴, 설정 필드와 저장 상태, 공통 버튼과 아이콘 버튼을 라이브러리
컴포넌트로 조합한다. 화면별 제목, 설명, 대화상자 문맥과 상태 설명은 메인 디자인의
화면 구성으로 유지한다.

변수를 사용한다.

## 구현 규칙

- 화면 구현은 [`component-library.md`](../component-library.md)의 변수 이름과
  컴포넌트 경계를 기준으로 한다.
- 색상, 간격, 반경, 타이포그래피와 아이콘 굵기를 화면별 상수로 복제하지 않는다.
- 화면 상태를 추가할 때 기존 라이브러리 컴포넌트의 인스턴스 속성으로 표현할 수
  있는지 먼저 확인한다.
- 새 반복 UI가 여러 화면에서 같은 구조와 역할을 가지면 라이브러리 컴포넌트로
  추가하고 메인 디자인에서는 `b:` 참조로 사용한다.
- 감사 수치는 2026-09-01의 `LOREKEEPER-401` 검증 결과다. 디자인 구조를 변경하면
  같은 항목을 다시 조회해 문서와 실제 파일을 함께 갱신한다.
