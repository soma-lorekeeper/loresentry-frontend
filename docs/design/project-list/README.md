# 프로젝트 목록

## 역할

- 인증을 완료한 사용자의 앱 시작점이다.
- 사용자가 기존 프로젝트를 선택하거나 새 프로젝트를 만든다.

## Route

```text
/projects
```

## 사이드바

프로젝트 목록에서는 전역 기능을 제공하는 사이드바를 사용한다.

```text
사용자 정보
├─ 계정 설정
└─ 로그아웃

프로젝트 목록
프로젝트 휴지통

사용 가이드
피드백 보내기
```

- Lorekeeper 로고와 사이트명은 표시하지 않는다.
- 사용자 정보는 사이드바 상단에 표시한다.
- `새 프로젝트`는 사이드바가 아닌 프로젝트 목록 본문에서 핵심 행동으로 제공한다.
- `내 작업공간`은 `프로젝트 목록`과 역할이 겹치므로 별도로 제공하지 않는다.
- 컬렉션과 커뮤니티는 해당 기능이 생기기 전까지 제공하지 않는다.
- 변경 내역은 별도 사이드바 항목으로 두지 않고 사용 가이드 안에서 제공한다.
- 프로젝트에 진입하면 같은 위치의 사이드바가 프로젝트 콘텐츠 탐색용으로 전환된다.

## 프로젝트 표시

- 프로젝트는 카드 그리드로 표시한다.
- `새 프로젝트` 카드를 첫 위치에 고정한다.
- 기존 프로젝트는 마지막 작업 일시가 가까운 순서로 정렬한다.
- 프로젝트 카드에는 제목, 마지막 작업 일시와 마지막으로 작업한 파일을 표시한다.
- 프로젝트 카드 전체를 선택 영역으로 사용한다.
- 카드의 더보기 메뉴에는 이름 변경과 휴지통 이동을 제공한다.

### 카드 계약

| 요소 | 표시 규칙 | 행동 |
| --- | --- | --- |
| 새 프로젝트 카드 | 그리드의 첫 위치에 고정하고 다른 카드와 같은 크기를 사용한다. | 카드 전체를 선택하면 프로젝트 생성 흐름으로 이동한다. |
| 프로젝트 제목 | 카드의 주 정보로 한 줄만 표시하고 넘치는 값은 말줄임한다. | 카드 선택 영역에 포함한다. |
| 마지막 작업 일시 | 제목 아래에 상대 시각 또는 날짜를 보조 정보로 표시한다. | 행동을 제공하지 않는다. |
| 마지막 파일 | 파일 이름을 한 줄로 표시하고 넘치는 값은 말줄임한다. 값이 없으면 `최근 작업한 파일 없음`을 표시한다. | 행동을 제공하지 않는다. |
| 더보기 | 카드 우측 상단의 독립된 버튼으로 제공한다. | 선택하면 이름 변경과 휴지통 이동 메뉴를 연다. 카드 진입 동작은 발생시키지 않는다. |

- 카드 순서는 서버가 제공한 마지막 작업 일시의 내림차순을 사용한다.
- 같은 시각인 카드는 제목 오름차순으로 순서를 안정화한다.
- 카드 전체와 더보기 버튼은 각각 키보드 포커스를 받을 수 있어야 한다.
- 포커스 표시와 선택 상태는 색상 변화 외에 외곽선 또는 테두리로 구분한다.
- 프로젝트 카드를 선택하면 프로젝트 ID가 유효한 경우에만 통합 작업공간으로 이동한다.
- 새 프로젝트는 생성 완료 후 발급된 프로젝트 ID로 통합 작업공간의 시작 안내 화면에 이동한다.

## 화면 상태 매트릭스

| 상태 | 진입 조건 | 본문 | 핵심 행동 | 유지 요소 |
| --- | --- | --- | --- | --- |
| 기본 | 프로젝트 조회가 성공하고 하나 이상의 프로젝트가 있다. | 새 프로젝트 카드와 최근 작업순 프로젝트 카드 그리드 | 프로젝트 선택 또는 새 프로젝트 만들기 | 전역 사이드바와 `프로젝트 목록` 선택 상태 |
| 빈 상태 | 프로젝트 조회가 성공하고 목록이 비어 있다. | 첫 프로젝트 생성의 목적을 설명하는 빈 상태 | `첫 프로젝트 만들기` | 전역 사이드바와 `프로젝트 목록` 선택 상태 |
| 로딩 | 프로젝트 조회가 진행 중이다. | 실제 카드와 같은 크기의 새 프로젝트 카드 및 카드 스켈레톤 | 없음 | 전역 사이드바와 `프로젝트 목록` 선택 상태 |
| 오류 | 프로젝트 조회가 실패했다. | 목록을 불러오지 못했다는 안내와 재시도 가능 상태 | `다시 시도` | 전역 사이드바와 `프로젝트 목록` 선택 상태 |
| 카드 메뉴 열림 | 기본 상태에서 프로젝트 카드의 더보기를 선택했다. | 기본 화면 위에 해당 카드의 이름 변경·휴지통 이동 메뉴 | 메뉴 항목 선택 또는 닫기 | 나머지 프로젝트 목록과 전역 사이드바 |

- 로딩 상태는 카드 그리드의 열·간격·높이를 기본 상태와 같게 유지해 화면 이동을 줄인다.
- 오류 안내는 원인을 확정할 수 없을 때 추측하지 않고 다시 시도할 수 있다는 정보만 제공한다.
- 재시도 중에는 오류 행동을 비활성화하고 로딩 상태로 전환한다.
- 빈 상태와 오류 상태는 동시에 표시하지 않는다.

## 빈 상태

프로젝트가 없으면 `첫 프로젝트 만들기`를 핵심 행동으로 안내한다.

## 카드 관리 계약

### 이름 변경

- 카드 더보기의 `이름 변경`을 선택하면 현재 제목을 선택한 단일 입력 대화상자를 연다.
- 제목은 프로젝트 생성과 같은 필수·공백·255자·중복 규칙을 사용한다.
- 앞뒤 공백을 제거한 값이 현재 제목과 같으면 `저장`을 비활성화한다.
- `취소` 또는 `Esc`는 변경하지 않고 대화상자를 닫은 뒤 해당 카드의 더보기 버튼으로 포커스를 돌린다.
- 저장 중에는 입력과 닫기 행동을 잠그고 `저장 중…`을 표시한다.
- 저장에 실패하면 변경 입력을 유지하고 입력과 연결된 오류 및 `다시 시도`를 제공한다.
- 저장에 성공하면 대화상자를 닫고 카드 제목을 새 값으로 갱신한다. 포커스는 갱신된 카드의 더보기 버튼으로 돌린다.

### 휴지통으로 이동

- 카드 더보기의 `휴지통으로 이동`을 선택하면 프로젝트 제목을 포함한 확인 대화상자를 연다.
- 대화상자는 프로젝트가 목록과 작업공간에서 제거되지만 휴지통에서 복원할 수 있음을 안내한다.
- 기본 포커스는 `취소`에 두고, 포커스를 대화상자 안에 가둔다.
- `취소` 또는 `Esc`는 이동하지 않고 해당 카드의 `휴지통으로 이동` 행동으로 포커스를 돌린다.
- 이동 중에는 닫기와 모든 행동을 잠그고 `이동 중…`을 표시해 중복 요청을 막는다.
- 이동에 실패하면 대화상자와 목록을 유지하고 `프로젝트를 이동하지 못했어요. 다시 시도해 주세요.`를 표시한다.
- 이동에 성공하면 대화상자를 닫고 프로젝트를 목록에서 제거한다. `휴지통에서 복원할 수 있어요.` 안내를 표시한다.

## 전역 사이드바 계약

- 사용자 정보, 프로젝트 목록, 프로젝트 휴지통, 사용 가이드와 피드백 보내기를 위에서 아래 순서로 제공한다.
- `/projects`에서는 `프로젝트 목록`을 현재 위치로 표시한다.
- 사이드바는 기본·빈 상태·로딩·오류 상태에서 같은 폭과 위치를 유지한다.
- 사용자 정보 선택 시 계정 설정과 로그아웃을 포함한 사용자 메뉴를 연다.
- 프로젝트 휴지통은 `/projects/trash`로 이동한다.
- 사용 가이드와 피드백 보내기는 각각 독립된 전역 진입점으로 동작한다.

## 초기 제외 범위

- 검색
- 정렬 방식 선택
- 프로젝트 복제
- 프로젝트 템플릿

기존 프로젝트를 선택한 이후의 이동은 [프로젝트 진입 Workflow](../workflow/project-entry.md)를 따른다. 새 프로젝트를 만드는 방식은 [프로젝트 생성](./create-project.md)과 [프로젝트 생성 Workflow](../workflow/project-creation.md)를 따른다. 이름 변경은 이 문서의 카드 관리 계약을 따르며, 삭제와 복원 방식은 [프로젝트 휴지통](./trash.md)과 [프로젝트 휴지통 Workflow](../workflow/project-trash.md)를 따른다.
