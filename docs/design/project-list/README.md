# 프로젝트 목록

## 역할

- 인증을 완료한 사용자의 앱 시작점이다.
- 사용자가 기존 프로젝트를 선택하거나 새 프로젝트를 만든다.

## Route

```text
/projects
```

## 사이드바

프로젝트 목록에서는 전역 기능을 제공하는 사이드바를 사용한다.

```text
사용자 정보
├─ 계정 설정
└─ 로그아웃

프로젝트 목록
프로젝트 휴지통

사용 가이드
피드백 보내기
```

- Lorekeeper 로고와 사이트명은 표시하지 않는다.
- 사용자 정보는 사이드바 상단에 표시한다.
- `새 프로젝트`는 사이드바가 아닌 프로젝트 목록 본문에서 핵심 행동으로 제공한다.
- `내 작업공간`은 `프로젝트 목록`과 역할이 겹치므로 별도로 제공하지 않는다.
- 컬렉션과 커뮤니티는 해당 기능이 생기기 전까지 제공하지 않는다.
- 변경 내역은 별도 사이드바 항목으로 두지 않고 사용 가이드 안에서 제공한다.
- 프로젝트에 진입하면 같은 위치의 사이드바가 프로젝트 콘텐츠 탐색용으로 전환된다.

## 프로젝트 표시

- 프로젝트는 카드 그리드로 표시한다.
- `새 프로젝트` 카드를 첫 위치에 고정한다.
- 기존 프로젝트는 마지막 작업 일시가 가까운 순서로 정렬한다.
- 프로젝트 카드에는 제목, 마지막 작업 일시와 마지막으로 작업한 파일을 표시한다.
- 프로젝트 카드 전체를 선택 영역으로 사용한다.
- 카드의 더보기 메뉴에는 이름 변경과 휴지통 이동을 제공한다.

## 빈 상태

프로젝트가 없으면 `첫 프로젝트 만들기`를 핵심 행동으로 안내한다.

## 초기 제외 범위

- 검색
- 정렬 방식 선택
- 프로젝트 복제
- 프로젝트 템플릿

기존 프로젝트를 선택한 이후의 이동은 [프로젝트 진입 Workflow](../workflow/project-entry.md)를 따른다. 새 프로젝트를 만드는 방식은 [프로젝트 생성](./create-project.md)과 [프로젝트 생성 Workflow](../workflow/project-creation.md)를 따른다. 삭제와 복원 방식은 [프로젝트 휴지통](./trash.md)과 [프로젝트 휴지통 Workflow](../workflow/project-trash.md)를 따른다.
