# Lorekeeper 대표 화면 시각 방향 탐색

- 상태: 대표 화면과 비교 범위 확정
- 기준 화면: `12 · Manuscript Editor · Memo · Work Selected`
- Pencil 프레임 ID: `BGPNV`
- 비교 크기: 1440 × 900
- 사용자 확인: 2026-08-28, 대표 화면과 비교 범위 승인

이 문서는 현재 C 와이어프레임의 구조를 유지한 채 Lorekeeper의 시각 방향을
실제 제품 참고자료와 사용자 선택으로 확정하기 위한 작업 기준이다. 추상적인
스타일 이름이나 AI가 임의로 만든 분위기를 기준으로 사용하지 않는다.

## 대표 화면

`12 · Manuscript Editor · Memo · Work Selected`를 대표 화면으로 사용한다. 이
화면에는 프로젝트 탐색, 문서 탭, 파일 헤더, 원고 편집 영역과 작품 메모 패널이
함께 있어 한 화면에서 다음 항목을 비교할 수 있다.

- 장시간 집필할 본문과 주변 도구 사이의 시각적 우선순위
- 좌측 탐색 영역, 중앙 편집 영역과 우측 보조 영역의 경계
- 활성 탭, 선택한 파일과 열린 메모 패널의 상태 표현
- UI 텍스트와 원고 본문 사이의 서체·크기 체계
- 탐색 영역의 압축된 밀도와 편집 영역의 여백 균형

AI 챗이 열린 상태는 이번 대표 화면에서 제외한다. 메모 패널만으로 보조 영역이
열렸을 때의 편집 폭과 영역 경계를 비교할 수 있고, AI 챗까지 동시에 포함하면
시각 방향보다 패널 동시 표시 정책이 판단에 개입하기 때문이다.

## 모든 시각안에서 유지할 요소

- 1440 × 900 화면 크기와 동일한 콘텐츠
- C 와이어프레임의 좌측 탐색과 중앙 작업 셸 구조
- 탭 바, 파일 헤더, 원고 편집 영역과 메모 패널의 순서
- 작품 메모가 선택된 상태와 메모 패널의 오른쪽 배치
- 메모 패널 헤더의 닫기·추가·배치 전환과 작품/원고 메모 전환 구조
- 현재 프로젝트, 활성 탭, 선택한 파일과 열린 패널의 상태
- 원고 본문과 주변 UI가 차지하는 구조적 영역

시각안 비교 중에는 정보 구조, 기능, 문구, 패널 위치와 상호작용을 다시 설계하지
않는다.

## 시각안별로 변경할 요소

- 배경과 표면의 명도 단계, 텍스트 대비와 제한적인 강조색
- UI 서체와 원고 본문 서체의 조합, 크기, 굵기와 줄 간격
- 탐색과 컨트롤의 밀도, 편집 영역의 여백과 본문 폭
- 영역 경계, 선택·활성·포커스 상태의 표현 방식
- 아이콘의 크기, 선 굵기와 레이블 결합 방식
- 반복 요소의 모서리와 표면 표현

변경 요소도 이후 정리할 실제 제품 참고자료와 사용자 선호에 근거해야 한다.
그라디언트, 발광, 과도한 카드와 장식은 별도 근거 없이 추가하지 않는다.

## 동일 조건 비교 규칙

- 모든 시각안은 대표 화면 기준본을 복제해 만든다.
- 구조, 내용과 상태를 먼저 대조한 뒤 시각 속성만 변경한다.
- 각 시각안에 참고한 실제 제품과 적용한 요소를 기록한다.
- 작업 집중, 가독성, 정보 위계와 사용자 선호를 같은 기준으로 비교한다.
- 단순 저장이나 레이아웃 오류 없음은 디자인 승인으로 간주하지 않는다.

## 이번 Deliverable에서 제외할 범위

- 선택한 시각 방향을 기존 모든 화면에 전파하는 작업
- 랜딩, 로그인, 프로젝트 목록 등 아직 다루지 않은 화면 설계
- frontend 코드 구현과 API 연동
- AI 챗과 메모 패널의 동시 표시 정책
- 반응형 레이아웃과 고충실도 인터랙션 프로토타입
- 전체 제품 디자인 완료 선언

이번 Deliverable의 완료 결과는 사용자가 승인한 대표 화면 하나와 그 화면에서
도출한 시각 규칙·디자인 변수·재사용 컴포넌트다.
