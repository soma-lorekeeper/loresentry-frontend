# 로그인 최종 검증

이 문서는 로그인 화면의 상태 완결성, 접근성, 다크·라이트 대비와 레이아웃을
검증한 `LOREKEEPER-414`의 완료 기준이다. 검증 기준일은 2026-09-01이다.

## 상태 레지스트리

| 번호 | 화면 | Pencil ID | 검증 목적 |
| ---: | --- | --- | --- |
| 139 | Login · Default | `EwUtO` | 직접 진입과 일반 인증 시작 |
| 140 | Login · Processing | `F4Qlk` | OAuth 이동·결과 처리와 중복 실행 방지 |
| 141 | Login · OAuth Canceled | `rENHC` | 사용자 취소와 같은 OAuth 재시도 |
| 142 | Login · OAuth Failed | `vJY2I` | 원인을 추측하지 않는 실패와 재시도 |
| 143 | Login · Session Expired | `y578o` | 만료 안내와 검증된 기존 작업 맥락 복귀 |
| 144 | Login · Default · Light | `sSVhG` | 같은 구조의 라이트 모드 기준 |

여섯 화면은 모두 `1440 × 900` 데스크톱 프레임이다. 기본 다크와 기본 라이트는
같은 컴포넌트 구조를 사용하고 `b:mode`만 바꾼다.

## 키보드와 상태 전달

- 기본 탭 순서는 Google 행동, 이용약관, 개인정보처리방침이다. 페이지 진입 때
  포커스를 강제로 이동하지 않는다.
- Google 행동은 기본 `360 × 44`, Focused는 외곽 포커스 링을 포함해
  `360 × 48`이다. `Auth / Google Button / Focused`는 2px 강조색 경계를 사용한다.
- 정책 링크는 각각 32px 높이의 독립 상호작용 목표를 가진다. 모든 상호작용
  목표는 WCAG 2.2의 24px 최소 크기를 넘는다.
- 처리 중에는 Google 행동의 포커스 문맥을 유지하고 `aria-disabled="true"`와
  `aria-live="polite"`로 중복 실행 방지와 진행 상태를 전달한다.
- 열린 화면의 상태가 취소·실패·세션 만료로 바뀌면 상태 제목으로 포커스를
  이동한다. 취소와 만료는 `status`, 실패는 `alert`로 전달한다.

## 색상 외 상태 구분

| 상태 | 색상 외 단서 |
| --- | --- |
| 처리 중 | 회전 진행 표식, 처리 문구, 비활성 행동 |
| 인증 취소 | 정보 아이콘, 경계, 취소 문구와 다시 시도 |
| 인증 실패 | 경고 아이콘, 더 뚜렷한 경계, 실패 문구와 다시 시도 |
| 세션 만료 | 정보 아이콘, 만료 문구, 이전 작업 맥락 복귀 설명 |
| 키보드 포커스 | 기본 행동 경계 바깥의 2px 연속 링 |

## 대비 검증

아래 수치는 라이브러리 색상 변수를 sRGB 상대 휘도로 계산한 명암비다.

| 조합 | 다크 | 라이트 | 판정 |
| --- | ---: | ---: | --- |
| 기본 텍스트 / 표면 | 13.49:1 | 16.52:1 | 일반 텍스트 AA 통과 |
| 보조 텍스트 / 표면 | 6.09:1 | 5.76:1 | 일반 텍스트 AA 통과 |
| 아이콘 / 표면 | 8.46:1 | 6.43:1 | 비텍스트 UI 통과 |
| 강조색 / 표면 | 8.54:1 | 5.86:1 | 포커스·경계 통과 |
| 강조색 위 텍스트 / 강조색 | 10.14:1 | 5.86:1 | 일반 텍스트 AA 통과 |

기본 Google 행동 경계는 강조색을, 오류 안내 경계는 보조 텍스트 색을 사용한다.
선택, 처리와 오류는 색상만으로 구분하지 않는다.

## 레이아웃과 구조

- Pencil의 해석된 인스턴스 경계를 기준으로 여섯 화면의 부모 밖 노드는 0개다.
- 화면과 라이브러리의 placeholder는 0개이며 끊어진 로그인 참조도 0개다.
- 정책 링크 목표를 32px로 확장한 뒤에도 카드, 상태 안내와 긴 세션 만료 문구는
  잘림이나 겹침 없이 들어간다.
- 기본 다크와 기본 라이트 화면을 시각 검토해 위계, 정렬, 경계와 정책 링크 위치가
  일치함을 확인했다.

## 범위 이탈 확인

이메일·비밀번호 입력, 별도 회원가입, 비밀번호 찾기, 추가 소셜 제공자, 별도 약관
동의 화면은 여섯 화면과 인증 컴포넌트에 존재하지 않는다.

## 검증 중 보완

- `Auth / Google Button / Focused`를 추가하고 2px 강조색 포커스 링을 정의했다.
- 기본 Google 행동 경계를 강조색으로, 오류 안내 경계를 보조 텍스트 색으로
  바꿨다.
- 이용약관과 개인정보처리방침 링크를 32px 높이의 독립 목표로 확장했다.

## 판정

정의된 다섯 인증 상태와 라이트 기준 화면은 상태, 키보드, 상태 전달, 대비,
레이아웃과 범위 조건을 모두 통과한다.
