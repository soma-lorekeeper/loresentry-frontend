# 로그인 frontend 구현 인계

이 문서는 로그인 Deliverable의 Pencil 화면과 frontend 구현 계약을 연결하는 최종
인계 기준이다. 화면 레지스트리와 범위는 2026-09-01의 `LOREKEEPER-415` 결과다.

## 원본과 우선순위

구현 중 기준이 충돌하면 다음 순서로 확인한다.

1. [로그인 페이지](./README.md)의 정보·표시·행동 계약
2. [Google OAuth 인증 Workflow](../workflow/authentication.md)의 인증 상태 전환
3. [서비스 진입 Workflow](../workflow/service-entry.md)의 진입·성공 후 이동
4. [로그인 최종 검증](./final-validation.md)의 접근성·레이아웃 완료 조건
5. 이 문서의 화면 ID와 구현 목적
6. `lorekeeper.lib.pen`의 변수와 재사용 컴포넌트

화면 ID는 Route가 아니라 상태별 시각 기준이다. `/login` 하나가 기본, 처리 중,
취소, 실패와 세션 만료 화면에 대응한다.

최상위 화면, 이 표와 최종 검증 문서를 같은 변경에서 갱신한다.

## Route와 결과 연결

| 진입점·상태 | 구현 결과 |
| --- | --- |
| `/login` 일반 진입 | 기본 화면에서 Google OAuth 하나만 시작 |
| OAuth 처리 중 | 같은 위치에서 중복 실행을 막고 진행 상태 알림 |
| OAuth 취소·실패 | 같은 Google OAuth 재시도, 입력·가입 대안은 추가하지 않음 |
| 일반 인증 성공 | `/projects`로 이동 |
| 세션 만료 후 성공 | 서버가 검증한 기존 Lorekeeper 작업공간으로 복귀 |
| 복귀 맥락 없음·무효 | `/projects`로 이동 |

복귀 URL은 클라이언트가 임의로 신뢰하지 않는다. 서버가 인증 전에 저장하고 인증
후 Lorekeeper 내부 작업공간임을 확인한 값만 사용한다.

## 컴포넌트와 변수

- `lorekeeper.lib.pen`의 33개 변수와 109개 재사용 컴포넌트를 디자인 원본으로
  사용한다. 로그인 전용 컴포넌트는 6개다.
- Google 행동은 `Default`, `Focused`, `Processing` 상태를 사용한다. 취소·세션
  만료는 `Status Notice / Info`, 실패는 `Status Notice / Error`를 사용한다.
- 동의 문구와 정책 링크는 `Auth / Policy Notice`를 사용한다.
- 다크·라이트는 같은 DOM 구조와 의미 순서를 유지하고 `mode` 토큰만 전환한다.
- 직접 색상, 간격, 반경, 글자 크기와 아이콘 굵기를 화면별로 만들지 않는다.
  Google 브랜드 표식의 원본 벡터 색상만 기록된 예외로 유지한다.

## 상호작용과 접근성

- 조작 순서는 Google 행동, 이용약관, 개인정보처리방침이다. 진입 시 포커스를
  강제로 옮기지 않는다.
- Google 행동을 실행하면 즉시 처리 중으로 바꾸고 포커스 문맥을 유지한다.
  `aria-disabled="true"`와 요청 잠금으로 키보드·포인터 중복 요청을 함께 막는다.
- 처리 문구는 `aria-live="polite"`, 취소·만료는 `status`, 실패는 `alert`로 한 번
  전달한다. 열린 화면의 결과 상태가 바뀌면 상태 제목에 포커스를 둔다.
- Focused는 2px 연속 강조색 링을 유지한다. 브라우저 기본 outline을 제거할 때는
  이 링과 동등한 표시를 반드시 제공한다.
- 정책 링크는 각각 32px 높이의 독립 목표로 구현하며 인증과 독립적으로 열리게
  한다. 링크 열기만으로 별도 동의 상태를 기록하지 않는다.
- 처리, 취소, 실패와 만료는 아이콘·경계·문구를 함께 사용해 색상에만 의존하지
  않는다. 검증된 대비 조합은 [로그인 최종 검증](./final-validation.md)을 따른다.

## 확정 범위

### 포함

- 데스크톱 `/login` 기본, 처리 중, 취소, 실패와 세션 만료
- Google OAuth 단일 인증 행동과 같은 행동의 재시도
- 일반 성공 후 프로젝트 목록 이동과 검증된 세션 만료 복귀
- 이용약관 동의 안내, 이용약관·개인정보처리방침 링크
- dark/light 공통 변수·컴포넌트, 키보드·상태 전달·대비·레이아웃 구현 계약

### 제외

- 이메일·비밀번호 로그인, 별도 회원가입과 비밀번호 찾기
- Google 외 소셜 제공자와 인증 방식 선택
- 별도 약관 동의 화면·체크박스와 계정 연결·전환 UI
- 랜딩, 프로젝트 목록과 통합 작업공간 재설계
- OAuth Provider, API·서버, 세션 저장과 계정 생성 구현
- 모바일·태블릿 전용 레이아웃, 배포와 출시 작업

## 미확정 정책과 후속 구현

- 이용약관과 개인정보처리방침의 실제 URL은 현재 디자인 문서에 정의돼 있지 않다.
  frontend는 임시 주소를 만들지 말고 제품·법무가 확정한 URL을 연결한다.
- OAuth 시작·callback, 오류 코드와 세션 만료 복귀 맥락의 API 계약은 별도 구현
  Work에서 서버 계약과 함께 확정한다. UI는 원인을 추측한 문구를 추가하지 않는다.
- 이 인계를 기준으로 `/login` frontend와 인증 통합을 별도 Work로 계획한다.
- 모바일·태블릿은 중단점과 정보 구조를 확정한 뒤 별도 Deliverable로 설계한다.
