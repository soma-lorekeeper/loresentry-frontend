# 로그인 디자인 시스템 감사

이 문서는 로그인 화면과 공통 라이브러리의 변수·컴포넌트 소유권 및 참조
무결성을 기록한다. 집계 기준은 2026-09-01에 저장된 `LOREKEEPER-413`
결과다.

메인 Pen의 로그인 화면은 같은 33개 변수 이름과 같은 라이브러리 컴포넌트를
공유한다. 다크와 라이트는 별도 컴포넌트 집합을 만들지 않고 화면의 `b:mode`만
바꾼다.

## 로그인 공통 컴포넌트

| 컴포넌트 | Pencil ID | 역할 |
| --- | --- | --- |
| `Auth / Google Button / Default` | `YuQi0` | Google 인증 시작과 재시도 |
| `Auth / Google Button / Processing` | `BmSd7` | 중복 실행이 막힌 인증 처리 중 행동 |
| `Auth / Status Notice / Info` | `nBJr6` | 취소·세션 만료·처리 상태 안내 |
| `Auth / Status Notice / Error` | `q921r` | 인증 실패 안내 |
| `Auth / Policy Notice` | `nr8tB` | 동의 안내와 두 정책 링크 |

메인 Pen에서는 위 ID가 `b:` 접두사를 가진 가져온 컴포넌트로 나타난다. 화면별
문구 차이는 인스턴스 속성으로 전달하며 로컬 재사용 컴포넌트를 만들지 않는다.

## 컴포넌트 문서 대조

[UI 컴포넌트 라이브러리](../component-library.md)는 기본 컴포넌트 42개와 상태
컴포넌트 66개, 총 108개를 기록한다. 이전 103개 목록에 로그인 기본 컴포넌트
3개와 상태 컴포넌트 2개를 추가한 결과이며 실제 라이브러리 집계와 일치한다.

## 직접값 예외

- Google 브랜드 표식의 빨강·파랑·노랑·초록은 제품 테마가 아니라 제공자 식별을
  위한 원본 벡터 색상으로 유지한다.
- 화면 프레임의 `1440 × 900` 크기와 최상위 배치 좌표는 화면 레지스트리용 구조
  값이다.
- 글자 굵기는 콘텐츠 위계 속성이다. 의미가 있는 색상, 간격, 반경, 글자 크기,
  행간과 아이콘 굵기는 모두 `b:` 공통 변수를 참조한다.

## 소유권 규칙

- 변수와 재사용 컴포넌트의 단일 원본은 `lorekeeper.lib.pen`이다.
- `lorekeeper.pen`은 가져온 변수와 컴포넌트만 사용한다.
- 로그인 화면별 배치와 한 화면에서만 쓰는 설명 구조는 메인 Pen에 둔다.
- 컴포넌트 수, 이름이나 ID가 바뀌면 라이브러리 문서와 frontend 인계 문서를 같은
  변경에서 갱신한다.

## 판정

변수·컴포넌트 소유권, 다크·라이트 대응, 참조 무결성, 문서 수량과 placeholder
조건을 모두 충족한다. 로그인 디자인 시스템 감사에서 수정이 필요한 항목은 없다.
