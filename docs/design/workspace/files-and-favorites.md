# 기본 섹션

즐겨찾기와 파일은 프로젝트를 만들 때 기본으로 제공하는 섹션이다. 기본 섹션은 이름을 변경할 수 있지만 삭제할 수 없다.

## 즐겨찾기

즐겨찾기는 파일이나 폴더의 원본을 복제하거나 이동하지 않고 바로가기를 모아 두는 섹션이다.

즐겨찾기 섹션의 더보기 메뉴는 다음 항목을 세로로 표시한다.

```text
새 폴더
이름 변경
```

- 즐겨찾기 섹션 헤더의 더보기 버튼은 펼침·접힘 여부와 관계없이 항상 표시한다.
- 즐겨찾기의 폴더는 바로가기를 정리한다.
- 즐겨찾기에서는 새 파일을 만들거나 외부 파일을 가져오지 않는다.
- 파일이나 폴더를 즐겨찾기로 드래그 앤 드롭하면 바로가기를 생성한다.
- 원본 파일이나 폴더는 기존 위치에 유지한다.

사용자 이동은 [즐겨찾기 Workflow](../workflow/favorites.md)를 따른다.

즐겨찾기 더보기 메뉴의 열린 상태는 `lorekeeper.pen`의
`22 · Workspace · Favorites Menu Open`(`tZZM3`)을 시각 기준으로 사용한다.

## 파일

파일 섹션은 현재 프로젝트의 원본 파일과 폴더를 보관한다.

파일 섹션의 더보기 메뉴는 다음 항목을 세로로 표시한다.

```text
원고
설정
캐릭터
이벤트
조직
아이템
장소
세계관
────────
새 폴더
가져오기
이름 변경
```

- 파일 섹션 헤더의 더보기 버튼은 펼침·접힘 여부와 관계없이 항상 표시한다.
- 각 파일 유형을 선택하면 해당 유형의 새 파일을 만든다.
- `가져오기`는 외부 원고나 데이터를 현재 프로젝트의 파일 섹션으로 가져온다.
- 기본 파일 섹션에는 `섹션 삭제`를 제공하지 않는다.
- 파일과 폴더의 이름은 항목을 더블클릭하거나 더보기 메뉴에서 `이름 변경`을 선택해 변경한다.

파일 더보기 메뉴의 열린 상태는 `lorekeeper.pen`의
`23 · Workspace · Files Menu Open`(`oPs13`)을 시각 기준으로 사용한다.

## 사용자 생성 섹션

사용자가 추가한 섹션은 파일 섹션과 같은 생성 기능을 제공하고 마지막에 `섹션 삭제`를 제공한다.

```text
원고
설정
캐릭터
이벤트
조직
아이템
장소
세계관
────────
새 폴더
가져오기
이름 변경
────────
섹션 삭제
```

`섹션 삭제`는 다른 항목과 구분한 마지막 위험 행동으로 배치한다. 내부 항목은
기본 파일 섹션에 보존한 뒤 사용자 생성 섹션만 제거한다.

### 사용자 생성 섹션 삭제

- 섹션을 삭제해도 내부 파일과 폴더를 휴지통으로 보내거나 영구 삭제하지 않는다.
- 내부 항목이 있으면 기본 `파일` 섹션 최상위에 삭제한 섹션과 같은 이름의 폴더를
  만들고 모든 항목을 그 안으로 이동한다.
- 중첩 폴더 구조와 파일 관계는 그대로 유지한다.
- 같은 이름의 폴더가 이미 있으면 `이름 (2)`, `이름 (3)` 순서로 충돌하지 않는
  이름을 사용한다.
- 이동한 파일과 폴더의 식별자는 유지하므로 기존 즐겨찾기 바로가기도 유지한다.
- 빈 섹션을 삭제할 때는 기본 파일 섹션에 빈 폴더를 만들지 않는다.
- 섹션 자체의 이름과 정렬 위치는 삭제 후 복원하지 않는다.

삭제 전 확인 대화상자에는 섹션 이름, 전체 파일·폴더 수와 이동 위치를 표시한다.

```text
자료 조사 섹션을 삭제할까요?
파일 6개와 폴더 2개는 파일 > 자료 조사로 이동합니다.

[취소] [섹션 삭제]
```

삭제 확인 상태는 `lorekeeper.pen`의
`86 · Workspace · User Section Delete Confirmation`(`eO5kL`)을 시각
기준으로 사용한다.

- `취소`는 대화상자를 닫고 섹션 더보기의 `섹션 삭제`로 포커스를 돌린다.
- `섹션 삭제`가 성공하면 기본 파일 섹션을 펼치고 이동된 폴더로 포커스를 옮긴다.
- 이동이나 섹션 삭제 중 하나라도 실패하면 어떤 변경도 적용하지 않는다. 대화상자에
  오류와 `다시 시도`를 표시하고 기존 섹션과 내부 항목을 유지한다.
- 기본 즐겨찾기와 파일 섹션에는 삭제 행동과 삭제 확인 대화상자를 제공하지 않는다.

전체 변경을 취소하고 다시 시도를 제공하는 실패 상태는 `lorekeeper.pen`의
`87 · Workspace · User Section Delete Error`(`F9oF1`)을 시각 기준으로
사용한다.

사용자 생성 섹션 더보기 메뉴의 열린 상태는 `lorekeeper.pen`의
`27 · Workspace · User Section Menu Open`(`PAM02`)을 시각 기준으로 사용한다.

삭제 상태와 이동 결과는
[사용자 생성 섹션 삭제 Workflow](../workflow/section-deletion.md)를 따른다.

파일과 폴더를 만드는 위치와 이름 입력 방식은 [파일·폴더 생성과 이름 변경 Workflow](../workflow/item-creation-and-renaming.md)를 따른다.
