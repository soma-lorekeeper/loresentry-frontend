# 통합 작업공간

프로젝트 홈을 별도로 두지 않고 하나의 통합 작업공간에서 콘텐츠를 탐색하고 편집한다.

## Route

```text
/workspace/[projectId]
```

## 화면 구조

통합 작업공간은 다음 세 영역으로 구성한다.

- 사이드바: 프로젝트 콘텐츠를 탐색하고 작업할 대상을 연다.
- 중심 작업 영역: 선택한 콘텐츠를 탭으로 열고 편집한다.
- AI 챗 보조 사이드 패널: 중심 작업 영역 오른쪽에서 열고 닫는다.

AI 챗 보조 사이드 패널은 세션 관리, 대화 내역과 메시지 입력 영역으로 구성한다.

## 사이드바

```text
사용자 정보

현재 프로젝트 이름 ▾

그래프
메모

즐겨찾기
파일

휴지통
설정

도움말
```

- 사용자 정보는 사이드바 상단에 표시한다.
- 현재 프로젝트 이름을 선택하면 프로젝트 전환 메뉴를 연다.
- 프로젝트 전환 메뉴의 첫 항목은 `프로젝트 목록`이다.
- 프로젝트 전환 메뉴에는 현재 프로젝트와 다른 프로젝트를 표시한다.
- 새 프로젝트 만들기는 프로젝트 전환 메뉴에 표시하지 않고 프로젝트 목록에서만 제공한다.
- 그래프와 메모는 현재 프로젝트 전체에서 공유하는 고정 기능으로 제공한다.
- 즐겨찾기와 파일에서는 프로젝트 콘텐츠를 탐색한다.
- 휴지통과 설정은 관리 기능으로 제공한다.
- 도움말에서는 사용 가이드와 피드백 보내기를 제공한다.

프로젝트를 이동하는 방식은 [프로젝트 전환 Workflow](../workflow/project-switching.md)를 따른다.
즐겨찾기와 파일의 구조는 [기본 섹션](./files-and-favorites.md)을 따른다.
개별 파일과 폴더의 메뉴는 [파일·폴더 동작](./file-and-folder-actions.md)을 따른다.
휴지통에서 파일과 폴더를 관리하는 방식은 [파일·폴더 휴지통](./trash.md)을 따른다.

## 중심 작업 영역

- 상단 탭 바와 선택한 콘텐츠를 표시하는 작업 화면으로 구성한다.
- 탭 바에는 왼쪽 사이드바 열기·닫기 버튼과 오른쪽 AI 챗 보조 사이드 패널 열기·닫기 버튼을 배치한다.
- 여러 콘텐츠를 브라우저와 같은 탭 방식으로 열고 전환한다.
- 분할 화면은 초기 범위에 포함하지 않는다.

콘텐츠를 여는 방식은 [작업공간 콘텐츠 열기 Workflow](../workflow/workspace-navigation.md)를 따른다.
세부 탭 동작은 [중앙 작업 영역 탭](./tabs.md)을 따른다.
새 탭의 콘텐츠 구성은 [새 탭 화면](./new-tab.md)을 따른다.
AI 챗 보조 사이드 패널의 구성은 [AI 챗 보조 사이드 패널](./ai-chat-panel.md)을 따른다.
파일 탭의 공통 기능은 [파일 헤더](./file-header.md)를 따른다.
파일 단위 메모는 [파일 메모 패널](./file-memo-panel.md)을 따른다.
원고 파일의 콘텐츠 구성은 [원고 편집 영역](./manuscript-editor.md)을 따른다.
