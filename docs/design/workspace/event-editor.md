# 이벤트 파일

이벤트 파일은 [속성 문서 편집 영역](./structured-file-editor.md)을 다른 분류와
똑같이 사용한다. 고정 필드도, 이벤트 전용 영역도 없다.

## 시간 흐름 영역을 두지 않는 이유

이전 설계는 속성 아래에 `시간 흐름` 영역을 두고 사건을 이루는 장면을 날짜·순서·미정
세 가지 방식으로 나열하게 했다. 이 설계는 폐기했다.

사건 하나를 다시 장면으로 쪼개면 사용자가 같은 것을 두 층위로 관리하게 된다. 장면이
따로 있어야 할 만큼 중요하면 그것 역시 사건이고, 그렇지 않으면 설명 한 줄로 족하다.

**사건이 언제 일어났는지는 `관련 원고` 관계가 말한다.** 그 사건이 실린 회차를 이으면
작품 안에서의 위치가 정해진다. 회차 자체가 이미 시간축이므로 문서마다 별도의 날짜를
받을 이유가 없다.

**작품 전체의 흐름은 [사건 시간 흐름](./timeline.md) 화면이 맡는다.** 한 문서 안에서
보는 것이 아니라, 어느 인물과 장소가 어느 구간에 걸쳐 나오는지를 표 하나로 본다.

## 화면 구조

```text
이벤트
도깨비 학살
──────────────────────────────────────────
분류        이벤트
설명        도깨비가 3807호차 승객을 시나리오로 몰아넣었다
관련 원고    [3화]
관련 캐릭터  [도깨비] [김독자]
관련 장소    [3807호차]
──────────────────────────────────────────
+ 속성 추가

(본문)
```

값이 있는 행만 보인다. 빈 문서는 분류와 설명 둘뿐이다.

## Pencil 시각 참조

- 기본: `159 · Property Document · Event · Default`
- 빈 문서: `160 · Property Document · Event · Empty`
