# 이벤트 파일과 시간 흐름

이벤트 파일은 [속성 문서 편집 영역](./structured-file-editor.md)의 제목, 사용자 정의
속성과 문서 내용을 그대로 사용하고 속성 아래에 `시간 흐름` 영역을 추가한다. 시간
흐름은 하나의 이벤트를 구성하는 장면이나 단계를 순서대로 기록하는 선택 영역이다.

## 화면 구조

```text
탭 바
파일 헤더                         [메모] [버전] [내보내기] [잠금]
──────────────────────────────────────────────────────────
편집 툴바
──────────────────────────────────────────────────────────
이벤트 제목

속성
사용자 정의 속성
[+ 속성 추가]

시간 흐름                                           [+ 항목]
시간 항목
시간 항목

문서 내용
```

- 이벤트 제목만 필수다. 고정 속성과 시간 항목을 미리 만들지 않는다.
- 속성의 추가·파일 참조와 저장은 속성 문서의 공통 규칙을 따른다.
- 시간 흐름은 속성과 문서 내용 사이에 둔다.
- 시간 항목은 이벤트 파일 안에서만 존재하며 사이드바 파일이나 그래프 노드로 만들지
  않는다.
- 시간 항목이 없어도 이벤트 파일을 저장할 수 있다.

## 시간 항목

```text
[시간 유형] 시간 또는 순서
항목 제목                                      […]
짧은 설명
관련 파일 칩
```

- 항목 제목은 필수다.
- 짧은 설명과 관련 파일은 선택 정보다.
- `더보기`는 항상 표시하고 `편집`과 `삭제`를 제공한다.
- 관련 파일은 기존 `Property / File Chip`을 사용하고 현재 프로젝트의 휴지통에 없는
  파일을 여러 개 연결할 수 있다.
- 관련 파일 참조는 시간 항목을 별도 노드로 만들지 않고 상위 이벤트 파일에서 대상
  파일로 향하는 관계로 저장한다. 그래프 관계 이름은 `시간 흐름 · 항목 제목`을
  사용한다.

## 시간 유형

시간 유형은 색상만으로 구분하지 않고 아이콘, 레이블과 값을 함께 표시한다.

| 유형 | 아이콘 | 표시 예시 | 입력 |
| --- | --- | --- | --- |
| 날짜·시간 | `calendar-days` | `1024. 3. 18. 21:30` | 날짜 필수, 시간 선택 |
| 순서 | `list-ordered` | `순서 2` | 같은 그룹 안에서 앞·뒤 이동 |
| 미정 | `circle-help` | `시간 미정` | 날짜와 순서 없음 |

- 날짜·시간 항목은 오래된 날짜부터 표시하고 같은 날짜에서는 시간이 빠른 항목부터
  표시한다. 시간이 없는 항목은 같은 날짜의 시간이 있는 항목 뒤에 둔다.
- 순서 항목은 사용자가 정한 순서대로 표시하고 `순서 1`부터 연속 번호를 붙인다.
- 미정 항목은 날짜·시간과 순서 항목 뒤에 두고 생성 순서를 유지한다.
- 화면에는 `날짜·시간`, `순서`, `미정` 그룹 레이블을 표시해 서로 다른 기준이 한
  목록에서 섞이지 않게 한다.
- 유형을 바꾸면 기존 값과 호환되지 않는 날짜·시간 또는 순서 값은 확인 후 제거한다.

## 생성과 편집

`항목 추가`를 선택하면 시간 흐름 첫머리에 편집 카드를 연다.

```text
항목 제목
시간 유형       [날짜·시간 | 순서 | 미정]
날짜            YYYY. MM. DD.
시간            HH:MM
짧은 설명
관련 파일

[취소] [완료]
```

- 새 항목의 초기 시간 유형은 `미정`이다.
- `날짜·시간`을 선택하면 날짜와 시간 입력을 표시한다.
- `순서`를 선택하면 현재 순서 그룹 마지막에 배치하고 앞·뒤 이동을 제공한다.
- `미정`을 선택하면 날짜·시간과 순서 입력을 표시하지 않는다.
- `완료`는 제목이 있을 때만 활성화한다.
- `취소`는 새 항목을 만들지 않고 이전 포커스로 돌아간다.
- 기존 항목을 선택하면 선택 테두리와 체크 아이콘을 표시하고 같은 위치에 편집
  카드를 펼친다.
- 편집한 값은 `완료`를 선택하면 저장한다. 이벤트 문서 자체의 제목·속성·내용은
  기존 자동 저장을 계속 사용한다.

## 삭제

- 시간 항목의 `더보기 → 삭제`를 선택하면 확인 대화상자를 연다.
- 대화상자에는 이벤트 제목, 시간 항목 제목과 시간 레이블을 함께 표시한다.
- 삭제하면 시간 항목과 그 항목이 만든 관련 파일 관계만 제거한다.
- 상위 이벤트 파일과 참조한 파일은 유지한다.
- 삭제 후 같은 그룹의 다음 항목을 선택하고, 다음 항목이 없으면 이전 항목을
  선택한다. 남은 항목이 없으면 `항목 추가`로 포커스를 이동한다.

## 상태

| 상태 | 표현 |
| --- | --- |
| 기본 | 시간 유형별 그룹과 저장된 항목 표시 |
| 빈 상태 | `아직 시간 항목이 없습니다`와 `항목 추가` 표시 |
| 선택 | 선택 항목의 테두리와 체크 아이콘 표시 |
| 새 항목 | 빈 편집 카드, `미정` 선택과 비활성 `완료` 표시 |
| 편집 | 선택 항목의 값과 활성 `완료` 표시 |
| 삭제 확인 | 대상 항목 정보를 포함한 확인 대화상자 표시 |
| 저장 오류 | 편집 카드 안에 입력을 유지하고 `다시 시도` 표시 |

## 키보드 접근

- `Tab`은 속성, `항목 추가`, 시간 항목, 문서 내용 순서로 이동한다.
- 시간 흐름에 진입하면 위·아래 방향키로 같은 그룹의 항목을 이동한다.
- `Enter`는 항목을 선택하고 편집 카드를 연다.
- `Esc`는 편집 내용을 취소하고 해당 시간 항목으로 포커스를 돌려보낸다.
- 시간 유형, 선택과 오류는 색상 외에 아이콘과 텍스트로도 전달한다.

## 컴포넌트 경계

라이브러리에는 다음 요소를 재사용 컴포넌트로 둔다.

- `Timeline / Item / Date`: 날짜·시간 레이블, 제목, 설명, 관련 파일과 더보기
- `Timeline / Item / Order`: 순서 레이블, 제목, 설명, 관련 파일과 더보기
- `Timeline / Item / Unscheduled`: 미정 레이블, 제목, 설명, 관련 파일과 더보기
- `Timeline / Add`: 시간 항목 추가
- `Timeline / Item / Selected`: 선택된 시간 항목
- `Timeline / Item / Editing`: 시간 유형과 값을 편집하는 카드
- `Dialog / Timeline Item Delete`: 삭제 대상과 확인 동작

화면 전체 배치와 대표 이벤트 데이터는 `lorekeeper.pen`에 유지한다.

연결한다.
