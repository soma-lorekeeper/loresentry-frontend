# 작업공간 프로젝트 설정

사이드바의 `설정`을 선택하면 현재 프로젝트의 설정 탭을 연다. 프로젝트 설정은
현재 프로젝트에만 적용하며 계정 전체 설정과 구분한다.

## 화면 구조

```text
탭 바
──────────────────────────────────────────────────────────
프로젝트 설정
현재 프로젝트에만 적용됩니다

일반
프로젝트 이름
프로젝트 설명
                                      [취소] [변경사항 저장]

위험 영역
프로젝트를 휴지통으로 이동                         [이동]
```

- 설정 탭은 프로젝트마다 하나만 유지한다.
- 파일이 아니므로 파일 헤더를 표시하지 않는다.
- 사이드바의 `설정`을 선택 상태로 표시한다.
- 설정 탭을 닫아도 프로젝트나 설정값을 삭제하지 않는다.

## 일반 설정

| 항목 | 필수 | 규칙 |
| --- | --- | --- |
| 프로젝트 이름 | 필수 | 한 줄 텍스트, 빈 값과 공백만 있는 값은 저장 불가 |
| 프로젝트 설명 | 선택 | 여러 줄 텍스트, 프로젝트의 목적이나 범위를 기록 |

- 프로젝트 이름을 저장하면 사이드바 프로젝트 전환 버튼, 프로젝트 목록 카드와 열린
  프로젝트의 표시 이름에 반영한다.
- 설명은 프로젝트 목록 카드의 기본 정보로 사용하지 않고 프로젝트 설정에서만
  확인한다.
- 입력 중에는 저장된 값과 현재 값을 구분하고, 저장하기 전 다른 탭으로 이동하면
  변경사항 유지 여부를 묻는다.

## 저장과 취소

- 처음 열었을 때 `변경사항 저장`과 `취소`는 비활성 상태다.
- 값이 바뀌면 두 버튼을 활성화하고 상단에 `저장되지 않은 변경사항`을 표시한다.
- `변경사항 저장`을 선택하면 버튼에 `저장 중…`을 표시하고 입력을 잠시 비활성화한다.
- 저장이 끝나면 `저장됨`을 잠시 표시하고 새 값을 기준값으로 삼는다.
- 저장에 실패하면 입력을 유지하고 `저장하지 못했습니다`와 `다시 시도`를 표시한다.
- `취소`는 마지막으로 저장된 값으로 되돌린다. 변경값이 있으면 먼저 확인한다.

## 저장하지 않은 변경사항 확인

저장하지 않은 상태에서 설정 탭을 닫거나 다른 프로젝트로 이동하면 확인
대화상자를 연다.

```text
변경사항을 저장하지 않고 나갈까요?
현재 프로젝트 설정의 변경사항이 사라집니다.

[계속 편집] [변경사항 버리기]
```

- `계속 편집`은 대화상자를 닫고 마지막으로 편집한 입력으로 포커스를 돌린다.
- `변경사항 버리기`는 저장된 값으로 되돌린 뒤 원래 이동을 계속한다.
- 같은 프로젝트의 다른 탭으로 이동하는 것만으로는 확인하지 않고 변경값을 설정
  탭에 유지한다.

## 위험 영역

위험 영역은 일반 설정과 충분한 간격, 테두리와 `위험 영역` 레이블로 구분한다.

- `프로젝트를 휴지통으로 이동`만 제공한다.
- `이동`을 선택하면 프로젝트 이름을 포함한 확인 대화상자를 연다.
- 확인하면 현재 프로젝트를 휴지통으로 이동하고 프로젝트 목록으로 이동한다.
- 프로젝트 안의 파일을 개별 삭제하거나 프로젝트를 즉시 영구 삭제하지 않는다.
- 복원과 영구 삭제는 [프로젝트 휴지통](../project-list/trash.md)을 따른다.

## 제외 항목

- 계정 이름, 이메일과 로그아웃: 프로젝트 목록의 계정 설정 범위
- 다크·라이트 테마: 사용자 전체 환경 설정 범위
- 멤버와 권한: 협업 기능 범위가 정해진 뒤 추가
- AI 모델과 API 설정: AI 서비스 정책이 정해진 뒤 추가
- 파일 유형별 기본 속성과 템플릿

## 컴포넌트 경계

- `Settings / Section`: 제목, 설명과 설정 항목을 묶는 공통 영역
- `Settings / Field`: 레이블, 설명, 입력과 오류
- `Settings / Save Bar`: 변경됨, 저장 중, 저장됨과 오류 상태
- `Settings / Danger Zone`: 위험 행동 설명과 버튼
- `Dialog / Unsaved Settings`: 저장하지 않은 변경사항 확인
- `Dialog / Move Project To Trash`: 프로젝트 휴지통 이동 확인

## Pencil 시각 참조

Atomic 구현에서 기본, 변경됨, 저장, 오류와 확인 상태 화면을 추가한 뒤 화면 ID를
연결한다.
