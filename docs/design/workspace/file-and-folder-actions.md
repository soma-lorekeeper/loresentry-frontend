# 파일·폴더 동작

파일과 폴더의 더보기 메뉴에는 이동이나 즐겨찾기 추가를 제공하지 않는다. 두 동작은 드래그 앤 드롭으로 수행한다.

## 파일 더보기

```text
이름 변경
────────
휴지통으로 이동
```

## 폴더 더보기

```text
원고
설정
캐릭터
이벤트
조직
아이템
장소
세계관
────────
새 폴더
가져오기
이름 변경
────────
휴지통으로 이동
```

- 폴더의 파일 유형과 `새 폴더`는 해당 폴더 안에 항목을 만든다.
- `가져오기`는 외부 원고나 데이터를 해당 폴더 안으로 가져온다.
- 파일과 폴더의 위치 이동은 [파일·폴더 이동 Workflow](../workflow/item-movement.md)를 따른다.
- 즐겨찾기 추가는 [즐겨찾기 Workflow](../workflow/favorites.md)를 따른다.
