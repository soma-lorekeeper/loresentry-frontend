# 새 탭 화면

새 탭 화면은 현재 프로젝트에서 작업을 빠르게 재개하거나 새 파일을 만드는 시작점이다. 별도 프로젝트 홈이나 Route로 만들지 않고 탭 안에서 표시한다.

## 화면 구조

```text
현재 프로젝트명

마지막으로 작업한 파일
파일명 · 마지막 작업 시각                         [이어서 작업하기]

원고 · 설정 · 캐릭터 · 이벤트 · 조직 · 아이템 · 장소 · 세계관

가져오기

최근에 연 파일
```

## 상단 영역

- 현재 프로젝트명을 가장 먼저 표시해 작업 맥락을 알려준다.
- 마지막으로 편집한 파일의 이름과 작업 시각을 표시한다.
- `이어서 작업하기`를 선택하면 해당 파일을 마지막 편집 위치에서 연다.
- 상단 영역은 넓고 낮은 배너 형태로 구성하고 이어서 작업하기를 핵심 행동으로 강조한다.

### 최근 작업 정보가 없는 상태

- 마지막 편집 파일 정보가 없으면 상단 배너를 다음 행동 안내로 바꾼다.
- 배너에는 `아직 작업한 파일이 없습니다`, `첫 파일을 만들어 시작하세요`와
  `원고 만들기` 행동을 표시한다.
- `원고 만들기`는 파일 섹션 최상위에 원고를 만들고 현재 새 탭을 생성한 원고
  탭으로 전환한다.
- 프로젝트 맥락과 파일 생성 유형 8개는 기본 상태와 동일하게 유지한다.

## 새로 만들기

- 원고, 설정, 캐릭터, 이벤트, 조직, 아이템, 장소와 세계관 유형을 모두 제공한다.
- 파일 유형을 선택하면 파일 섹션 최상위에 해당 파일을 만든다.
- 이름 입력을 마치면 현재 새 탭을 생성한 파일 탭으로 전환한다.
- `가져오기`는 파일 섹션의 가져오기 흐름을 시작한다.

## 최근에 연 파일

- 현재 프로젝트에서 최근에 연 파일만 표시한다.
- 가장 최근에 연 파일부터 정렬한다.
- 파일을 선택하면 현재 새 탭을 해당 파일 탭으로 전환한다.
- 일정, 작업과 프로젝트 통계는 초기 범위에 포함하지 않는다.
- 최근에 연 파일이 없으면 목록 대신 빈 상태 안내를 표시한다.

## 표시 조건

- 탭 바의 `+`를 선택하면 새 탭 화면을 연다.
- 모든 콘텐츠 탭을 닫으면 새 탭 화면 하나를 남긴다.
- 프로젝트에 진입할 때 복원할 탭이 없으면 새 탭 화면을 연다.
