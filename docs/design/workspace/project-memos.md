# 메모 탭

사이드바의 `메모`는 프로젝트 메모와 파일 메모를 한곳에서 관리하는 별도 작업
화면을 연다. 화면 오른쪽 위의 범위 전환으로 두 목록을 바꾸며 한 화면에 동시에
표시하지 않는다.

## 메모 범위

| 구분 | 프로젝트 메모 | 파일 메모 |
| --- | --- | --- |
| 소속 | 현재 프로젝트 | 현재 파일 |
| 기본 진입점 | 사이드바 `메모` | 사이드바 `메모` 또는 파일 헤더 `메모` |
| 메모 탭 표시 | 정사각형 메모 카드 | 파일명과 정사각형 메모 카드 |
| 개수 | 여러 개의 카드 | 파일당 하나의 입력 영역 |
| 파일 전환 영향 | 영향 없음 | 선택한 파일에 맞춰 변경 |

- 파일 메모 패널의 `프로젝트 메모` 탭은 메모 탭과 같은 프로젝트 메모를 표시한다.
- 어느 진입점에서 수정해도 동일한 메모가 갱신된다.
- 프로젝트를 전환하면 해당 프로젝트의 메모만 표시한다.

## 열기와 탭

- 사이드바 `메모`를 선택하면 `메모` 탭을 연다.
- 프로젝트마다 메모 탭은 하나만 유지한다.
- 이미 열려 있으면 새 탭을 만들지 않고 기존 메모 탭으로 이동한다.
- 현재 탭이 새 탭 화면이면 새 탭을 추가하지 않고 메모 탭으로 전환한다.
- 메모 탭을 닫아도 메모 데이터는 삭제하지 않는다.

## 화면 구조

```text
탭 바                       [메모]
─────────────────────────────────────────────────────────
프로젝트 메모 선택: 메모  [+]     [프로젝트 메모 | 파일 메모]
파일 메모 선택:     메모           [프로젝트 메모 | 파일 메모]

[메모 카드]  [메모 카드]  [메모 카드]
[메모 카드]  [메모 카드]  …
```

- 화면 제목 옆의 `+`는 `프로젝트 메모`를 선택했을 때만 표시한다.
- 화면 오른쪽 끝에는 `프로젝트 메모`와 `파일 메모` 범위 전환을 둔다.
- 마지막으로 선택한 범위를 프로젝트별로 기억한다.
- `+`는 새 프로젝트 메모를 추가한다.
- 메모 카드는 가용 너비에 따라 열 수를 조절하되 읽기 순서는 왼쪽에서 오른쪽,
  위에서 아래로 유지한다.
- 메모가 많아져도 목록을 접거나 페이지를 나누거나 `더 보기`로 일부만 숨기지
  않는다. 카드 수만큼 목록을 아래로 늘리고 화면 전체를 세로 스크롤한다.
- 카드의 크기와 간격은 두 범위에서 동일하게 유지한다.

## 범위 전환

- `프로젝트 메모`를 선택하면 프로젝트 메모 카드만 표시한다.
- `파일 메모`를 선택하면 파일 메모가 있는 파일의 카드만 표시한다.
- 범위를 전환해도 반대쪽 메모의 작성 내용과 스크롤 위치를 유지한다.
- 각 범위 안에서는 최근 수정한 순서로 카드를 표시한다.

## 프로젝트 메모 카드

```text
┌────────────────────────┐
│                  [⋯]   │
│ 프로젝트 메모를         │
│ 바로 작성한다.           │
│                        │
│ 저장됨                  │
└────────────────────────┘
```

- 프로젝트 메모는 정사각형 카드로 표시한다.
- 별도의 읽기·편집 전환 없이 카드 안에서 바로 작성하고 수정한다.
- 카드 오른쪽 위에 항상 표시되는 `더보기` 버튼을 둔다.
- 프로젝트 메모의 `더보기`에는 `삭제`만 둔다.
- 본문이 카드 높이를 넘으면 카드 입력 영역 안에서 스크롤한다. 카드 자체를 접거나
  본문을 줄이지 않는다.
- `+`를 선택하면 목록 맨 앞에 빈 프로젝트 메모 카드를 추가하고 본문 입력으로
  포커스를 이동한다.

## 파일 메모 카드

```text
1장 · 유리 정원의 밤                         [⋯]
┌────────────────────────┐
│ 이 장면에서 유리 조각은   │
│ 주인공의 기억을 상징한다.  │
│                        │
│ 저장됨                  │
└────────────────────────┘
```

- 파일명을 메모 카드 위에 표시한다.
- 파일 메모도 별도의 편집 전환 없이 카드 안에서 바로 작성하고 수정한다.
- 카드 오른쪽 위의 `더보기`에는 `파일로 이동`과 `삭제`를 둔다.
- `파일로 이동`을 선택하면 해당 파일의 기존 탭으로 이동하거나 새 파일 탭을 연다.
- `삭제`는 파일이 아니라 파일에 연결된 메모만 삭제한다.
- 파일 메모는 각 파일당 하나만 존재하며 해당 파일 화면에서만 생성한다.
- 메모 탭의 파일 메모 범위에는 `+`나 다른 생성 행동을 제공하지 않는다.

## 빈 상태

저장된 프로젝트 메모가 없으면 카드 목록 대신 빈 상태를 표시한다.

```text
아직 프로젝트 메모가 없습니다
상단의 +를 눌러 프로젝트 전체에서 기억할 내용을 남겨 보세요.
```

- 파일 메모 범위가 비어 있으면 `아직 파일 메모가 없습니다`와 `파일을 열어 메모를
  작성하면 여기에 표시됩니다.`를 표시한다.
- 프로젝트 메모 빈 상태에서는 `+`와 범위 전환을 유지하고, 파일 메모 빈 상태에서는
  범위 전환만 유지한다.
- 검색이나 필터가 없는 화면이므로 빈 결과와 초기 빈 상태를 나누지 않는다.

## 작성

- 프로젝트 메모 범위의 `+`는 빈 정사각형 카드를 바로 만든다.
- 새 카드가 만들어지면 본문 입력으로 포커스를 이동한다.
- 입력을 시작하지 않은 빈 카드는 포커스가 카드 밖으로 이동하면 목록에서 제거한다.
- 여러 카드를 동시에 편집할 수 있으며 별도 `저장`과 `취소` 버튼을 두지 않는다.
- 파일 메모 생성은 파일 화면에서만 수행하며 메모 탭에서는 기존 파일 메모만
  편집한다.

## 편집

- 모든 메모 카드는 항상 직접 편집할 수 있는 입력 영역이다.
- 카드 본문을 선택하면 해당 위치에서 바로 커서를 표시한다.
- 별도의 `편집` 메뉴와 편집 상태 화면을 두지 않는다.
- 입력 중인 카드는 범위를 전환하거나 다른 카드로 이동해도 작성 내용을 유지한다.

## 저장 상태

- 입력이 멈춘 뒤 자동 저장하며 카드 아래쪽에 `저장 중`을 표시한다.
- 저장 중에도 입력을 막지 않으며 추가 입력이 있으면 현재 요청 뒤 최신 내용을 다시
  저장한다.
- 저장 성공 후 카드 아래쪽 상태를 `저장됨`으로 바꾼다.
- 저장 실패 시 입력값을 유지하고 카드 안에 오류 메시지와 `다시 시도`를 표시한다.
- `다시 시도`는 같은 입력값으로 저장을 다시 요청한다.
- 화면 전체를 오류 상태로 바꾸지 않는다. 다른 메모는 계속 탐색할 수 있다.

## 삭제

- 각 카드의 `더보기 > 삭제`를 선택하면 삭제 확인 대화상자를 연다.
- 대화상자에는 삭제할 메모의 첫 두 줄을 미리보기로 표시한다.
- 삭제를 확인하기 전에는 목록에서 카드를 제거하지 않는다.
- 삭제 성공 후 다음 카드의 본문으로 포커스를 이동한다. 다음 카드가 없으면 상단
  `+`로 이동하고 현재 범위의 빈 상태를 표시한다.
- 삭제 실패 시 대화상자를 유지하고 오류 메시지와 `다시 시도`를 표시한다.
- 삭제는 실행 취소를 제공하지 않는 영구 동작이다.

## 키보드와 포커스

- 메모 화면을 열면 화면 제목으로 포커스를 이동한다. 프로젝트 메모 범위의 탭 순서는
  `+`, 범위 전환, 카드이며 파일 메모 범위는 범위 전환, 카드 순서다.
- 카드의 탭 순서는 본문 입력, `더보기`다.
- 카드 메뉴는 `위/아래 방향키`로 항목을 이동하고 `Enter`로 실행하며 `Esc`로 닫는다.
- 범위 전환은 `왼쪽/오른쪽 방향키`로 선택을 바꾸고 선택한 범위 목록으로
  `Tab` 이동한다.
- 삭제 대화상자는 포커스를 내부에 가두고 `Esc`로 닫는다.
- 삭제 대화상자의 기본 포커스는 `취소`에 둔다.
