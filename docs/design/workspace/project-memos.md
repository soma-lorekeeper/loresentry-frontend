# 프로젝트 메모

사이드바의 `메모`는 현재 프로젝트 전체에서 공유하는 메모를 별도 작업 화면으로
연다. 특정 파일의 메모 패널과 달리 파일 선택 여부에 영향을 받지 않으며, 프로젝트
메모 전체를 탐색하고 관리하는 기본 진입점이다.

## 메모 범위

| 구분 | 프로젝트 메모 | 파일 메모 |
| --- | --- | --- |
| 소속 | 현재 프로젝트 | 현재 파일 |
| 진입점 | 사이드바 `메모` | 파일 헤더 `메모` |
| 표시 방식 | 중앙 작업 영역의 독립 탭 | 파일 콘텐츠 옆 또는 아래 패널 |
| 개수 | 여러 개의 카드 | 파일당 하나의 입력 영역 |
| 파일 전환 영향 | 영향 없음 | 선택한 파일에 맞춰 변경 |

- 파일 메모 패널의 `프로젝트 메모` 탭은 이 화면과 같은 프로젝트 메모를 표시한다.
- 어느 진입점에서 수정해도 동일한 메모가 갱신된다.
- 프로젝트를 전환하면 해당 프로젝트의 메모만 표시한다.

## 열기와 탭

- 사이드바 `메모`를 선택하면 `메모` 탭을 연다.
- 프로젝트마다 메모 탭은 하나만 유지한다.
- 이미 열려 있으면 새 탭을 만들지 않고 기존 메모 탭으로 이동한다.
- 현재 탭이 새 탭 화면이면 새 탭을 추가하지 않고 메모 탭으로 전환한다.
- 메모 탭을 닫아도 메모 데이터는 삭제하지 않는다.

## 화면 구조

```text
탭 바                       [메모]
─────────────────────────────────────────────────────────
프로젝트 메모   현재 프로젝트 이름   총 N개       [새 메모]

[메모 카드]  [메모 카드]  [메모 카드]
[메모 카드]  [메모 카드]  …
```

- 화면 제목 옆에 현재 프로젝트 이름을 표시해 파일 메모와 문맥을 구분한다.
- 메모 개수는 저장된 프로젝트 메모만 계산하며 작성 중인 초안은 제외한다.
- 목록은 최근 수정한 순서로 정렬한다.
- 메모 카드는 가용 너비에 따라 열 수를 조절하되 읽기 순서는 왼쪽에서 오른쪽,
  위에서 아래로 유지한다.
- 카드에는 본문, 마지막 수정 시각과 항상 표시되는 `더보기` 버튼을 둔다.
- 본문은 줄바꿈을 유지하며 카드 높이를 넘으면 카드 내부에서 스크롤하지 않고
  `더보기`로 접는다.

## 기본 상태

- 저장된 메모를 최근 수정한 순서로 표시한다.
- 카드 본문을 선택하면 해당 카드를 편집 상태로 전환한다.
- `더보기` 메뉴에는 `편집`과 `삭제`를 제공한다.
- 메모가 다른 진입점에서 갱신되면 현재 편집 중인 카드를 제외한 목록을 갱신한다.

## 빈 상태

저장된 프로젝트 메모가 없으면 카드 목록 대신 빈 상태를 표시한다.

```text
아직 프로젝트 메모가 없습니다
프로젝트 전체에서 기억할 내용을 남겨 보세요.
[첫 메모 작성]
```

- `첫 메모 작성`은 헤더의 `새 메모`와 같은 작성 상태를 연다.
- 검색이나 필터가 없는 화면이므로 빈 결과와 초기 빈 상태를 나누지 않는다.

## 작성

- `새 메모`를 선택하면 목록 맨 앞에 작성 카드를 추가한다.
- 작성 카드의 본문 입력으로 포커스를 이동한다.
- 한 번에 하나의 작성 카드만 열 수 있다.
- 작성 중 다시 `새 메모`를 선택하면 기존 작성 카드로 포커스를 이동한다.
- 작성 카드는 `취소`와 `저장` 행동을 제공한다.
- 공백만 있는 본문은 저장할 수 없다.
- `취소`하면 저장하지 않고 작성 카드를 제거하며 `새 메모`로 포커스를 돌린다.

## 편집

- 카드 본문 또는 `더보기 > 편집`을 선택하면 같은 위치에서 편집 상태로 전환한다.
- 한 번에 하나의 카드만 편집한다.
- 다른 카드 편집을 시작하려 하면 기존 변경을 유지한 채 기존 편집 카드로
  포커스를 이동한다.
- 편집 카드는 `취소`와 `저장` 행동을 제공한다.
- `취소`하면 마지막으로 저장된 본문을 복원하고 읽기 상태로 돌아간다.
- 저장이 완료되면 카드가 목록 맨 앞으로 이동하고 해당 카드의 `더보기`에
  포커스를 둔다.

## 저장 상태

- 저장을 시작하면 입력과 `취소`, `저장`을 비활성화하고 카드 안에 `저장 중`을
  표시한다.
- 저장 성공 후 수정 시각을 갱신하고 읽기 상태로 돌아간다.
- 저장 실패 시 입력값을 유지하고 카드 안에 오류 메시지와 `다시 시도`를 표시한다.
- 실패 상태의 `취소`는 마지막 저장 값으로 돌아가며, `다시 시도`는 같은 입력값으로
  저장을 다시 요청한다.
- 화면 전체를 오류 상태로 바꾸지 않는다. 다른 메모는 계속 탐색할 수 있다.

## 삭제

- `더보기 > 삭제`를 선택하면 삭제 확인 대화상자를 연다.
- 대화상자에는 삭제할 메모의 첫 두 줄을 미리보기로 표시한다.
- 삭제를 확인하기 전에는 목록에서 카드를 제거하지 않는다.
- 삭제 성공 후 다음 카드의 `더보기`로 포커스를 이동한다. 다음 카드가 없으면
  `새 메모`로 이동하고 빈 상태를 표시한다.
- 삭제 실패 시 대화상자를 유지하고 오류 메시지와 `다시 시도`를 표시한다.
- 삭제는 실행 취소를 제공하지 않는 영구 동작이다.

## 키보드와 포커스

- 메모 화면을 열면 화면 제목으로 포커스를 이동하고, 다음 `Tab`에서 `새 메모`에
  도달한다.
- 읽기 상태의 카드에서는 카드마다 `더보기`만 탭 순서에 포함한다.
- 카드 메뉴는 `위/아래 방향키`로 항목을 이동하고 `Enter`로 실행하며 `Esc`로 닫는다.
- 작성·편집 상태의 탭 순서는 본문 입력, `취소`, `저장`이다.
- 작성·편집 중 `Ctrl+Enter` 또는 `Cmd+Enter`는 저장하고 `Esc`는 취소한다.
- 삭제 대화상자는 포커스를 내부에 가두고 `Esc`로 닫는다.
- 삭제 대화상자의 기본 포커스는 `취소`에 둔다.
