# 파일 헤더

파일 헤더는 탭 바 아래에서 파일 단위 공통 기능을 제공하는 한 줄 영역이다.

## 구성

```text
                                      [메모] [버전] [내보내기] [잠금]
```

- 기능은 파일 헤더 오른쪽에 정렬한다.
- 왼쪽에는 경로, 파일명이나 다른 정보를 표시하지 않는다.
- 파일명은 본문 영역에서 편집한다.
- 저장 상태는 파일 헤더에 표시하지 않는다.

## 적용 대상

- 원고
- 설정
- 캐릭터
- 이벤트
- 조직
- 아이템
- 장소
- 세계관

새 탭, 그래프, 메모, 휴지통과 설정처럼 파일이 아닌 화면에는 파일 헤더를 표시하지 않는다.

## 공통 기능

- `메모`: 파일 헤더 아래 콘텐츠 영역의 오른쪽에 [파일 메모 패널](./file-memo-panel.md)을 연다.
- `버전`: 현재 파일의 [버전 기록](./version-history.md)을 연다.
- `내보내기`: 버튼 바로 아래에 내보내기 형식 목록을 연다.
- `잠금`: 현재 파일의 편집 잠금 상태를 전환한다.

네 기능은 파일 유형과 무관하게 같은 자리, 같은 순서로 둔다.

## 내보내기

`내보내기`를 선택하면 버튼 바로 아래에 형식 목록을 연다. 형식을 고르는 것이 곧
내보내기 실행이므로 중간 확인 단계를 두지 않는다.

```text
PDF로 내보내기
MS Word (.docx)
마크다운 (.md)
텍스트 (.txt)
한글 오피스 (.hwp)
```

- 목록은 `내보내기` 버튼의 오른쪽 끝에 맞춰 정렬한다.
- 목록에 구분선을 두지 않는다. 다섯 항목은 모두 같은 무게의 선택지이고 위험한
  항목이 없다.
- 파일 유형에 따라 목록을 바꾸지 않는다. 원고와 속성 문서 모두 같은 다섯 형식을
  제공한다.
- 다른 메뉴와 마찬가지로 배경 차단막을 쓰지 않는다. 목록이 열려 있는 동안 문서는
  그대로 보이고 편집 상태도 유지한다.
- 목록이 열려 있는 동안 `내보내기` 버튼을 활성 상태로 표시한다.
- 위·아래 방향키로 항목을 이동하고 `Enter`로 실행한다.
- `Esc`, 목록 밖 선택 또는 `내보내기` 재선택은 목록을 닫고 `내보내기`로 포커스를
  돌린다.

내보내기 목록이 열린 상태는 `lorekeeper.pen`의
`170 · Manuscript Editor · Export Menu Open`(`C4X6b1`)을 시각 기준으로 사용한다.

## 잠금

`잠금`은 현재 파일의 편집 가능 여부를 바꾸는 토글이다. **기본값은 풀린 상태다.**

| 상태 | 자물쇠 | 버튼 | 알림 |
| --- | --- | --- | --- |
| 편집 가능 (기본) | 열림 | 기본 | — |
| 편집 잠김 | 닫힘 | 활성 | `편집이 비활성화 되었습니다` |
| 잠금 해제 직후 | 열림 | 기본 | `편집이 활성화 되었습니다` |

- **잠금은 편집만 막고 읽기는 막지 않는다.** 본문과 속성은 그대로 보인다.
- 잠긴 동안 편집 도구와 본문 입력을 비활성으로 표시한다.
- 잠긴 동안에도 `메모`, `버전`, `내보내기`는 그대로 쓸 수 있다. 셋 다 파일 내용을
  고치지 않는다.
- 버전 기록의 `버전 저장`과 `이 버전으로 복원`은 잠긴 동안 실행할 수 없다.
- 잠금 상태는 파일마다 따로 기억하고 탭을 닫았다 열어도 유지한다.
- 잠금은 확인 대화상자를 거치지 않는다. 같은 버튼을 다시 눌러 바로 되돌릴 수 있다.

### 상태 변경 알림

상태가 바뀐 사실은 화면 하단 가운데에 잠시 떠올랐다 사라지는 알림으로 알린다.

- 알림은 중앙 작업 영역의 가로 가운데에 놓는다. 사이드바를 접어도 글이 놓인 자리
  위에 남는다.
- 알림에는 행동 버튼을 두지 않는다. 되돌릴 방법이 `잠금` 버튼 그 자체라 알림이
  행동을 다시 제안할 이유가 없다.
- 한 번에 하나만 표시한다. 잠금과 해제를 빠르게 반복하면 마지막 알림으로 바꾼다.
- 알림 문구는 `aria-live`로 한 번 전달한다.

잠긴 상태는 `lorekeeper.pen`의 `171 · Manuscript Editor · Locked`(`sr43z`), 잠금을
푼 직후는 `172 · Manuscript Editor · Unlocked`(`l829Nb`)을 시각 기준으로 사용한다.

## 컴포넌트 경계

- 파일 헤더는 네 버튼을 함께 갖는 한 컴포넌트다. 잠긴 상태만 별도 상태
  컴포넌트로 둔다.
- 내보내기 목록과 상태 변경 알림은 파일 헤더 밖의 독립 컴포넌트다. 둘 다 헤더
  경계를 넘어 떠 있고, 알림은 파일 헤더 말고 다른 곳에서도 쓸 자리다.
- 버전 기록 모달의 구조는 [버전 기록](./version-history.md)에서 정한다.

## Pencil 시각 참조

`lorekeeper.lib.pen`의 다음 컴포넌트를 `lorekeeper.pen`에서 `b:` 별칭으로
참조한다.

- 파일 헤더: `zdoWO` / `b:zdoWO`
- 메모 활성: `E5sHV` / `b:E5sHV`
- 잠긴 파일 헤더: `cKOUG` / `b:cKOUG`
- 내보내기 목록: `G2jwA` / `b:G2jwA`
- 상태 변경 알림: `pMUQM` / `b:pMUQM`

세 기능의 상태 전이는
[파일 헤더 동작 Workflow](../workflow/file-header-actions.md)를 따른다.
