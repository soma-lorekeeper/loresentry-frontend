# 파일 헤더

파일 헤더는 탭 바 아래에서 파일 단위 공통 기능을 제공하는 한 줄 영역이다.

## 구성

```text
                                      [메모] [버전] [내보내기] [잠금]
```

- 기능은 파일 헤더 오른쪽에 정렬한다.
- 왼쪽에는 경로, 파일명이나 다른 정보를 표시하지 않는다.
- 파일명은 본문 영역에서 편집한다.
- 저장 상태는 파일 헤더에 표시하지 않는다.

## 적용 대상

- 원고
- 설정
- 캐릭터
- 이벤트
- 조직
- 아이템
- 장소
- 세계관

새 탭, 그래프, 메모, 휴지통과 설정처럼 파일이 아닌 화면에는 파일 헤더를 표시하지 않는다.

## 공통 기능

- `메모`: 파일 헤더 아래 콘텐츠 영역의 오른쪽에 [파일 메모 패널](./file-memo-panel.md)을 연다.
- `버전`: 현재 파일의 버전 기록을 연다.
- `내보내기`: 현재 파일을 외부 형식으로 내보내는 흐름을 시작한다.
- `잠금`: 현재 파일의 편집 잠금 상태를 전환한다.

버전, 내보내기와 잠금의 표시 방식과 세부 동작은 별도로 결정한다.
