# 작업공간 도움말

사이드바의 `도움말`을 선택하면 현재 프로젝트 위에서 도움말 탭을 연다. 도움말은
프로젝트 데이터를 편집하지 않으며 사용 가이드 탐색과 피드백 보내기 진입을
제공한다.

## 도움말 기본 화면

```text
탭 바
──────────────────────────────────────────────────────────
도움말
Lorekeeper 사용 방법을 확인하거나 의견을 보내세요

[사용 가이드]
작업공간과 파일 편집 방법을 단계별로 확인합니다

[피드백 보내기 ↗]
문제와 개선 의견을 외부 피드백 폼으로 전달합니다
```

- 도움말 탭은 프로젝트마다 하나만 유지한다.
- 파일이 아니므로 파일 헤더를 표시하지 않는다.
- 사이드바의 `도움말`을 선택 상태로 표시한다.
- 두 진입 카드는 아이콘, 제목, 설명과 이동 방향을 함께 표시한다.

## 사용 가이드

사용 가이드는 도움말 탭 안에서 이동한다.

```text
[도움말로 돌아가기]  사용 가이드

가이드 검색

작업공간 시작하기
파일과 속성 문서
원고 작성
검색과 그래프
메모와 시간 흐름
휴지통과 복원
```

- 처음 열면 주제 목록과 검색을 표시한다.
- 주제를 선택하면 같은 탭에 문서 제목, 목차와 본문을 표시한다.
- `도움말로 돌아가기`는 도움말 기본 화면으로 이동한다.
- 가이드 내부 뒤로가기는 이전 주제 또는 주제 목록으로 이동하고 작업공간의 다른
  탭 상태를 바꾸지 않는다.
- 검색 결과가 없으면 검색어를 유지하고 `일치하는 가이드가 없습니다`를 표시한다.
- 가이드를 불러오지 못하면 `다시 시도`를 제공하고 선택한 주제를 유지한다.

## 피드백 보내기

- `피드백 보내기`는 외부 이동 아이콘과 `새 탭에서 열림` 접근 가능한 이름을
  제공한다.
- 선택하면 브라우저 새 탭에서 외부 피드백 폼을 열고 Lorekeeper 도움말 탭은
  유지한다.
- 외부 폼에는 로그인한 계정과 현재 프로젝트 식별자를 전달하지 않는다.
- 새 탭을 열 수 없으면 도움말 화면에 `피드백 페이지를 열지 못했습니다`와 `다시
  열기`, `링크 복사`를 표시한다.
- 사용자가 Lorekeeper로 돌아오면 `피드백 보내기` 카드로 포커스를 돌리고
  `피드백 페이지를 새 탭에서 열었습니다`를 상태 메시지로 알린다.

## 키보드 접근

- `Tab`은 도움말 탭의 뒤로가기, 검색, 주제와 피드백 순서로 이동한다.
- 가이드 주제 목록에서는 위·아래 방향키로 주제를 이동하고 `Enter`로 연다.
- 외부 링크는 아이콘뿐 아니라 텍스트로도 새 탭 이동을 알린다.
- 도움말에서 작업공간으로 돌아오면 마지막 활성 콘텐츠 탭의 마지막 포커스를
  복원한다.

## 컴포넌트 경계

버튼은 `Button / Icon Label`, 검색 입력은 `Search / Input`을 사용한다. 진입 카드,
가이드 주제, 검색 빈 상태와 외부 링크 상태는 도움말 화면 안에서만 쓰므로 화면
구조로 유지한다. 같은 구조가 다른 기능에도 필요해질 때 라이브러리 컴포넌트로
추출한다.

## Pencil 시각 참조

- `77 · Workspace Help · Default`: 도움말 진입과 작업공간 복귀
- `78 · Workspace Help · Guide Topics`: 가이드 검색과 주제 탐색
- `79 · Workspace Help · Guide Article`: 목차와 가이드 본문
- `80 · Workspace Help · Feedback Opened`: 외부 페이지 열기와 포커스 복원
- `81 · Workspace Help · Feedback Open Error`: 다시 열기와 링크 복사
- `89 · Workspace Help · Guide Search Empty`(`oAP5s`): 검색어 유지와 빈 결과 안내
- `90 · Workspace Help · Guide Load Error`(`i4zE54`): 선택 주제 유지와 다시 시도
