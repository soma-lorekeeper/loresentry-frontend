# AI 챗 보조 사이드 패널

AI 챗은 중앙 작업 영역 오른쪽에서 열리는 보조 사이드 패널이다. 탭 바의 AI 챗 버튼으로 열고 닫으며 패널 안에는 별도 닫기 버튼을 두지 않는다.

## 화면 구조

```text
┌──────────────────────────────┐
│ 현재 채팅 세션명 ▾    +   … │  세션 관리
├──────────────────────────────┤
│                              │
│ 대화 내역                    │
│                              │
├──────────────────────────────┤
│ 메시지 입력             전송 │
└──────────────────────────────┘
```

## 상단 세션 관리

- 상단 영역은 중앙 작업 영역의 탭 바와 같은 높이로 맞춘다.
- 현재 세션명을 선택하면 최근 사용 순으로 채팅 세션 목록을 표시한다.
- `+`를 선택하면 새 세션을 만들고 하단 메시지 입력란에 포커스한다.
- 첫 메시지를 기준으로 세션명을 자동 생성한다.
- 세션 더보기 메뉴에는 `이름 변경`과 `삭제`만 제공한다.
- 이름은 인라인으로 변경한다.
- 세션 삭제는 확인 후 실행한다.
- 현재 세션을 삭제하면 가장 최근 세션으로 이동하고, 남은 세션이 없으면 새 세션을 만든다.

## 대화 내역

- 선택한 세션의 사용자 메시지와 AI 응답을 시간순으로 표시한다.
- 메시지가 영역을 넘으면 대화 영역 내부를 세로로 스크롤한다.
- 세션을 전환하면 해당 세션의 대화 내역을 표시한다.

## 메시지 입력

- 메시지 입력란은 패널 하단에 고정한다.
- 입력란과 전송 버튼을 제공한다.
- 빈 메시지는 전송할 수 없다.

## 새 세션 빈 상태

- `+`를 선택하면 현재 패널 안에서 새 세션으로 전환한다.
- 새 세션의 대화 내역은 비우고 메시지 입력란에 키보드 포커스를 표시한다.
- 첫 메시지를 입력하기 전까지 전송 버튼은 비활성 상태로 유지한다.
- 첫 메시지를 보내면 해당 메시지를 기준으로 생성한 세션명을 상단에 표시한다.

## Pencil 시각 참조

- 기본 열린 상태: `11 · Manuscript Editor · AI Chat Open`(`iHWvC`)
- 세션 목록 열린 상태:
  `15 · Manuscript Editor · AI Chat · Session List Open`(`azx8U`)
- 세션 더보기 메뉴 열린 상태:
  `16 · Manuscript Editor · AI Chat · Session Menu Open`(`qJBRZ`)
- 세션 이름 인라인 변경 상태:
  `17 · Manuscript Editor · AI Chat · Session Rename`(`W0bpE`)
- 세션 삭제 확인 상태:
  `18 · Manuscript Editor · AI Chat · Delete Confirmation`(`V3QwF1`)
- 새 세션 빈 상태:
  `19 · Manuscript Editor · AI Chat · New Session Empty`(`RFf3u`)
