# 작업공간 그래프

사이드바의 `그래프`를 선택하면 현재 프로젝트 파일 사이의 명시된 관계를 탐색하는
그래프 탭을 연다. 그래프는 관계를 조회하는 화면이며 관계의 생성과 수정은 각 원본
파일에서 수행한다.

## 그래프 범위

- 현재 프로젝트에서 휴지통에 없는 원고, 설정, 캐릭터, 이벤트, 조직, 아이템, 장소와
  세계관 파일을 노드로 표시한다.
- 폴더는 노드로 만들지 않고 노드 상세 패널의 파일 경로로 표시한다.
- 파일의 구조화된 관계와 사용자가 만든 파일 참조만 연결로 표시한다.
- 단순히 같은 단어가 본문에 있다는 이유로 관계를 추론하지 않는다.
- 다른 프로젝트의 파일, 휴지통 항목과 프로젝트 설정은 표시하지 않는다.

## 화면 구조

```text
그래프                                      노드 수 · 관계 수
[노드 검색] [파일 유형] [관계 유형] [초기화]  [-] [100%] [+] [화면 맞춤]

┌──────────────────────── 그래프 캔버스 ────────────────────────┐
│ 노드 ── 관계 레이블 ──▶ 노드                                  │
│                                                               │
│ 범례                                      선택 노드 상세 패널  │
└───────────────────────────────────────────────────────────────┘
```

- 그래프 탭은 프로젝트마다 하나만 유지한다.
- 탭을 다시 열면 마지막 카메라 위치, 확대 비율, 필터, 검색어와 선택 노드를
  복원한다.
- 프로젝트를 바꾸면 이전 프로젝트의 그래프 상태를 섞지 않는다.

## 노드

모든 노드는 파일 이름, 파일 유형 아이콘과 파일 유형 레이블을 함께 표시한다. 파일
유형은 색상만으로 구분하지 않는다.

| 파일 유형 | 아이콘 |
| --- | --- |
| 원고 | `file-text` |
| 설정 | `notebook-tabs` |
| 캐릭터 | `user-round` |
| 이벤트 | `calendar-days` |
| 조직 | `users-round` |
| 아이템 | `gem` |
| 장소 | `map-pin` |
| 세계관 | `globe` |

- 긴 파일 이름은 한 줄 말줄임표로 줄이고 전체 이름은 상세 패널에서 제공한다.
- 연결이 없는 파일도 기본 그래프에 표시한다.
- 선택 노드는 강조 테두리와 선택 아이콘을 함께 사용한다.
- 선택 노드와 직접 연결된 노드·관계는 유지하고 나머지는 흐리게 표시한다.

## 연결

- 구조화된 방향 관계는 실선과 화살표로 방향을 표시한다.
- 파일 본문에서 사용자가 만든 참조는 점선과 화살표로 출처와 대상을 표시한다.
- 방향이 없는 동등 관계는 화살표 없는 실선으로 표시한다.
- 모든 연결은 선 위에 관계 역할 레이블을 표시한다.
- 같은 두 노드 사이에 여러 관계가 있으면 한 선으로 묶고 레이블에 관계 수를
  표시한다. 상세 패널에서 전체 관계를 확인한다.
- 필터로 한쪽 노드가 숨겨지면 해당 노드에 연결된 선도 숨긴다.

## 선택과 상세 패널

노드를 선택하면 그래프 오른쪽에 다음 정보를 표시한다.

```text
파일 유형 · 파일 이름
파일 > 상위 폴더 > 현재 폴더
직접 연결 수

들어오는 관계
나가는 관계

[파일 열기]
```

- 캔버스 빈 영역을 선택하거나 `Esc`를 누르면 선택을 해제한다.
- `파일 열기`는 기존 파일 탭이 있으면 해당 탭으로 이동하고, 없으면 새 탭으로
  연다.
- 그래프 탭은 닫지 않으며 돌아왔을 때 선택과 카메라 상태를 유지한다.

## 검색과 필터

### 노드 검색

- 그래프 검색은 파일 이름만 찾는다. 본문 검색은 [작업공간 검색](./search.md)을
  사용한다.
- 검색어와 일치한 노드를 강조하고 나머지 노드는 흐리게 표시한다.
- 첫 번째 일치 노드로 카메라를 이동하고 결과 수를 검색 입력 옆에 표시한다.
- 일치하는 노드가 없으면 캔버스 위에 `일치하는 노드가 없습니다`를 표시하고
  검색어를 유지한다.

### 필터

- 파일 유형과 관계 유형을 각각 복수 선택할 수 있다.
- 같은 필터 그룹 안에서는 하나라도 일치하면 표시하고, 서로 다른 그룹 사이는
  모두 일치해야 표시한다.
- `연결 없는 파일 표시`를 켜거나 끌 수 있다.
- 활성 필터 수를 필터 버튼에 표시한다.
- `초기화`는 검색어, 파일 유형, 관계 유형과 연결 없는 파일 조건을 모두 기본값으로
  되돌린다.
- 필터 결과가 없으면 `조건에 맞는 관계가 없습니다`와 `필터 초기화`를 표시한다.

## 확대·이동

- 처음 열 때 전체 노드가 보이도록 화면에 맞춘다.
- 확대 비율은 50%에서 200%까지 제공한다.
- `-`, `+` 버튼과 `Ctrl` 또는 `Cmd`를 누른 휠로 확대·축소한다.
- 빈 캔버스를 드래그하거나 트랙패드를 스크롤해 이동한다.
- `화면 맞춤`은 현재 필터로 표시된 모든 노드가 보이도록 카메라를 맞춘다.
- 확대 비율과 카메라 위치가 바뀌어도 선택과 필터는 유지한다.

## 키보드 접근

- `Tab`은 검색, 필터, 확대 도구, 그래프와 상세 패널 순서로 이동한다.
- 그래프에 진입하면 하나의 노드만 탭 순서에 포함하고 방향키로 공간상 가장 가까운
  노드로 이동한다.
- `Enter` 또는 `Space`는 포커스한 노드를 선택한다.
- `Esc`는 노드 선택을 해제하고 그래프에 포커스를 돌려준다.
- 연결선은 별도 탭 정지점으로 만들지 않고 선택 노드의 상세 패널 목록에서
  탐색한다.
- 도구 버튼과 노드는 접근 가능한 이름에 현재 값, 파일 유형 또는 관계 역할을
  포함한다.

## 상태

- 기본: 전체 그래프를 화면에 맞추고 선택·검색·필터가 없다.
- 선택: 선택 노드와 직접 관계를 강조하고 상세 패널을 연다.
- 필터: 활성 조건에 맞는 노드와 연결만 표시한다.
- 검색: 일치 노드와 결과 수를 표시하고 첫 결과에 포커스를 둔다.
- 빈 상태: 프로젝트에 표시할 관계가 없거나 현재 조건 결과가 없다.
- 오류: 그래프 데이터를 불러오지 못하면 `다시 시도`를 제공하고 검색·필터 상태를
  유지한다.

세부 상태 전환은 [작업공간 그래프 Workflow](../workflow/workspace-graph.md)를
따른다.
