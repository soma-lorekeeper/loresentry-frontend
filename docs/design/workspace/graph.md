# 작업공간 그래프

사이드바의 `그래프`를 선택하면 현재 프로젝트 파일 사이의 명시된 관계를 탐색하는
그래프 탭을 연다. 그래프는 관계를 조회하는 화면이며 관계의 생성과 수정은 각 원본
파일에서 수행한다.

## 그래프 범위

- 현재 프로젝트에서 휴지통에 없는 원고, 캐릭터, 이벤트, 조직, 아이템, 장소와
  세계관 파일을 노드로 표시한다.
- 폴더는 노드로 만들지 않는다. 파일 경로는 파일을 열어 확인한다.
- 파일의 구조화된 관계와 사용자가 만든 파일 참조만 연결로 표시한다.
- 단순히 같은 단어가 본문에 있다는 이유로 관계를 추론하지 않는다.
- 다른 프로젝트의 파일, 휴지통 항목과 프로젝트 설정은 표시하지 않는다.

## 화면 구조

```text
[에피소드 전체 ⌄]                    [-] [100%] [+] [화면 맞춤]
──────────────────────────────────────────────────────────
                                              [노드 검색] [분류 필터]

┌──────────────────────── 그래프 캔버스 ────────────────────────┐
│ 노드 ── 관계 레이블 ──▶ 노드                                  │
│                                                               │
│ 범례                                          선택 노드 패널  │
└───────────────────────────────────────────────────────────────┘
```

- 그래프 탭은 프로젝트마다 하나만 유지한다.
- 탭을 다시 열면 마지막 카메라 위치, 확대 비율, 필터, 검색어와 선택 노드를
  복원한다.
- 프로젝트를 바꾸면 이전 프로젝트의 그래프 상태를 섞지 않는다.

## 노드

모든 노드는 파일 이름, 파일 유형 아이콘과 파일 유형 레이블을 함께 표시한다. 파일
유형은 색상만으로 구분하지 않는다.

| 파일 유형 | 아이콘 | 색 |
| --- | --- | --- |
| 원고 | `file-text` | `color-node-manuscript` |
| 캐릭터 | `circle-user-round` | `color-node-character` |
| 장소 | `map-pin` | `color-node-place` |
| 조직 | `building-2` | `color-node-organization` |
| 아이템 | `package` | `color-node-item` |
| 이벤트 | `scroll` | `color-node-event` |
| 세계관 | `globe` | `color-node-worldview` |

**노드 색은 두 모드에서 다르게 만든다.** 다크는 무채색 명도 일곱 단계이고, 라이트는
그 계단 위에 색상을 얹는다. 어느 쪽이든 가장 옅은 단계가 캔버스 대비 3:1 을 지킨다 —
노드 안 아이콘을 캔버스 색으로 뚫기 때문에 그보다 낮으면 아이콘이 뭉개진다.

다크를 무채색으로 두는 것은 캔버스의 유일한 유채색을 즐겨찾기 별에 남겨 두기
위해서다. 라이트에서 색을 쓸 수 있는 것은 밝은 바탕에서는 별의 노란색이 노드 색과
같은 밝기 대역에 놓이지 않아 자리를 다투지 않기 때문이다.

**라이트의 일곱 색을 같은 밝기에 두지 않는다.** 노드는 지름 10~30px이고, 작은
시야각에서는 색상 변별력이 누구에게나 떨어진다. 등명도 집합은 그 조건에서 가장
약하므로 OKLCH 밝기를 0.46~0.62로 벌린다. 밝기 순서는 다크와 같게 두어(캐릭터가 가장
진하고 원고가 가장 옅다) 두 모드가 같은 계단을 공유하게 한다.

색상은 어느 모드에서도 유일한 단서가 아니다. 인접한 두 단계는 구분이 약하므로
분류를 실제로 알리는 것은 노드 안 아이콘이다.

즐겨찾기 노드에는 `color-favorite` 별 배지를 붙인다. 다크에서는 캔버스의 유일한
유채색이라 무채색 노드 사이에서 먼저 눈에 들고, 라이트에서는 노드 일곱 색보다 훨씬
밝아 같은 방식으로 떠오른다.

- 긴 파일 이름은 한 줄 말줄임표로 줄이고 전체 이름은 마우스를 올렸을 때 표시한다.
- 연결이 없는 파일도 기본 그래프에 표시한다.
- 노드를 선택하면 그래프를 그 노드와 직접 연결된 노드만으로 좁힌다. 화면에 남은
  것이 전부 관련된 것이므로 나머지를 흐리게 만들 일이 없다.
- 선택 노드는 원 바깥의 링으로만 표시한다. 이름은 다른 노드와 같은 굵기로 둔다.
- 링은 배경색 띠와 밝은 선을 겹쳐 두 겹으로 그린다. **다크에서** 노드 색이 무채색
  일곱 단계라 가장 밝은 캐릭터는 `color-text-primary` 와 같은 값인데, 링을 한 겹으로만
  그으면 그 분류에서 링이 원에 묻혀 사라진다. 라이트에서는 노드가 유채색이라 그
  충돌이 없지만, 띠는 두 모드에 같은 그림을 두려고 그대로 남긴다.
- 선택을 크기로 알리지 않는다. 반지름은 이미 이어진 수를 말하고 있어서, 선택이
  원을 키우면 큰 노드가 곧 많이 이어진 노드라는 읽기가 무너진다.
- 선택에 유채색을 쓰지 않는다. 링은 두 모드 모두 `color-text-primary` 다. 다크에서는
  캔버스의 유일한 유채색이 즐겨찾기 별이라 그 자리를 나눌 수 없고, 라이트에서는 노드가
  이미 일곱 색이라 여덟 번째 색을 더하면 무엇이 선택인지 흐려진다.

## 연결

- 구조화된 방향 관계는 실선과 화살표로 방향을 표시한다.
- 파일 본문에서 사용자가 만든 참조는 점선과 화살표로 출처와 대상을 표시한다.
- 방향이 없는 동등 관계는 화살표 없는 실선으로 표시한다.
- 구조화된 관계는 선 위에 관계 역할 레이블을 표시한다. 파일 본문에서 만들어진
  참조에는 역할 이름이 없다.
- 같은 두 노드 사이에 여러 관계가 있으면 한 선으로 묶고 레이블에 관계 수를
  표시한다. 노드 패널의 관계 칩에서 전체 관계를 확인한다.
- 필터로 한쪽 노드가 숨겨지면 해당 노드에 연결된 선도 숨긴다.

## 선택과 노드 패널

노드를 선택하면 그래프 오른쪽에 노드 패널을 연다. 패널은 선택한 노드 하나를
설명하는 상세 카드가 아니라, 선택 노드와 그에 직접 이어진 노드를 상자로 늘어놓은
목록이다. 캔버스는 무엇이 무엇과 이어져 있는지를 보여주지만 그 노드가 무엇인지는
이름 한 줄이 전부다. 나머지를 여기에서 읽는다.

```text
선택한 노드                                     ×
──────────────────────────────────────────────────
▏ⓒ 레나 아르벨
▏  타인의 기억이 남긴 방향을 감각으로 읽는 항해사

  ▤ 12화 · 균열의 밤
    [레나 아르벨]

  ⌂ 은빛 항해단
    [레나 아르벨]
    안전한 기억 항로를 확보하려는 항해 조직
```

- 머리에는 `선택한 노드`와 닫기만 둔다. 개수는 적지 않는다.
- 상자 하나는 파일 유형 아이콘, 파일 이름, 관계 칩, 설명 순으로 담는다.
- 파일 이름은 한 줄, 설명은 두 줄까지 보여 주고 넘치면 말줄임표로 줄인다.
- 설명은 속성 문서의 `설명` 값을 그대로 쓴다. 원고처럼 `설명`이 없는 파일은 설명
  줄 자체를 두지 않는다. 없는 값을 빈 칸으로 남기면 상자마다 높이가 들쭉날쭉해진다.
- 관계 칩은 주변 노드에만 붙이고 이어진 선택 노드의 이름만 적는다. 어떤 속성이
  그 연결을 만들었는지는 적지 않는다. 왼쪽 아이콘이 이미 분류를 말하고 있어
  `관련 원고` 같은 속성 이름은 같은 말을 한 번 더 하는 자리다.
- 선택 노드는 상자 왼쪽 2px 세로선으로만 구분한다. 색은 무채색이다.
  - `center` 같은 글자 라벨을 붙이지 않는다. 왼쪽 선이 이미 같은 말을 한다.
  - 바탕을 칠하지 않는다. 목록이 얼룩덜룩해져 어디를 읽어야 할지 흐려진다.
  - 오른쪽에 `원고`·`캐릭터` 같은 분류 글자를 두지 않는다. 왼쪽 아이콘이 이미
    말한 것을 한 번 더 말하는 자리다.
  - 별칭은 상자에 두지 않는다. 관계보다 부차적이고 좁은 폭에서 설명을 밀어낸다.
- 목록 순서는 선택 노드가 맨 앞이고, 그다음은 원고, 캐릭터, 이벤트, 조직, 아이템,
  장소와 세계관 순이다. 원고가 앞인 것은 어느 회차에 나오는지가 작가가 가장 먼저
  확인하는 것이기 때문이고, 장소와 세계관은 배경이라 뒤로 뺐다. 같은 분류 안에서는
  이어진 수가 많은 것이 먼저이고, 동률이면 이름순이라 순서가 흔들리지 않는다.
- 상자 자체가 버튼이다. 선택하면 그 파일로 이동한다. 기존 파일 탭이 있으면 해당
  탭으로 이동하고, 없으면 새 탭으로 연다. 패널 아래에 `파일 열기` 버튼을 따로 두지
  않는다. 여는 대상이 상자마다 다른데 버튼은 하나뿐이라 무엇을 여는지 매번 다시
  확인해야 한다.
- 캔버스 빈 영역을 선택하거나 `Esc`를 누르면 선택을 해제하고 패널을 닫는다.
- 그래프 탭은 닫지 않으며 돌아왔을 때 선택과 카메라 상태를 유지한다.

## 검색과 필터

### 노드 검색

- 그래프 검색은 파일 이름만 찾는다. 본문 검색은 [작업공간 검색](./search.md)을
  사용한다.
- 검색어와 일치한 노드를 강조하고 나머지 노드는 흐리게 표시한다.
- 첫 번째 일치 노드로 카메라를 이동한다.
- 일치하는 노드가 없으면 캔버스 위에 `일치하는 노드가 없습니다`를 표시하고
  검색어를 유지한다.

### 필터

- 파일 유형과 관계 유형을 각각 복수 선택할 수 있다.
- 같은 필터 그룹 안에서는 하나라도 일치하면 표시하고, 서로 다른 그룹 사이는
  모두 일치해야 표시한다.
- `초기화`는 검색어, 파일 유형, 관계 유형과 연결 없는 파일 조건을 모두 기본값으로
  되돌린다.
- 필터 결과가 없으면 `조건에 맞는 관계가 없습니다`와 `필터 초기화`를 표시한다.

## 확대·이동

- 처음 열 때 전체 노드가 보이도록 화면에 맞춘다.
- 확대 비율은 50%에서 200%까지 제공한다.
- `-`, `+` 버튼과 `Ctrl` 또는 `Cmd`를 누른 휠로 확대·축소한다.
- 빈 캔버스를 드래그하거나 트랙패드를 스크롤해 이동한다.
- `화면 맞춤`은 현재 필터로 표시된 모든 노드가 보이도록 카메라를 맞춘다.
- 확대 비율과 카메라 위치가 바뀌어도 선택과 필터는 유지한다.

## 키보드 접근

- `Tab`은 검색, 필터, 확대 도구, 그래프와 노드 패널 순서로 이동한다.
- 그래프에 진입하면 하나의 노드만 탭 순서에 포함하고 방향키로 공간상 가장 가까운
  노드로 이동한다.
- `Enter` 또는 `Space`는 포커스한 노드를 선택한다.
- `Esc`는 노드 선택을 해제하고 그래프에 포커스를 돌려준다.
- 연결선은 별도 탭 정지점으로 만들지 않고 노드 패널의 상자 목록에서
  탐색한다.
- 도구 버튼과 노드는 접근 가능한 이름에 현재 값, 파일 유형 또는 관계 역할을
  포함한다.

## 상태

- 기본: 전체 그래프를 화면에 맞추고 선택·검색·필터가 없다.
- 선택: 선택 노드와 직접 관계를 강조하고 노드 패널을 연다.
- 필터: 활성 조건에 맞는 노드와 연결만 표시한다.
- 검색: 일치 노드를 강조하고 첫 결과에 포커스를 둔다.
- 빈 상태: 프로젝트에 표시할 관계가 없거나 현재 조건 결과가 없다.
- 오류: 그래프 데이터를 불러오지 못하면 `다시 시도`를 제공하고 검색·필터 상태를
  유지한다.

세부 상태 전환은 [작업공간 그래프 Workflow](../workflow/workspace-graph.md)를
따른다.

## 수치 표시

노드 수, 관계 수, FPS 와 배치 시간은 화면에 두지 않는다. 그래프를 읽는 데
쓰이지 않고, 숫자가 늘 떠 있으면 무엇을 보는 화면인지 흐려진다.

## 캔버스 규격

치수는 text2graph 의 실측값을 따른다. 도구·패널의 높이와 글자는 pensiv 토큰 스케일로
내려 잡는다(그 둘이 부딪히면 pensiv 가 이긴다).

| 항목 | 값 |
| --- | --- |
| 노드 반지름 | 5〜15. 이어진 수가 많을수록 크고, **가장 큰 것이 가장 작은 것의 3배**다 |
| 노드 안 아이콘 | `반지름 × 1.2`. 반지름 9 미만이면 그리지 않는다 |
| 즐겨찾기 별 | 중심에서 `반지름 × 0.72` 만큼 오른쪽 위, 크기 `반지름 × 0.95` |
| 연결선 | 굵기 0.6 |
| 노드 이름 | `font-size-label`, 원 **아래 가운데**, 원에서 4.5 떨어져 |
| 배경 격자 | 20 단위, 5칸마다 한 단계 진하게 |
| 도구 버튼 | 28×28, **바탕 없음** (열려 있을 때만 눌린 바탕) |
| 도구 패널 | 최소 186 / 최대 260, 행 30, `모두 선택` 28 |
| 범례 | 좌하단 16/16, 점 7, `font-size-label` |
| 선택 링 | 배경색 띠 `반지름+1`, 밝은 선 `반지름+3`, 둘 다 굵기 2 |
| 노드 패널 | 280 |

### 배치는 재현하지 않는다

text2graph 는 노드를 해바라기 나선으로 깐다(간격 82 · 황금각). **와이어프레임은 그
기하를 따라 하지 않는다.** 목업에는 차수 데이터가 없어 그 식을 풀 값이 없고, 배치는
읽는 이가 확인할 대상도 아니다. 대신 둘만 지킨다 — 밀도가 고르게 퍼질 것, 크고 많이
이어진 노드가 가운데에 올 것.

## Pencil 시각 참조

- 기본: `145 · Graph · Default`
- 노드 선택: `146 · Graph · Node Selected`
- 분류 필터 열림: `147 · Graph · Filter Open`
- 노드 검색 열림: `148 · Graph · Search Open`

캔버스의 노드와 연결은 `docs/design/graph-canvas.js` 가 만든다.
