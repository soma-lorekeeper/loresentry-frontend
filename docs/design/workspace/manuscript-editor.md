# 원고 편집 영역

원고 파일은 공통 파일 헤더 아래에 편집 툴바와 작성 영역을 제공한다.

```text
탭 바
파일 헤더                     [메모] [버전] [내보내기] [잠금]
───────────────────────────────────────────────────────
편집 툴바
───────────────────────────────────────────────────────
작성 영역
```

## 편집 툴바

원고 본문의 입력과 서식에 필요한 기능만 제공한다.

```text
[되돌리기] [다시 실행]
│ [글꼴] [크기] [줄 간격]
│ [정렬] [내어쓰기] [들여쓰기]
│ [굵게] [기울임] [밑줄] [취소선]
│ [글머리 목록] [번호 목록]
│ [찾기·바꾸기]
                                      [글자 수]
```

- 편집 기록: 되돌리기, 다시 실행
- 집필 환경: 글꼴, 글자 크기, 줄 간격
- 문단: 왼쪽·가운데·오른쪽·양쪽 정렬, 내어쓰기와 들여쓰기
- 문자 서식: 굵게, 기울임, 밑줄, 취소선
- 목록: 글머리 목록, 번호 목록
- 탐색: 찾기·바꾸기
- 상태: 공백 포함·제외 글자 수

툴바는 파일 헤더 아래에 고정한다. 파일 메모 패널이나 AI 챗 패널 때문에 너비가 줄면 낮은 우선순위 기능부터 `더보기`에 접는다.

초기 툴바에는 다음 항목을 포함하지 않는다.

- 저장 버튼: 자동 저장을 사용한다.
- 색상과 형광펜
- 이미지와 표 삽입
- AI 기능: 탭 바의 AI 챗 버튼을 사용한다.
- 메모, 버전, 내보내기와 잠금: 파일 헤더에서 제공한다.

## 작성 영역

작성 영역은 Pensiv처럼 제목 아래에 일반 본문을 두는 구조를 사용한다.

```text
원고 제목

일반 본문
```

- 제목과 본문을 작성 영역 안에서 직접 편집한다.
- 편집 툴바의 본문 서식 기능은 일반 본문에 적용한다.
- 제목의 입력 규칙과 작성 영역의 너비·여백은 별도로 결정한다.

## 파일 메모가 열린 상태

파일 메모는 파일 헤더 아래 오른쪽에서 열리므로 편집 툴바와 작성 영역 옆에 배치된다.

```text
파일 헤더
───────────────────────────────────────────────────────
편집 툴바와 작성 영역                    │ 파일 메모 패널
```
