# 파일·폴더 휴지통

사이드바의 `휴지통`을 선택하면 중앙 작업 영역에 휴지통 탭을 연다. 휴지통에는 현재 프로젝트에서 삭제한 파일과 폴더를 표시한다.

각 항목에는 다음 행동을 제공한다.

```text
복원
영구 삭제
```

- `복원`은 파일이나 폴더를 삭제 전 위치로 되돌린다.
- 삭제 전 상위 폴더가 존재하지 않으면 파일 섹션 최상위로 복원한다.
- `영구 삭제`는 확인 후 실행하며 되돌릴 수 없다.
- 다른 프로젝트에서 삭제한 항목은 표시하지 않는다.

세부 이동과 탭 처리는 [파일·폴더 휴지통 Workflow](../workflow/workspace-trash.md)를 따른다.
