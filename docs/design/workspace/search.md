# 작업공간 검색

사이드바의 `검색`을 선택하면 현재 프로젝트의 파일을 찾는 검색 탭을 연다. 검색은
프로젝트마다 하나의 탭만 유지하며, 이미 열려 있으면 기존 검색 탭으로 이동한다.

## 검색 범위

- 현재 프로젝트의 휴지통에 없는 파일을 대상으로 한다.
- 원고, 캐릭터, 장소, 조직, 아이템, 이벤트와 세계관 파일의 이름과 검색
  가능한 본문을 찾는다.
- 폴더 이름은 검색 결과로 만들지 않고 결과 파일의 위치를 설명하는 경로로
  표시한다.
- 다른 프로젝트의 파일, 휴지통 항목과 프로젝트 설정은 검색하지 않는다.

## 화면 구조

```text
검색

[현재 프로젝트에서 검색                                  ]

상태 안내 또는 검색 결과
```

검색 결과 항목은 다음 정보를 같은 순서로 표시한다.

```text
파일 유형 아이콘 · 파일 이름                       파일 유형
일치한 본문 한 줄
파일 > 상위 폴더 > 현재 폴더
```

- 파일 이름과 일치한 경우에도 본문 요약 대신 파일 이름 일치임을 알려준다.
- 본문과 일치한 경우 검색어가 포함된 한 줄을 보여준다.
- 최상위 파일은 위치를 `파일`로 표시한다.
- 경로는 결과가 속한 위치를 설명하는 정보이며 검색 결과 안에서 이동 링크로
  사용하지 않는다.

## 상태

### 초기

- 검색어가 비어 있을 때 검색 입력에 포커스를 둔다.
- 결과 영역에는 `현재 프로젝트의 파일을 검색하세요`와 검색 범위를 안내한다.

### 입력

- 공백을 제외한 검색어가 생기면 현재 입력값을 기준으로 검색한다.
- 결과를 가져오는 동안 기존 결과를 새 검색 결과로 오인하지 않도록 로딩 상태를
  표시한다.
- 입력을 모두 지우면 초기 상태로 돌아간다.

### 결과 있음

- 검색어와 결과 수를 함께 표시한다.
- 파일 이름, 본문 일치 내용, 파일 유형과 폴더 경로를 구분해 보여준다.
- 결과는 관련도가 높은 순서로 표시하고, 관련도가 같으면 최근 수정한 파일을 먼저
  표시한다.

### 결과 없음

- 검색어를 유지하고 `검색 결과가 없습니다`를 표시한다.
- 다른 검색어를 입력하도록 안내하며 별도의 빈 결과 항목은 만들지 않는다.

### 오류

- 검색 요청이 실패하면 검색어를 유지하고 `검색 결과를 불러오지 못했습니다`를
  표시한다.
- `다시 시도`는 같은 검색어로 검색을 다시 실행한다.
- 오류 상태에서 검색어를 바꾸면 변경한 검색어로 새 검색을 실행한다.

세부 탭 전환과 포커스 이동은
[작업공간 검색 Workflow](../workflow/workspace-search.md)를 따른다.

## Pencil 시각 기준

검색 화면은 `lorekeeper.pen`의 다음 프레임을 시각 기준으로 사용한다.

- 초기: `38 · Workspace · Search · Default`(`KVKU8`)
- 입력: `39 · Workspace · Search · Input`(`GqRoM`)
- 결과 있음: `40 · Workspace · Search · Results`(`sj1mq`)
- 결과 없음: `41 · Workspace · Search · No Results`(`gEeY1`)
- 오류: `42 · Workspace · Search · Error`(`fJm26`)

화면은 `lorekeeper.lib.pen`의 `Search / Input`(`h8n7ia`)과
`Search / Result Row`(`YVBp8`)를 각각 `b:h8n7ia`, `b:YVBp8`로 참조한다.
