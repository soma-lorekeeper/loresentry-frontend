# 메모 패널

파일 헤더의 `메모`를 선택하면 파일 헤더 아래 영역의 오른쪽에서 메모 패널이 나타난다.

```text
탭 바
파일 헤더                                      [메모 활성]
─────────────────────────────────────────────────────────
파일 유형별 콘텐츠 영역                │ 메모 패널
                                       │
```

- 메모 패널은 작품 전체 메모와 현재 파일 메모를 전환해서 표시한다.
- 패널은 탭 바나 파일 헤더를 덮지 않고 파일 헤더 아래에서 시작한다.
- 작업공간 전체 오른쪽에 열리는 AI 챗 보조 사이드 패널과는 별개의 영역이다.

## 패널 헤더

패널 헤더 왼쪽에는 닫기 버튼과 `메모` 제목을 배치한다. 오른쪽에는 패널 배치 전환을 둔다.

- 아래 배치: 메모 패널을 편집 영역 아래에 펼친다.
- 오른쪽 배치: 메모 패널을 편집 영역 오른쪽에 붙인다.

닫기 버튼을 선택하면 파일 헤더의 `메모` 버튼으로 키보드 포커스를 돌려보낸다.

## 메모 범위 전환

패널 헤더 바로 아래에 `작품 메모`와 `원고 메모` 탭을 둔다. 두 메모를 동시에 나열하지 않고 선택한 탭의 내용만 표시한다.

- `작품 메모`: 작품 전체에서 공유하는 메모 카드 목록을 표시하며 탭 행 오른쪽에 `+`를 둔다.
- `원고 메모`: 현재 원고 파일에만 연결된 단일 메모 입력 영역을 표시한다.
- 마지막으로 선택한 탭을 기억한다.

## 패널 배치

- `오른쪽`을 선택하면 편집기 오른쪽에 세로 패널로 붙인다.
- `아래`를 선택하면 편집기 너비 전체를 사용하는 가로 패널로 붙인다.
- 아래 배치에서도 헤더와 메모 범위 탭의 순서는 유지한다.
- 아래 배치의 작품 메모 카드는 한 행에 여러 장을 놓아 가로로 훑을 수 있게 한다.

## 작품 메모

- 작품 전체에서 공유하는 메모를 표시한다.
- 이 탭을 선택했을 때만 `+`를 탭 행 오른쪽에 표시한다.
- 각 작품 메모는 독립된 사각형 카드로 표시한다.
- 카드 오른쪽 위의 `×`를 선택하면 해당 작품 메모를 삭제한다.
- `+`를 선택하면 새 작품 메모 카드를 목록 맨 위에 추가한다.

## 원고 메모

- 현재 원고 파일에서만 사용하는 메모를 표시한다.
- `원고 메모` 섹션 안에 별도 카드 없이 직접 입력한다.
- 현재 원고 파일명을 함께 표시해 메모가 연결된 문맥을 알 수 있게 한다.

## 미정 항목

- 오른쪽에 붙였을 때의 너비 조절 방식
- 아래 배치의 높이 조절 방식
- AI 챗 패널과 메모 패널의 동시 표시 여부
