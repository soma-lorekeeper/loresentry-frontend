# 메모 패널

파일 헤더의 `메모`를 선택하면 파일 헤더 아래 영역의 오른쪽에서 메모 패널이 나타난다.

```text
탭 바
파일 헤더                                      [메모 활성]
─────────────────────────────────────────────────────────
파일 유형별 콘텐츠 영역                │ 메모 패널
                                       │
```

- 메모 패널은 프로젝트 전체 메모와 현재 파일 메모를 전환해서 표시한다.
- 패널은 탭 바나 파일 헤더를 덮지 않고 파일 헤더 아래에서 시작한다.
- 작업공간 전체 오른쪽에 열리는 AI 챗 보조 사이드 패널과는 별개의 영역이다.

## 패널 헤더

패널 헤더 왼쪽에는 닫기 버튼과 `메모` 제목을 배치한다. 오른쪽에는 패널 배치 전환을 둔다.

- 아래 배치: 메모 패널을 편집 영역 아래에 펼친다.
- 오른쪽 배치: 메모 패널을 편집 영역 오른쪽에 붙인다.

닫기 버튼을 선택하면 파일 헤더의 `메모` 버튼으로 키보드 포커스를 돌려보낸다.

패널을 닫은 뒤 포커스가 돌아온 상태는 `lorekeeper.pen`의
`26 · Manuscript Editor · Memo Closed · Focus Returned`(`sVEg1`)을 시각
기준으로 사용한다.

## 메모 범위 전환

패널 헤더 바로 아래에 `프로젝트 메모`와 `원고 메모` 탭을 둔다. 두 메모를 동시에 나열하지 않고 선택한 탭의 내용만 표시한다.

- `프로젝트 메모`: 프로젝트 전체에서 공유하는 메모 카드 목록을 표시하며 탭 행 오른쪽에 `+`를 둔다.
- `원고 메모`: 현재 원고 파일에만 연결된 단일 메모 입력 영역을 표시한다.
- 마지막으로 선택한 탭을 기억한다.

## 패널 배치

- `오른쪽`을 선택하면 편집기 오른쪽에 세로 패널로 붙인다.
- `아래`를 선택하면 편집기 너비 전체를 사용하는 가로 패널로 붙인다.
- 아래 배치에서도 헤더와 메모 범위 탭의 순서는 유지한다.
- 아래 배치의 프로젝트 메모 카드는 한 행에 여러 장을 놓아 가로로 훑을 수 있게 한다.

### 크기 조절

- 오른쪽 패널은 왼쪽 경계의 세로 조절 손잡이를 드래그해 너비를 바꾼다.
- 오른쪽 패널의 기본 너비는 `360px`, 최소 너비는 `320px`, 최대 너비는 파일
  콘텐츠 영역의 `45%`다.
- 아래 패널은 위쪽 경계의 가로 조절 손잡이를 드래그해 높이를 바꾼다.
- 아래 패널의 기본 높이는 `300px`, 최소 높이는 `240px`, 최대 높이는 파일
  콘텐츠 영역의 `50%`다.
- 조절 손잡이에 키보드 포커스를 둘 수 있고 방향키로 `8px`, `Shift`와 방향키로
  `32px`씩 조절한다.
- 현재 크기와 최소·최대 도달 상태는 수치와 접근 가능한 이름으로 알린다.
- 오른쪽 너비와 아래 높이는 서로 독립적으로 프로젝트·사용자 단위로 기억한다.

### AI 챗과 동시 표시

- AI 챗과 메모 패널은 동시에 열 수 있다.
- AI 챗은 작업공간 오른쪽을 사용하므로 오른쪽 메모 패널과 같은 경계를 동시에
  차지하지 않는다.
- 오른쪽 메모 패널이 열린 상태에서 AI 챗을 열면 메모 패널을 임시로 아래 배치로
  전환하고, AI 챗을 닫으면 사용자가 마지막으로 선택한 오른쪽 배치와 너비를
  복원한다.
- AI 챗이 열린 동안 사용자가 메모를 아래 배치로 직접 고정하면 AI 챗을 닫아도
  아래 배치를 유지한다.
- 패널을 닫아도 선택한 메모 범위, 작성 중인 입력과 마지막 크기를 유지한다.

### 좁은 작업 영역

- 두 패널을 표시한 결과 파일 콘텐츠의 가로 공간이 `560px`보다 작거나 세로
  공간이 `320px`보다 작아지면 동시 표시하지 않는다.
- 이때 새로 연 패널을 표시하고 기존 패널은 접은 상태로 전환한다. 접힌 패널의
  탭·입력·크기는 유지한다.
- 파일 헤더에 `작업 영역이 좁아 메모를 접었습니다` 또는 `AI 챗을 접었습니다`를
  표시하고 `다시 열기`를 제공한다.
- 공간이 다시 넓어져도 접힌 패널을 자동으로 열지 않는다.

## 프로젝트 메모

- 프로젝트 전체에서 공유하는 메모를 표시한다.
- 이 탭을 선택했을 때만 `+`를 탭 행 오른쪽에 표시한다.
- 각 프로젝트 메모는 독립된 사각형 카드로 표시한다.
- 카드의 항상 표시되는 `더보기`에서 편집과 삭제를 제공한다.
- 삭제는 확인 대화상자를 거친다.
- `+`를 선택하면 새 프로젝트 메모 카드를 목록 맨 위에 추가한다.
- 프로젝트 메모 화면과 같은 데이터를 사용하며 세부 동작은
  [프로젝트 메모](./project-memos.md)를 따른다.

## 원고 메모

- 현재 원고 파일에서만 사용하는 메모를 표시한다.
- `원고 메모` 섹션 안에 별도 카드 없이 직접 입력한다.
- 현재 원고 파일명을 함께 표시해 메모가 연결된 문맥을 알 수 있게 한다.

패널 배치와 동시 표시의 상태 전이는
[메모 패널 배치 Workflow](../workflow/memo-panel-layout.md)를 따른다.
