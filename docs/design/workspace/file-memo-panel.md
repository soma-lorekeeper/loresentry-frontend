# 파일 메모 패널

파일 헤더의 `메모`를 선택하면 파일 헤더 아래 영역의 오른쪽에서 파일 메모 패널이 나타난다.

```text
탭 바
파일 헤더                                      [메모 활성]
─────────────────────────────────────────────────────────
파일 유형별 콘텐츠 영역                │ 파일 메모 패널
                                       │
```

- 파일 메모 패널은 현재 파일에 연결된 메모를 표시한다.
- 패널은 탭 바나 파일 헤더를 덮지 않고 파일 헤더 아래에서 시작한다.
- 작업공간 전체 오른쪽에 열리는 AI 챗 보조 사이드 패널과는 별개의 영역이다.
- 패널의 닫기 방식, 너비 조절과 AI 챗 패널과의 동시 표시 여부는 추후 결정한다.
