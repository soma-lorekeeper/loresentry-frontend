# 중앙 작업 영역 탭

중앙 작업 영역은 브라우저처럼 여러 작업을 동시에 열어 두고 전환할 수 있는 탭 방식을 사용한다.

## 탭 바

```text
[사이드바 열기·닫기] [열린 탭 ………………] [+ 새 탭] [AI 챗]
```

- 사이드바 열기·닫기 버튼은 탭 바 왼쪽에 배치한다.
- 사이드바를 닫아도 열기 버튼은 탭 바에 유지한다.
- AI 챗 버튼은 탭 바 오른쪽에 배치한다.
- AI 챗 버튼은 중앙 작업 영역 오른쪽의 보조 사이드 패널을 열고 닫는다.
- 패널이 열려 있으면 AI 챗 버튼을 활성 상태로 표시한다.
- `+` 버튼을 선택하면 새 탭 화면을 연다.

## 탭 대상

- 원고, 설정, 캐릭터, 이벤트, 조직, 아이템, 장소, 세계관 파일
- 그래프
- 메모
- 휴지통
- 설정
- 도움말

폴더는 탭으로 열지 않고 사이드바에서 펼치거나 접는다.

## 탭 동작

- 콘텐츠를 선택하면 새 탭으로 연다.
- 현재 선택한 탭이 새 탭 화면이면 새 탭을 추가하지 않고 해당 탭에 콘텐츠를 연다.
- 이미 열린 콘텐츠를 다시 선택하면 기존 탭으로 이동한다.
- 하나의 콘텐츠는 하나의 탭만 가질 수 있다.
- 즐겨찾기 바로가기와 원본 파일은 같은 탭을 사용한다.
- 탭에는 콘텐츠 유형 아이콘, 이름, 닫기 버튼을 표시한다.
- 탭을 드래그 앤 드롭해 순서를 바꿀 수 있다.
- 탭이 탭 바의 너비를 넘으면 가로 스크롤로 탐색한다.
- 탭을 닫아도 원본 콘텐츠는 삭제하지 않는다.
- 콘텐츠는 자동 저장하며 탭을 닫을 때 저장 확인 창을 표시하지 않는다.
- 모든 콘텐츠 탭을 닫으면 새 탭 화면 하나를 자동으로 남긴다.

## 복원

- 열린 탭의 목록과 순서, 마지막 활성 탭을 프로젝트별로 저장한다.
- 프로젝트에 다시 진입하면 저장한 탭 상태를 복원한다.
- 복원할 탭이 없으면 새 탭 화면 하나를 연다.
- 다른 프로젝트의 탭은 현재 프로젝트에 섞어서 표시하지 않는다.

## Pencil 시각 참조

- 탭이 탭 바 너비를 넘는 상태는
  `24 · Workspace · Tabs Overflow`(`Q6a0ol`)을 기준으로 한다.
- 탭을 끌어 순서를 바꾸는 상태는
  `25 · Workspace · Tab Reorder`(`TeBAK`)을 기준으로 한다.

## 좌우 분할 보기

문서 두 장을 나란히 놓고 함께 읽는 보기다. 설정 문서를 열어 둔 채 원고를 고치거나,
두 인물 문서를 견주는 자리에서 쓴다.

```text
┌ 사이드바 220 ┬───── pane ─────┬───── pane ─────┐
│              │ 탭 바 42        │ 탭 바 42        │
│              ├────────────────┼────────────────┤
│              │ 에디터 바 42    │ 에디터 바 42    │
│              ├────────────────┼────────────────┤
│              │ 문서            │ 문서            │
└──────────────┴────────────────┴────────────────┘
```

- **각 pane 이 제 탭 바와 에디터 바를 갖는다.** 탭 바를 하나만 두고 아래를 나누면
  어느 탭이 어느 쪽 문서인지 알 수 없다.
- 두 pane 사이는 1px 선으로 가르고, 폭은 절반씩 나눠 갖는다.
- 문서 콘텐츠 폭은 `min(672, pane − 56)` 이다. 1440 화면에서 pane 이 약 609 이므로
  콘텐츠는 553 이 된다 — 단일 보기(672)보다 좁지만 좌우 여백 28 은 그대로다.
- **좁아진 pane 에서 편집 바는 도구를 덜어내지 않고 가로로 넘긴다.** 어느 도구가
  남고 어느 도구가 사라지는지를 폭이 정하면, 같은 문서를 단일 보기와 분할 보기에서
  번갈아 볼 때마다 도구 자리가 바뀐다. 자리는 그대로 두고 보이는 범위만 옮긴다.
- 넘치는 쪽 가장자리에는 편집 바 바탕색으로 사라지는 64px 그라디언트를 덮는다.
  글자가 잘린 단면으로 끝나면 화면이 깨진 것처럼 보이지만, 흐려지며 사라지면 더
  있다는 뜻으로 읽힌다. 마지막 8px 은 완전히 불투명해 잘린 획이 남지 않는다.
- 그라디언트는 `color-surface-default` 로 수렴한다. 밝은 색을 직접 칠하지 않으므로
  dark 와 light 에서 각각 제 바탕으로 사라진다.
- 넘긴 범위는 드래그로 옮긴다. 화살표 버튼을 두지 않는 것은 탭 바와 달리 편집 바는
  한 번에 여러 도구를 지나쳐 가는 자리라, 한 칸씩 미는 버튼이 맞지 않기 때문이다.

기준 화면은 `167 · Workspace · Split View · Two Documents`(`pQgTr`) 다.
