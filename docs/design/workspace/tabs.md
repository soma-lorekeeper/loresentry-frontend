# 중앙 작업 영역 탭

중앙 작업 영역은 브라우저처럼 여러 작업을 동시에 열어 두고 전환할 수 있는 탭 방식을 사용한다.

## 탭 바

```text
[사이드바 열기·닫기] [열린 탭 ………………] [+ 새 탭] [AI 챗]
```

- 사이드바 열기·닫기 버튼은 탭 바 왼쪽에 배치한다.
- 사이드바를 닫아도 열기 버튼은 탭 바에 유지한다.
- AI 챗 버튼은 탭 바 오른쪽에 배치한다.
- AI 챗 버튼은 중앙 작업 영역 오른쪽의 보조 사이드 패널을 열고 닫는다.
- 패널이 열려 있으면 AI 챗 버튼을 활성 상태로 표시한다.
- `+` 버튼을 선택하면 새 탭 화면을 연다.

## 탭 대상

- 원고, 설정, 캐릭터, 이벤트, 조직, 아이템, 장소, 세계관 파일
- 그래프
- 메모
- 휴지통
- 설정

폴더는 탭으로 열지 않고 사이드바에서 펼치거나 접는다.

## 탭 동작

- 콘텐츠를 선택하면 새 탭으로 연다.
- 현재 선택한 탭이 새 탭 화면이면 새 탭을 추가하지 않고 해당 탭에 콘텐츠를 연다.
- 이미 열린 콘텐츠를 다시 선택하면 기존 탭으로 이동한다.
- 하나의 콘텐츠는 하나의 탭만 가질 수 있다.
- 즐겨찾기 바로가기와 원본 파일은 같은 탭을 사용한다.
- 탭에는 콘텐츠 유형 아이콘, 이름, 닫기 버튼을 표시한다.
- 탭을 드래그 앤 드롭해 순서를 바꿀 수 있다.
- 탭이 탭 바의 너비를 넘으면 가로 스크롤로 탐색한다.
- 탭을 닫아도 원본 콘텐츠는 삭제하지 않는다.
- 콘텐츠는 자동 저장하며 탭을 닫을 때 저장 확인 창을 표시하지 않는다.
- 모든 콘텐츠 탭을 닫으면 새 탭 화면 하나를 자동으로 남긴다.

## 복원

- 열린 탭의 목록과 순서, 마지막 활성 탭을 프로젝트별로 저장한다.
- 프로젝트에 다시 진입하면 저장한 탭 상태를 복원한다.
- 복원할 탭이 없으면 새 탭 화면 하나를 연다.
- 다른 프로젝트의 탭은 현재 프로젝트에 섞어서 표시하지 않는다.

## 초기 범위 제외

- 분할 화면
- 임시 미리보기 탭
