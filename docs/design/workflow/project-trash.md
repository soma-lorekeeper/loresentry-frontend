# 프로젝트 휴지통 Workflow

## 휴지통으로 이동

```text
프로젝트 목록
→ 프로젝트 더보기
→ 휴지통으로 이동
→ 이동 확인
→ 프로젝트 목록에서 제거
→ 프로젝트 휴지통에 보관
```

```text
이동 확인
├─ 취소 또는 Esc → 카드 메뉴의 휴지통 이동 행동
└─ 휴지통으로 이동 → 이동 중
   ├─ 성공 → 목록에서 카드 제거 → 복원 가능 안내
   └─ 실패 → 대화상자와 목록 유지 → 다시 시도 또는 취소
```

- 이동 확인에는 대상 프로젝트 제목과 목록·작업공간에서 제거된다는 영향을 표시한다.
- 프로젝트의 파일과 설정은 휴지통에 보존하며 복원 전까지 작업공간에 진입할 수 없다.
- 이동 중에는 대화상자를 닫지 않고 취소와 확인 행동을 잠가 중복 요청을 막는다.
- 실패하면 사용자가 선택한 프로젝트와 목록 순서를 바꾸지 않는다.
- 성공 안내는 프로젝트 휴지통에서 복원할 수 있음을 포함한다.

## 복원

```text
프로젝트 휴지통
→ 프로젝트 복원
→ 복원 중
├─ 성공 → 휴지통 목록에서 제거 → 복원 완료 안내
│  ├─ 프로젝트 목록에서 보기 → 프로젝트 목록의 복원된 카드
│  └─ 현재 화면 유지 → 다음 휴지통 항목 또는 빈 상태
└─ 실패 → 대상과 목록 유지 → 다시 시도
```

- 복원은 되돌릴 수 있는 행동이므로 별도 확인 대화상자를 열지 않는다.
- 복원 중에는 대상 프로젝트의 행동만 잠그고 `복원 중…`으로 요청을 알린다.
- 실패하면 대상과 목록 순서를 유지하며 같은 항목에서 재시도할 수 있다.
- 성공하면 휴지통 목록에서 대상을 제거하고 프로젝트 목록에서 확인할 수 있는 이동 행동을 제공한다.
- 성공 후 현재 화면에 머물면 다음 항목의 `복원`으로 포커스를 옮긴다. 남은 항목이 없으면 빈 상태의 목록 복귀 행동으로 옮긴다.

## 영구 삭제

```text
프로젝트 휴지통
→ 영구 삭제
→ 대상 프로젝트와 복구 불가 안내 확인
├─ 취소 또는 Esc → 대상 항목의 영구 삭제 행동
└─ 영구 삭제 → 삭제 중
   ├─ 성공 → 대화상자 닫기 → 휴지통 목록에서 제거 → 삭제 완료 안내
   └─ 실패 → 대화상자와 대상 유지 → 다시 시도 또는 취소
```

- 확인 대화상자에는 프로젝트 제목과 파일·설정까지 삭제된다는 영향을 표시한다.
- 기본 포커스는 `취소`에 두며 대화상자가 열린 동안 포커스를 내부에 가둔다.
- 삭제 중에는 닫기, 취소와 확인 행동을 잠그고 `삭제 중…`을 표시해 중복 요청을 막는다.
- 실패하면 대상 프로젝트와 배경 목록 순서를 유지하고 같은 대화상자에서 재시도할 수 있다.
- 성공하면 프로젝트를 휴지통 목록에서 제거한다. 남은 항목이 없으면 삭제 완료 안내와 빈 상태를 함께 표시한다.
- 성공 후 포커스는 다음 항목의 `복원`으로 옮기며, 다음 항목이 없으면 빈 상태의 `프로젝트 목록으로 돌아가기`로 옮긴다.

## 휴지통 조회

```text
프로젝트 목록 사이드바
→ 프로젝트 휴지통
→ 휴지통 조회
├─ 항목 있음 → 최근 이동순 목록
├─ 항목 없음 → 빈 상태 → 프로젝트 목록으로 돌아가기
└─ 실패 → 오류 안내 → 다시 시도
```

- 조회 중에는 실제 항목과 같은 높이의 스켈레톤을 표시해 목록의 공간을 유지한다.
- 조회 실패 후 재시도하면 로딩 상태로 돌아가며, 성공 결과에 따라 목록 또는 빈 상태를 표시한다.
- 휴지통의 프로젝트 정보는 작업공간 진입 행동을 제공하지 않는다.
