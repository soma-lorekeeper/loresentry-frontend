# 프로젝트 휴지통 Workflow

## 휴지통으로 이동

```text
프로젝트 목록
→ 프로젝트 더보기
→ 휴지통으로 이동
→ 이동 확인
→ 프로젝트 목록에서 제거
→ 프로젝트 휴지통에 보관
```

```text
이동 확인
├─ 취소 또는 Esc → 카드 메뉴의 휴지통 이동 행동
└─ 휴지통으로 이동 → 이동 중
   ├─ 성공 → 목록에서 카드 제거 → 복원 가능 안내
   └─ 실패 → 대화상자와 목록 유지 → 다시 시도 또는 취소
```

- 이동 확인에는 대상 프로젝트 제목과 목록·작업공간에서 제거된다는 영향을 표시한다.
- 프로젝트의 파일과 설정은 휴지통에 보존하며 복원 전까지 작업공간에 진입할 수 없다.
- 이동 중에는 대화상자를 닫지 않고 취소와 확인 행동을 잠가 중복 요청을 막는다.
- 실패하면 사용자가 선택한 프로젝트와 목록 순서를 바꾸지 않는다.
- 성공 안내는 프로젝트 휴지통에서 복원할 수 있음을 포함한다.

## 복원

```text
프로젝트 휴지통
→ 프로젝트 복원
→ 프로젝트 목록
```

## 영구 삭제

```text
프로젝트 휴지통
→ 영구 삭제
→ 대상 프로젝트와 복구 불가 안내 확인
→ 영구 삭제
→ 프로젝트 휴지통
```
