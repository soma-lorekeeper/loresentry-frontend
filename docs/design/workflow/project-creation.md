# 프로젝트 생성 Workflow

## 프로젝트가 없는 경우

```text
프로젝트 목록 빈 상태
→ 첫 프로젝트 만들기
→ 프로젝트 제목 입력
→ 프로젝트 만들기
→ 통합 작업공간 시작 안내
```

## 기존 프로젝트가 있는 경우

```text
프로젝트 목록
→ 새 프로젝트
→ 프로젝트 제목 입력
→ 프로젝트 만들기
→ 통합 작업공간 시작 안내
```

## 취소

```text
프로젝트 제목 입력
→ 취소
→ 프로젝트 목록
```

## 입력과 제출

```text
프로젝트 제목 입력
├─ 빈 값·공백만·255자 초과 → 입력 오류 → 제목 수정
├─ 유효한 값 → 프로젝트 만들기 → 생성 중
│  ├─ 중복 제목 → 입력 유지 → 제목 수정 또는 다시 시도
│  ├─ 기타 오류 → 입력 유지 → 취소 또는 다시 시도
│  └─ 생성 성공과 유효한 프로젝트 ID → 통합 작업공간 시작 안내
└─ 취소 또는 Esc → 프로젝트 목록
```

- 제출할 제목은 앞뒤 공백을 제거하고 단어 사이 공백은 유지한다.
- 생성 중에는 입력, 취소, 닫기와 제출을 잠가 한 번의 요청만 유지한다.
- 생성 실패 뒤 다시 시도하면 보존한 입력으로 새 요청을 보낸다.
- 성공 응답에 유효한 프로젝트 ID가 없으면 작업공간으로 이동하지 않고 오류 상태를 표시한다.
