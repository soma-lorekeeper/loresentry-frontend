# 사용자 생성 섹션 삭제 Workflow

사용자 생성 섹션을 제거하면서 내부 항목은 기본 파일 섹션에 보존한다.

## 내용이 있는 섹션

```text
사용자 생성 섹션 더보기
→ 섹션 삭제
→ 섹션 이름, 파일·폴더 수와 이동 위치 확인
→ 섹션 삭제 확인
→ 파일 섹션 최상위에 섹션 이름의 폴더 생성
→ 내부 항목과 중첩 구조 이동
→ 사용자 생성 섹션 제거
→ 이동된 폴더로 포커스 이동
```

- 같은 이름의 폴더가 있으면 숫자 접미사를 붙인 새 폴더를 만든다.
- 파일·폴더 식별자와 이를 가리키는 즐겨찾기 바로가기는 유지한다.
- 이동과 섹션 제거는 하나의 작업으로 처리한다.

## 빈 섹션

```text
빈 사용자 생성 섹션 더보기
→ 섹션 삭제
→ 내부 항목 없음 확인
→ 섹션 삭제 확인
→ 섹션만 제거
→ 기본 파일 섹션 헤더로 포커스 이동
```

빈 섹션은 기본 파일 섹션에 대체 폴더를 만들지 않는다.

## 취소와 실패

```text
삭제 확인
→ 취소 또는 Esc
→ 대화상자 닫기
→ 원래 섹션의 섹션 삭제 항목으로 포커스 복귀
```

```text
삭제 확인
→ 이동 또는 섹션 제거 실패
→ 전체 변경 취소
→ 기존 섹션과 내부 항목 유지
→ 오류, 다시 시도와 취소 표시
```

- 실패 후 `다시 시도`는 같은 대상과 목적지를 다시 검증한 뒤 전체 작업을 재실행한다.
- 기본 즐겨찾기와 파일 섹션에는 이 Workflow로 들어오는 삭제 행동이 없다.
