# 이벤트 시간 흐름 편집 Workflow

## 이벤트 파일 열기

```text
사이드바·검색·그래프 또는 열린 탭
→ 이벤트 파일 열기
→ 제목·속성·시간 흐름·내용 표시
```

이벤트 제목, 사용자 정의 속성과 문서 내용은 속성 문서와 같은 방식으로 직접
편집하고 자동 저장한다.

## 시간 항목 생성

```text
이벤트 파일의 시간 흐름
→ 항목 추가
→ 미정 유형의 빈 편집 카드 열기
→ 항목 제목 입력
→ 날짜·시간, 순서 또는 미정 선택
→ 선택한 유형에 필요한 값 입력
→ 완료
→ 해당 시간 유형 그룹에 항목 표시
```

- 제목이 없으면 완료할 수 없다.
- 관련 파일을 선택하면 상위 이벤트 파일의 관계로 저장한다.
- 취소하면 시간 항목과 관계를 만들지 않는다.

## 시간 항목 선택과 편집

```text
시간 항목 선택
→ 선택 상태와 편집 카드 표시
→ 제목·시간 유형·값·설명·관련 파일 변경
→ 완료
→ 시간 유형과 값에 맞는 그룹과 위치로 이동
```

- 시간 유형을 바꾸면서 기존 값이 제거되면 먼저 확인한다.
- 저장 오류가 발생하면 입력을 유지하고 다시 시도할 수 있다.

## 시간 항목 삭제

```text
시간 항목 더보기
→ 삭제
→ 삭제 확인 대화상자
→ 삭제 확인
→ 항목과 해당 항목의 파일 관계 제거
→ 다음 또는 이전 항목 선택
```

삭제를 취소하면 대화상자를 닫고 대상 시간 항목으로 포커스를 돌려보낸다.
