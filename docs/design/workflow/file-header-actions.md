# 파일 헤더 동작 Workflow

[파일 헤더](../workspace/file-header.md)의 `버전`, `내보내기`, `잠금`이 만드는
상태 전이를 기록한다. `메모`는
[메모 패널 배치](./memo-panel-layout.md)를 따른다.

## 버전 기록 열기

```text
원고 또는 속성 문서 편집 화면
→ 파일 헤더의 버전 선택
→ 배경을 흐리게 덮고 버전 기록 모달 열기
→ 최신 버전을 고른 상태로 시작
→ 선택한 버전과 현재 문서를 나란히 표시
```

- 속성이 있는 파일은 `속성`과 `본문`을 한 스크롤에 잇고, 원고는 `본문`만 보인다.
- 목록에서 다른 버전을 고르면 모달을 닫지 않고 비교 영역만 바꾼다.
- `Esc`, `×` 또는 모달 밖 선택은 모달을 닫고 `버전`으로 포커스를 돌린다.

## 버전 저장

```text
버전 기록 모달
→ 버전 저장
→ 지금 상태를 새 버전으로 기록
→ 목록 맨 위에 수동 저장으로 추가
→ 모달 유지
```

- 저장 뒤에도 모달을 닫지 않는다. 방금 남긴 버전이 목록에 쌓이는 것을 보여 준다.
- 저장된 버전이 없던 파일은 이 행동으로 첫 버전을 갖는다.

## 버전 복원

```text
버전 기록 모달
→ 목록에서 버전 선택
→ 이 버전으로 복원
→ 지금 상태를 먼저 버전으로 기록
→ 선택한 버전의 속성과 본문으로 문서를 되돌림
→ 모달을 닫고 되돌아온 문서 표시
```

- 복원 직전 상태를 항상 버전으로 남기므로 복원은 되돌릴 수 있는 행동이다.
  별도의 확인 대화상자를 두지 않는 이유가 여기에 있다.
- 잘못 복원했으면 다시 `버전`을 열어 방금 남은 버전을 고른다.
- 속성과 본문을 함께 되돌린다. 일부만 골라 받는 흐름은 두지 않는다.

## 내보내기

```text
원고 또는 속성 문서 편집 화면
→ 파일 헤더의 내보내기 선택
→ 버튼 아래에 형식 목록 열기
→ 형식 선택
→ 해당 형식으로 파일 내보내기
→ 목록을 닫고 내보내기로 포커스 복귀
```

- 형식을 고르는 것이 곧 실행이다. 중간 확인 단계를 두지 않는다.
- 목록은 배경을 덮지 않으므로 여는 동안에도 문서를 계속 읽을 수 있다.
- `Esc`, 목록 밖 선택 또는 `내보내기` 재선택은 내보내지 않고 목록만 닫는다.

## 잠금 전환

```text
편집 가능 상태 (열린 자물쇠)
→ 잠금 선택
→ 자물쇠를 닫힌 모양으로 바꾸고 버튼을 활성으로 표시
→ 편집 도구와 본문 입력을 비활성으로 전환
→ 하단 가운데에 편집이 비활성화 되었습니다 알림
→ 편집 잠김 상태
```

```text
편집 잠김 상태 (닫힌 자물쇠)
→ 잠금 선택
→ 자물쇠를 열린 모양으로 되돌리고 버튼을 기본으로 표시
→ 편집 도구와 본문 입력을 다시 활성으로 전환
→ 하단 가운데에 편집이 활성화 되었습니다 알림
→ 편집 가능 상태
```

- 두 방향 모두 확인 대화상자를 거치지 않는다. 같은 버튼으로 바로 되돌린다.
- 잠긴 동안에도 `메모`, `버전`, `내보내기`는 그대로 연다.
- 잠긴 동안 `버전 저장`과 `이 버전으로 복원`은 실행할 수 없고 비교만 볼 수 있다.
- 알림은 잠시 뒤 스스로 사라지며 행동 버튼을 두지 않는다.
