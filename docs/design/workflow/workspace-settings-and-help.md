# 작업공간 설정과 도움말 Workflow

## 프로젝트 설정 열기

```text
통합 작업공간 사이드바
→ 설정 선택
→ 기존 설정 탭이 있으면 해당 탭으로 이동
→ 없으면 프로젝트 설정 탭 열기
```

설정 탭을 열면 사이드바의 설정 항목을 선택 상태로 표시한다.

## 프로젝트 설정 저장

```text
프로젝트 설정 탭
→ 프로젝트 이름 또는 설명 변경
→ 변경사항 저장
→ 저장 중
→ 저장 완료
```

- 저장에 실패하면 현재 입력을 유지하고 다시 시도한다.
- 취소하면 마지막 저장값으로 되돌린다.
- 저장하지 않은 상태로 설정 탭을 닫거나 프로젝트를 바꾸면 변경사항을 버릴지
  확인한다.

## 프로젝트 휴지통 이동

```text
프로젝트 설정의 위험 영역
→ 프로젝트를 휴지통으로 이동
→ 프로젝트 이름을 포함한 확인 대화상자
→ 이동 확인
→ 프로젝트 목록
```

취소하면 대화상자를 닫고 위험 영역의 이동 버튼으로 포커스를 돌려보낸다.

## 도움말 열기

```text
통합 작업공간 사이드바
→ 도움말 선택
→ 기존 도움말 탭이 있으면 해당 탭으로 이동
→ 없으면 도움말 기본 화면 열기
```

## 사용 가이드 탐색

```text
도움말 기본 화면
→ 사용 가이드 선택
→ 가이드 주제 목록
→ 주제 선택
→ 같은 도움말 탭에서 가이드 본문
→ 도움말로 돌아가기
→ 도움말 기본 화면
```

## 피드백 보내기

```text
도움말 기본 화면
→ 피드백 보내기 선택
→ 브라우저 새 탭에서 외부 피드백 폼 열기
→ Lorekeeper로 복귀
→ 도움말 탭과 피드백 보내기 포커스 복원
```

새 탭을 열지 못하면 현재 도움말 화면에서 다시 열기와 링크 복사를 제공한다.
