# 파일·폴더 생성과 이름 변경 Workflow

## 파일 생성

```text
섹션 더보기 → 파일 유형 선택 → 섹션 최상위에 파일 생성
→ 사이드바에서 이름 인라인 입력 → 입력 확정 → 중앙 탭에서 파일 열기
```

```text
폴더 더보기 → 파일 유형 선택 → 해당 폴더 안에 파일 생성
→ 사이드바에서 이름 인라인 입력 → 입력 확정 → 중앙 탭에서 파일 열기
```

- 파일 생성에 별도 모달을 사용하지 않는다.
- 이름 입력을 취소하면 생성 중인 빈 파일을 제거한다.

## 폴더 생성

```text
섹션 또는 폴더 더보기 → 새 폴더
→ 선택한 위치에 폴더 생성 → 사이드바에서 이름 인라인 입력 → 입력 확정
```

- 섹션에서 만들면 섹션 최상위에 생성한다.
- 폴더에서 만들면 해당 폴더 안에 생성한다.
- 이름 입력을 취소하면 생성 중인 빈 폴더를 제거한다.

## 이름 변경

다음 두 진입점을 모두 제공한다.

```text
파일 또는 폴더 더블클릭 → 이름 인라인 입력 → 입력 확정
```

```text
파일 또는 폴더 더보기 → 이름 변경 → 이름 인라인 입력 → 입력 확정
```

- 이름 변경에 별도 모달을 사용하지 않는다.
- 이름 변경을 취소하면 기존 이름을 유지한다.

## Pencil 시각 참조

- 파일 생성 인라인 입력 상태는
  `31 · Workspace · File Create Inline`(`jwhkD`)을 기준으로 한다.
- 폴더 생성 인라인 입력 상태는
  `32 · Workspace · Folder Create Inline`(`m7kHy`)을 기준으로 한다.
- 기존 항목 이름 변경 인라인 입력 상태는
  `33 · Workspace · Item Rename Inline`(`H9zx7`)을 기준으로 한다.
