# 작업공간 그래프 Workflow

## 그래프 열기

```text
사이드바 그래프 선택
→ 열린 그래프 탭이 있으면 해당 탭으로 이동
→ 없고 현재 탭이 새 탭 화면이면 현재 탭을 그래프 탭으로 전환
→ 그 외에는 새 그래프 탭 열기
→ 저장된 상태가 있으면 카메라·필터·검색·선택 복원
→ 저장된 상태가 없으면 전체 그래프 화면 맞춤
```

## 노드 선택

```text
노드 선택
→ 선택 노드와 직접 연결 강조
→ 나머지 노드와 연결 흐리게 표시
→ 오른쪽 상세 패널 열기
```

```text
빈 캔버스 선택 또는 Esc
→ 선택 해제
→ 상세 패널 닫기
→ 현재 카메라·검색·필터 유지
```

## 파일 열기

```text
선택 노드 상세 패널 → 파일 열기
→ 파일 탭이 이미 있으면 해당 탭으로 이동
→ 없으면 새 파일 탭 열기
→ 파일의 주 콘텐츠 영역으로 포커스 이동
```

그래프 탭은 닫지 않고 마지막 상태를 유지한다.

## 검색

```text
노드 검색어 입력
→ 일치 노드 강조
→ 첫 번째 결과로 카메라 이동
→ 결과가 없으면 검색 결과 없음 상태
```

- 검색어를 지우면 검색 전 카메라 위치로 돌아가고 필터는 유지한다.
- 검색 결과를 선택하면 일반 노드 선택 상태로 전환한다.

## 필터

```text
파일 유형 또는 관계 유형 선택
→ 활성 조건 수 표시
→ 일치 노드와 연결만 표시
→ 결과가 없으면 필터 결과 없음 상태
```

`필터 초기화`는 모든 필터와 검색어를 지우고 전체 그래프를 화면에 맞춘다.

## 확대와 이동

```text
확대·축소 또는 캔버스 이동
→ 카메라 상태 변경
→ 선택·검색·필터 유지
```

`화면 맞춤`은 현재 표시 중인 노드만 기준으로 카메라를 다시 맞춘다.

## 오류 복구

```text
그래프 불러오기 실패
→ 오류 상태와 다시 시도 표시
→ 다시 시도
→ 성공하면 이전 검색·필터·선택 복원
→ 실패하면 오류 상태 유지
```
