# 즐겨찾기 Workflow

## 추가

```text
통합 작업공간 사이드바의 파일 또는 폴더
→ 즐겨찾기 섹션으로 드래그
→ 즐겨찾기 섹션에 드롭
→ 원본 항목의 바로가기 생성
```

원본 파일 또는 폴더는 기존 위치에 유지한다. 같은 원본의 바로가기는 중복해서 생성하지 않는다.

## 제거

```text
즐겨찾기 섹션
→ 바로가기 제거
→ 즐겨찾기에서 제거
```

바로가기만 제거하고 원본 파일 또는 폴더는 유지한다.

- 원본의 이름이나 위치가 바뀌어도 바로가기를 유지한다.
- 원본이 삭제되면 해당 바로가기도 제거한다.

## Pencil 시각 참조

즐겨찾기 섹션이 드롭 대상이 된 상태는
`36 · Workspace · Favorites Drop Target`(`GkSbZ`)을 기준으로 한다.
