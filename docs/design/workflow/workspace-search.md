# 작업공간 검색 Workflow

## 검색 열기

```text
사이드바 검색 선택
→ 열린 검색 탭이 있으면 해당 탭으로 이동
→ 없고 현재 탭이 새 탭 화면이면 현재 탭을 검색 탭으로 전환
→ 그 외에는 새 검색 탭 열기
→ 검색 입력에 포커스
```

- 검색 탭은 현재 프로젝트에서 하나만 유지한다.
- 검색 탭을 다시 열면 기존 검색어와 결과 상태를 유지한다.

## 검색 실행

```text
검색어 입력 → 입력 상태 → 결과 있음 또는 결과 없음
검색 요청 실패 → 오류 상태 → 다시 시도 → 같은 검색어로 검색
```

- 공백을 제외한 검색어가 비어 있으면 초기 상태로 돌아간다.
- 새 검색어를 입력하면 이전 요청의 결과를 현재 검색어의 결과로 표시하지 않는다.

## 결과 열기

```text
검색 결과 선택
→ 파일 탭이 이미 열려 있으면 해당 탭으로 이동
→ 열려 있지 않으면 새 파일 탭 열기
→ 사이드바에서 상위 폴더를 펼치고 파일 위치 표시
→ 파일의 주 콘텐츠 영역으로 키보드 포커스 이동
```

- 검색 탭은 닫지 않으며 사용자가 다시 돌아왔을 때 검색어와 결과를 유지한다.
- 파일의 주 콘텐츠 영역이 편집기이면 편집기의 마지막 편집 위치에 포커스를 둔다.
- 편집기가 아닌 파일은 화면 제목 또는 첫 번째 주 행동에 포커스를 둔다.
