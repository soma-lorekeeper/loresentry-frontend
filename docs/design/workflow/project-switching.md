# 프로젝트 전환 Workflow

## 프로젝트 목록으로 이동

```text
통합 작업공간
→ 현재 프로젝트 이름 선택
→ 프로젝트 전환 메뉴
→ 프로젝트 목록
```

`프로젝트 목록`은 프로젝트 전환 메뉴의 첫 항목으로 표시한다.

## 다른 프로젝트로 이동

```text
통합 작업공간
→ 현재 프로젝트 이름 선택
→ 프로젝트 전환 메뉴
→ 다른 프로젝트 선택
→ 현재 프로젝트의 열린 탭 상태 저장
→ 선택한 프로젝트의 통합 작업공간
→ 선택한 프로젝트의 마지막 작업 상태 복원
```

새 프로젝트 생성은 프로젝트 전환 메뉴에서 제공하지 않는다.
