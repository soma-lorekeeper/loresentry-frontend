# 프로젝트 진입 Workflow

```text
프로젝트 목록 → 프로젝트 카드 선택 → 프로젝트 ID 검증 → 통합 작업공간
```

- 카드의 더보기 버튼과 메뉴 항목은 프로젝트 진입을 실행하지 않는다.
- 프로젝트 ID가 없거나 접근할 수 없으면 목록에 머물며 오류 상태를 알리고 자동으로 다른 프로젝트를 열지 않는다.
- 처음 만든 프로젝트는 통합 작업공간의 시작 안내 화면을 표시한다.
- 기존 프로젝트는 마지막으로 작업한 문서와 작업공간 배치를 복원한다.
- 열린 문서를 모두 닫으면 통합 작업공간의 기본 화면을 표시한다.
- 프로젝트 현황은 별도의 프로젝트 홈이 아닌 기본 화면 또는 작업공간 내부 탭으로 제공한다.

## 상태 계약

| 상태 | 사용자에게 보이는 결과 | 다음 행동 |
| --- | --- | --- |
| 진입 준비 | 선택한 프로젝트 카드를 선택 상태로 표시한다. | 프로젝트 ID와 접근 권한을 확인한다. |
| 진입 중 | 중복 선택을 막고 진행 중임을 표시한다. | 검증이 끝나면 작업공간으로 이동한다. |
| 진입 실패 | 프로젝트 목록을 유지하고 해당 프로젝트를 열 수 없다는 오류를 표시한다. | 다시 시도하거나 다른 프로젝트를 선택한다. |
| 진입 성공 | 새 프로젝트는 시작 안내, 기존 프로젝트는 복원된 작업공간을 표시한다. | 작업공간에서 콘텐츠를 탐색한다. |
