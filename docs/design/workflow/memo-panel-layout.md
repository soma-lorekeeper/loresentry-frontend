# 메모 패널 배치 Workflow

파일 메모 패널의 오른쪽·아래 배치, 크기 조절과 AI 챗 동시 표시를 정의한다.

## 크기 조절

```text
메모 패널 열림
→ 경계 조절 손잡이 드래그 또는 방향키 입력
→ 배치별 최소·최대 범위 안에서 크기 변경
→ 프로젝트·사용자 단위로 마지막 크기 저장
```

- 오른쪽 너비는 `320px`부터 파일 콘텐츠의 `45%`까지 조절한다.
- 아래 높이는 `240px`부터 파일 콘텐츠의 `50%`까지 조절한다.
- 범위를 넘는 입력은 가까운 한계값에서 멈추고 현재 수치를 알린다.

## AI 챗 동시 표시

```text
오른쪽 메모 패널 열림
→ AI 챗 열기
→ 메모 패널을 임시 아래 배치로 전환
→ AI 챗 닫기
→ 마지막 수동 배치가 오른쪽이면 오른쪽 배치와 너비 복원
```

```text
AI 챗과 임시 아래 메모 패널 열림
→ 사용자가 아래 배치를 직접 선택하거나 크기를 조절
→ 아래 배치를 마지막 수동 배치로 저장
→ AI 챗 닫기
→ 아래 배치 유지
```

## 좁은 작업 영역

```text
보조 패널 열기
→ 남은 파일 콘텐츠가 560px × 320px 미만
→ 새 패널 표시
→ 기존 패널 접기와 안내 표시
→ 사용자가 다시 열기 선택
→ 공간이 충분하면 열기, 부족하면 새 패널과 교체
```

- 접힌 패널은 선택 범위, 입력과 크기를 잃지 않는다.
- 공간이 넓어져도 자동으로 다시 열지 않아 예기치 않은 레이아웃 변화를 막는다.
- 패널을 닫으면 해당 패널의 열기 버튼으로 포커스를 돌린다.
