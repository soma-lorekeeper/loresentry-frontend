# 파일·폴더 휴지통 Workflow

## 휴지통으로 이동

```text
파일 또는 폴더 더보기 → 휴지통으로 이동 → 프로젝트 휴지통에 보관
```

- 삭제한 파일의 편집 탭이 열려 있으면 해당 탭만 닫는다.
- 폴더를 삭제하면 폴더 안에 포함된 파일의 열린 탭만 닫는다.
- 삭제 대상과 관계없는 탭은 유지한다.
- 삭제한 파일과 폴더를 가리키는 즐겨찾기 바로가기는 제거한다.

## 복원

```text
사이드바 휴지통 → 삭제된 파일 또는 폴더 → 복원 → 삭제 전 위치로 이동
```

삭제 전 상위 폴더가 존재하지 않으면 파일 섹션 최상위로 복원한다.

## 영구 삭제

```text
사이드바 휴지통 → 삭제된 파일 또는 폴더 → 영구 삭제
→ 확인 → 프로젝트에서 완전히 삭제
```

영구 삭제는 취소하거나 복원할 수 없다.
