# 파일·폴더 이동 Workflow

```text
파일 섹션의 파일 또는 폴더
→ 이동할 항목을 드래그
→ 대상 폴더 또는 섹션에 드롭
→ 원본 항목의 위치 이동
```

- 더보기 메뉴에는 `이동`을 제공하지 않는다.
- 폴더 안이나 섹션 사이의 이동은 드래그 앤 드롭으로만 수행한다.
- 즐겨찾기로 드롭하면 원본을 이동하지 않고 바로가기를 생성한다.

## Pencil 시각 참조

- 항목을 끌고 있는 상태는
  `34 · Workspace · Item Dragging`(`LmEmI`)을 기준으로 한다.
- 폴더가 드롭 대상이 된 상태는
  `35 · Workspace · Folder Drop Target`(`CMK2T`)을 기준으로 한다.
