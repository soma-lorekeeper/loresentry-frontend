# 메모 탭 Workflow

## 메모 열기

```text
사이드바 메모 선택
→ 열린 메모 탭이 있으면 해당 탭으로 이동
→ 없고 현재 탭이 새 탭 화면이면 현재 탭을 메모 탭으로 전환
→ 그 외에는 새 메모 탭 열기
→ 메모 화면 제목으로 포커스 이동
```

- 메모 탭은 현재 프로젝트에서 하나만 유지한다.
- 프로젝트를 전환하면 전환한 프로젝트의 메모 탭과 목록을 복원한다.

## 메모 범위 전환

```text
프로젝트 메모 또는 파일 메모 선택
→ 선택한 범위의 전체 카드 목록 표시
→ 반대쪽 범위의 작성 내용과 스크롤 위치 유지
```

- 메모가 많아져도 접거나 일부만 표시하지 않고 전체 목록을 아래로 이어서 표시한다.

## 메모 작성

```text
프로젝트 메모 범위에서 상단 + 선택
→ 목록 맨 앞에 빈 정사각형 카드 표시
→ 카드 안에서 바로 본문 입력
→ 입력이 멈추면 자동 저장
→ 카드 안에 저장 중 표시
→ 성공하면 저장됨 표시
```

```text
자동 저장 실패
→ 입력값과 카드 유지
→ 다시 시도
→ 같은 입력값으로 저장
```

- 입력하지 않은 빈 카드는 포커스가 밖으로 이동하면 제거한다.
- 파일 메모는 각 파일 화면에서만 만들며 메모 탭에서는 생성하지 않는다.

## 파일 메모 생성 반영

```text
파일 화면에서 해당 파일의 메모 작성
→ 파일 메모 자동 저장
→ 메모 탭의 파일 메모 범위에 해당 파일 카드 표시
```

- 한 파일에는 파일 메모 하나만 만든다.
- 메모 탭에서는 기존 파일 메모를 편집하거나 삭제할 수 있지만 새 파일 메모를
  만들 수 없다.

## 메모 편집

```text
프로젝트 메모 또는 파일 메모 본문 선택
→ 카드 안에 커서 표시
→ 본문 수정
→ 입력이 멈추면 자동 저장
→ 저장 중 또는 저장됨 상태 표시
```

- 별도의 편집 모드, 저장 버튼과 취소 버튼을 두지 않는다.
- 여러 카드의 입력 상태를 동시에 유지할 수 있다.
- 저장 실패 시 수정값을 유지하고 카드 안에서 다시 시도한다.

## 메모 삭제

```text
더보기 > 삭제
→ 삭제 확인 대화상자
→ 삭제 확인
→ 성공하면 목록에서 제거
→ 다음 카드 또는 새 메모로 포커스 이동
```

```text
삭제 실패
→ 대화상자와 메모 미리보기 유지
→ 다시 시도
→ 같은 메모 삭제 재요청
```

- 대화상자에서 `취소` 또는 `Esc`를 선택하면 메모를 유지하고 원래 카드의
  `더보기`로 돌아간다.
- 마지막 메모를 삭제하면 빈 상태로 전환한다.

## 파일로 이동

```text
파일 메모 카드 더보기 > 파일로 이동
→ 파일 탭이 이미 열려 있으면 해당 탭으로 이동
→ 열려 있지 않으면 새 파일 탭 열기
→ 파일의 주 콘텐츠 영역으로 포커스 이동
```

- 파일 메모의 `삭제`는 메모만 삭제하고 원본 파일은 유지한다.

## 파일 메모 패널과 동기화

```text
메모 탭에서 프로젝트 메모 저장 또는 삭제
→ 열린 파일 메모 패널의 프로젝트 메모 목록 갱신
```

```text
파일 메모 패널에서 프로젝트 메모 변경
→ 메모 탭의 동일 카드 갱신
```

- 두 진입점은 같은 프로젝트 메모를 사용한다.
- 한쪽에서 편집 중인 메모가 다른 쪽에서 변경되면 자동으로 덮어쓰지 않고 편집 중인
  화면에 최신 값이 있음을 알린다.
