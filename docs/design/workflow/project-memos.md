# 프로젝트 메모 Workflow

## 메모 열기

```text
사이드바 메모 선택
→ 열린 메모 탭이 있으면 해당 탭으로 이동
→ 없고 현재 탭이 새 탭 화면이면 현재 탭을 메모 탭으로 전환
→ 그 외에는 새 메모 탭 열기
→ 프로젝트 메모 화면 제목으로 포커스 이동
```

- 메모 탭은 현재 프로젝트에서 하나만 유지한다.
- 프로젝트를 전환하면 전환한 프로젝트의 메모 탭과 목록을 복원한다.

## 메모 작성

```text
새 메모 또는 첫 메모 작성 선택
→ 목록 맨 앞에 작성 카드 표시
→ 본문 입력
→ 저장
→ 저장 중
→ 성공하면 읽기 카드로 전환하고 목록 맨 앞으로 이동
```

```text
저장 실패
→ 입력값과 작성 카드 유지
→ 다시 시도
→ 같은 입력값으로 저장
```

- 공백만 있는 본문은 저장하지 않는다.
- 작성 중 `취소`하면 작성 카드를 제거하고 원래 목록 또는 빈 상태로 돌아간다.

## 메모 편집

```text
카드 본문 선택 또는 더보기 > 편집
→ 같은 위치에서 편집 카드로 전환
→ 본문 수정
→ 저장
→ 성공하면 읽기 카드로 전환하고 목록 맨 앞으로 이동
```

```text
편집 중 취소
→ 마지막 저장 값 복원
→ 같은 카드의 읽기 상태로 돌아감
```

- 다른 카드가 편집 중이면 새 편집 상태를 열지 않고 기존 편집 카드로 이동한다.
- 저장 실패 시 수정값을 유지하고 카드 안에서 다시 시도한다.

## 메모 삭제

```text
더보기 > 삭제
→ 삭제 확인 대화상자
→ 삭제 확인
→ 성공하면 목록에서 제거
→ 다음 카드 또는 새 메모로 포커스 이동
```

```text
삭제 실패
→ 대화상자와 메모 미리보기 유지
→ 다시 시도
→ 같은 메모 삭제 재요청
```

- 대화상자에서 `취소` 또는 `Esc`를 선택하면 메모를 유지하고 원래 카드의
  `더보기`로 돌아간다.
- 마지막 메모를 삭제하면 빈 상태로 전환한다.

## 파일 메모 패널과 동기화

```text
메모 탭에서 프로젝트 메모 저장 또는 삭제
→ 열린 파일 메모 패널의 프로젝트 메모 목록 갱신
```

```text
파일 메모 패널에서 프로젝트 메모 변경
→ 메모 탭의 동일 카드 갱신
```

- 두 진입점은 같은 프로젝트 메모를 사용한다.
- 한쪽에서 편집 중인 메모가 다른 쪽에서 변경되면 자동으로 덮어쓰지 않고 편집 중인
  화면에 최신 값이 있음을 알린다.
