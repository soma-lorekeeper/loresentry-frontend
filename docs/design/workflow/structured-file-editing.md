# 속성 문서 편집 Workflow

## 새 파일 작성

```text
새 탭 또는 사이드바 파일 섹션
→ 설정·캐릭터·조직·아이템·장소·세계관 중 하나 선택
→ 제목·속성·내용 구조의 빈 문서를 현재 탭에 열기
→ 제목 입력
→ 필요한 속성 추가 또는 내용 작성
→ 자동 저장
→ 저장 완료 상태
```

- 새 파일에는 고정 속성을 미리 만들지 않는다.
- 제목과 내용만 작성해도 저장할 수 있다.
- 제목을 입력하면 사이드바와 탭 이름에 즉시 반영한다.
- 자동 저장에 실패하면 입력을 유지하고 `다시 시도`를 제공한다.

## 기존 파일 편집

```text
사이드바·검색·그래프 또는 열린 탭
→ 설정·캐릭터·조직·아이템·장소·세계관 파일 열기
→ 저장된 제목·속성·내용 표시
→ 원하는 영역을 직접 편집
→ 자동 저장
→ 저장 완료 상태
```

- 편집 모드를 별도로 켜지 않는다.
- 저장 중 탭을 바꾸거나 보조 패널을 열어도 변경 내용을 버리지 않는다.
- 같은 파일을 다시 열면 기존 탭으로 이동하고 마지막 스크롤 위치를 복원한다.

## 속성 추가

```text
제목과 내용 사이의 속성 영역
→ 속성 추가
→ 속성 이름 입력
→ 텍스트 또는 참조할 파일 유형 선택
→ 속성 값 입력 또는 파일 선택
→ 자동 저장
```

- 텍스트 속성은 입력한 값을 그대로 저장한다.
- 파일 참조 속성은 선택한 유형의 파일만 검색한다.
- 파일을 선택하면 참조 칩을 만들고 그래프 관계에 반영한다.
- 속성을 삭제하면 해당 속성의 값과 관계만 제거하고 참조한 파일은 유지한다.

## 파일 메모 열기

```text
속성 문서 편집 화면
→ 파일 헤더의 메모 선택
→ 편집 영역 오른쪽 또는 아래에 메모 패널 열기
→ 파일 메모 선택
→ 현재 속성 문서 파일의 단일 메모 편집
```

메모 패널을 닫으면 파일 헤더의 메모 버튼으로 포커스를 돌려보낸다.
