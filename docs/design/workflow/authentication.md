# Google OAuth 인증 Workflow

로그인 화면에서 약관을 안내하고 Google OAuth 인증과 가입을 하나의 흐름으로 처리한다.

## 기본 흐름

```text
로그인 페이지
→ 약관 안내 확인
→ Google로 계속하기
   ├─ 이용약관 동의 의사 표시
   └─ Google OAuth 시작
→ 로그인 페이지의 인증 처리 중 상태
→ Google OAuth 인증
→ Google 계정 식별
   ├─ 기존 사용자
   │  → 로그인 완료
   │  → 프로젝트 목록
   └─ 신규 사용자
      → Lorekeeper 계정 생성
      → 로그인 완료
      → 프로젝트 목록
```

## 예외 흐름

```text
Google OAuth 인증
   ├─ 사용자 취소
   │  → Lorekeeper 계정 미생성 또는 로그인 미완료
   │  → 로그인 페이지의 인증 취소 상태
   │  → 다시 시도
   └─ 인증 또는 결과 처리 실패
      → Lorekeeper 계정 미생성 또는 로그인 미완료
      → 로그인 페이지의 인증 실패 상태
      → 다시 시도
```

## 세션 만료 흐름

```text
보호된 기존 작업공간
→ 세션 만료
→ 로그인 페이지의 세션 만료 상태
→ Google OAuth 인증
   ├─ 서버가 기존 작업 맥락을 확인함
   │  → 기존 작업공간 복귀
   └─ 기존 작업 맥락을 확인할 수 없음
      → 프로젝트 목록
```

복귀 대상은 서버가 인증 전 작업 맥락으로 확인한 Lorekeeper 내부 작업공간으로
제한한다. 확인할 수 없거나 대상이 유효하지 않으면 프로젝트 목록으로 이동한다.

로그인 화면의 상태 문구, 유지 요소, 재시도와 포커스 계약은
[로그인 페이지](../login/README.md)를 따른다.
